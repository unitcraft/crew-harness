# Машина: Запуск сессии

- machine: session_start
- machine_version: 1
- format: 2.26

Запуск одной сессии агента (задача 121): ворота профиля и цены В2, проверка объёма ОБЪЁМ и ворота В1, вызов вложенной машины «Шаг агента» в состоянии СЕССИЯ, разбор итога сессии РАЗБОР_ИТОГА и ворота сбоя В13_СЕССИЯ. Это таблица методики (`task-runner-session-states.md`, десять состояний) в Алуле; «Шаг агента» (`agent_step.alula.md`) вызывается стороной вида `machine`, фрагмент «Пауза» передаёт ему «стоп», «продолжить», «остановить» и «отмену». Вызывают эту машину «Раннер» и «Проверка цикла» (задача 123); профиль запуска, сборка промпта, измерение объёма, чтение артефакта сессии, подготовка и завершение запуска и остановка группы процессов агента — примитивы хозяина (`standard_registry()`), у которых в продукте пока исполнитель для тестов (`ScriptedHost`). Подготовка запуска (`prepare_launch`: группа процессов агента, запись запуска, отметки `progress.log` и `profile.log`) и его завершение (`finish_launch`: подсказка из `profile.log`, проверка `progress.log`, расшифровка диалога) — записывающие примитивы в действиях строк; прежде они были спрятаны внутри читающего `session_context`, а повтор у ворот В13 не останавливал группу процессов. Текст отказа вложенной машины (`текст_отказа`) движок в событие «сбой» не передаёт, поэтому данное остаётся пустым, как в рукописном автомате методики.

## Вход

| имя | тип | примечание |
|---|---|---|
| сессия | строка | код запускаемой сессии: s1, s1_fix, s3, s3_fix, s5, s5_continue, s5_fix, s7, s9, commit, push (раннер) или проверка и правка (проверка цикла) |
| источник_запуска | ?строка | источник правок: ссылка на файл, текст с источником ответа или решение владельца; нет — не передаётся |
| фаза | ?строка | фаза цикла задачи для выбора профиля; у вызова из проверки цикла не передаётся |
| заход_запуска | ?число | номер захода файла проверки; только у сессий проверки цикла, у вызова из раннера не передаётся |
| папка_задачи | строка | папка задачи |
| рабочее_дерево | строка | рабочее дерево кода |
| режим_сдачи | строка | способ сдачи |
| маршрут | строка | маршрут задачи: full или fast |
| перечень_источников | ?строка | перечень источников из постановки быстрого маршрута; нет — перечня нет |
| сдача_сжата | булево | сжата ли сдача |

Инварианта входа нет. Идентификатор запроса вызова (`запрос_вызова`) во входе не лежит: его даёт исполнитель.
