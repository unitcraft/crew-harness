# ADR-0005. Пульт владельца — свой, в браузере

## Контекст

Владелец, 2026-10-07: «делаем свой продукт, картинки можно будет вставлять, agent view надо самим писать или есть что-то
готовое красивое?». Панель фоновых агентов Claude Code есть только у Claude; у Codex и Kimi — нет. Владельцу нужны
ворота методики (утверждения, ответы, решения), доска задач, разговор с агентом.

## Варианты

1. **Окно OpenCode** (как сейчас). + привычно. − держит нас в OpenCode (ADR-0004).
2. **Панели вендоров** (agent view Claude Code и т.п.). + готово, красиво. − у каждого своя, наших ворот и правил нет.
3. **Пульт Agent Orchestrator.** + готовая доска, терминал. − наши ворота, приёмка, очередь — чужеродны.
4. **Свой пульт в браузере**, его отдаёт сервис на `localhost`. + один на всех агентов, ворота методики — родные. −
   писать самим.

## Решение

Вариант 4. Доска («работает / ждёт вас / на приёмке / готово к вливанию»), карточка задачи (история, шаги, письма),
ворота, живой терминал агента (`xterm.js` + PTY сервиса), чат с агентом по его машинному потоку, вставка и
перетаскивание картинок. Страница — HTML от сервера и немного скриптов.

## Последствия

- \+ Работа без окна OpenCode; один пульт на любых агентов.
- − Объём работы; терминал и чат для каждого агента — свои разборщики потоков. Живём так: пульт тонкий (HTML от
  сервера), разборщик потока — часть драйвера агента, а не пульта.

## Границы

Пульт не хранит состояние сам — только показывает и передаёт решения сервису.

Когда пересмотреть: готовый пульт (свой у вендора или у оркестратора) даёт подключить наши ворота и приёмку без
переделки.
