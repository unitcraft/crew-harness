# ADR-0010. Ответ на вопросы сессий по рекомендации: настройка проекта по типам вопросов, ворота за владельцем

## Контекст

Задача [007](../../tasks/007-question-answering/): на каждый вопрос сессии ждёт владелец, хотя у большинства вопросов есть
рекомендация сессии, и он отвечает «по рекомендации». Методика отдаёт ответ человеку: ворота В4, В6, В7 стоят на нём.
Владелец, 2026-10-08/09: нужна настройка, как отвечать — владелец, по рекомендациям, другой агент; ворота остаются за владельцем
при любом режиме; режим «другой агент» вынесен в отдельную задачу; при доле закрытых вопросов ниже трети — остановка приёмки с
решением владельца.

## Решение

- Ключи проекта `answer_mode` («тип → режим»; режимы `owner` и `recommendations`, по умолчанию `owner`) и `answer_max` (предел
  автоответов подряд, по умолчанию 3). Ключи ставит только человек (правка файла и коммит); `crew_config set` их отвергает.
- Вопрос объявляет `Тип:` (`requirements`, `plan`, `implementation`, `gate`), `Рекомендация:` и `Автоответ: допустим`; «?» в
  конце строки. Закрыт вопрос только при всех условиях сразу; сомнение, сбой разбора, тип `gate`, слова ворот в тексте, сессия
  приёмки и исчерпанный предел — владельцу.
- Запись ответа — файл журнала `answers/` и событие задачи; письмо автоответа служебное («не слово владельца»); отзыв — слово
  владельца; показ — раздел «Автоответы» в `/crew`.
- Общее правило (источник ответа записывается, решения из закрытого списка у человека, ответ по настройке не сбрасывает потолок
  заходов) записано в методике (`methodology.md`, раздел 18, «Кто отвечает на воротах»); здесь — настройка проекта.

## Последствия

- \+ Владельца не ждёт вопрос с рекомендацией, объявленным разрешением и без касания ворот; без ключей поведение прежнее.
- \+ Каждый автоответ записан и отзывается словом владельца.
- − Доля закрытых вопросов мала (по замеру 20 % при пороге в треть): слова «потому что …» в рекомендации часто сами называют
  ворота, и вопрос уходит владельцу — цена принята; приёмка останавливается по порогу.
- − Словарь слов ворот открытый, полноту не гарантирует; безопасность держат три слоя, а не словарь один.
- − Отступление от методики: рекомендация закрывает вопрос без слова человека; ручной цикл судится приёмкой, механизма нет.

## Границы

Не касается ворот владельца (утверждение спецификации и плана, пуши, слияния, удаления, перезапуск службы, живая проверка), ключа
`plan_approver`, режима `agent` (отдельная задача), расширения `endsWithQuestion`, правил пуша, слияния и удаления, показа хода,
профилей моделей. Плагин ключи `answer_*` не пишет.

Когда пересмотреть: доля закрытых вопросов остаётся ниже трети после двух задач; автоответ закрыл вопрос ворот (дефект
безопасности — сразу); понадобится режим `agent`.
