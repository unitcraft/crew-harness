# ADR-0012. Версия основы Канона и явный переход активных задач

## Контекст

Плавающая внешняя основа не должна тихо менять основания проверок уже начатой задачи.
Владелец, 2026-10-16, question «061 В-01 — версия»: «А: на старте (Recommended)»;
question «061 В-01а — дрейф»: «А: сверить заново (Recommended)».
Владелец, 2026-10-18, чат оркестратора: «бери тот коммит, по которому шёл 061»;
«методика постоянно будет в работе, нет смысла её ждать»; question «061: разрешение переноса»:
«Перенос + Sol (Recommended)», передано оркестратором по слову владельца
«проверь сессии opencode, есть ли вопросы, ответь по своей рекомендации».

## Варианты

1. **Плавающая main для всех задач.** + нет отдельного выбора версии. − прежние проверки невоспроизводимы,
   активные задачи переходят без явного полномочия; противоречит выбранной политике.
2. **Версия на старте и явный переход.** + основание проверок и источник перехода прослеживаются.
   − старые задачи остаются на старой версии; drift требует сравнения и повторных ворот.

## Решение

Вариант 2. Политика и полномочия — [process.md](../process.md), «Версия и переход»;
основа Канона — [README](../README.md), «Параметры для раннера».
Принятое основание результата061 — `a449bd2e218e04384d1d42e0c1bffe892495e298`, без смены pin061.
Для этой задачи новое слово владельца 2026-10-18 разрешает завершить перенос на a449, не ожидая последующих
изменений upstream. Это конкретное исключение061, не отмена общей политики для других задач.
Внешние нормы применяются по своим условиям, не пересказываются новым слоем проекта.

## Последствия

- + Старые pins, журналы, серии и утверждения сохраняют основание; норма и практика не смешиваются.
- − Нельзя считать любой подготовленный пакет актуальным навсегда: общая политика требует сравнения drift и новых ворот.
- − Применение внешней нормы не доказывает программную реализацию; границы ручного цикла остаются явными.
- − Literal требование061 ждать latest не исполнено как прежде: исключение и затронутые критерии отражаются в отчёте результата,
  а прежние утверждённые документы не переписываются.

## Границы

Не разрешает массовый переход задач, изменение принятых ADR, новый формат/JSONC/каталог, правки approved031,
возобновление045/013 или отменённой приёмки, изменение кода/config/AGENTS/моделей, main/push/live/restart.
Не заменяет независимую проверку перенесённого результата и не объявляет её исполненной.
Первый любой перенос результата сопровождается current тем же шагом; указатель не содержит нормы.

## Уточнение: pin основы Канона, 2026-10-19 (владелец)

**Уточнение, 2026-10-19 (владелец).** Основа Канона переведена с `a449bd2e` на
`744e0af34dc9c7f9d4db2a91e312ee170c6642fd` — коммит `main` методики от 2026-10-19 05:22 (+03:00); коммит есть в `main`
репозитория методики (проверка `gh api`, 2026-10-19). Причина — слова владельца: чат оркестратора, 2026-10-19:
«догони методику сейчас»; правило владельца, 2026-10-16: «на каждый push методики считать дельту и править Канон»
(по тексту задания задачи [103](../../tasks/103-canon-methodology-sync/)). Между pin — 306 коммитов; дельта посчитана построчно по
корневым файлам методики и индексу `state-machines/README.md`, её таблица — в папке задачи 103 (происхождение, не норма).

Что вошло в Канон по дельте: новый pin и ссылка на индекс стейт-машин методики ([README](../README.md)); параметры проекта для
опытных норм «вратарь», «маршрут задачи» ([README](../README.md), «Параметры для раннера»); раздел «Опытные нормы методики»,
число ворот В1–В15 и код «Св» вместо «Ф» ([process.md](../process.md)). Новых правил проекта дельта не породила: опытные нормы
(вратарь и усиленный вратарь, маршрут задачи, предположение вместо ожидания, потолок доказательства) названы так, как их называет
методика, и приняты по ссылке, без пересказа.

| 2026-10-18 | `a449bd2e218e04384d1d42e0c1bffe892495e298` | результат задачи 061 (решение выше) |

Что это не меняет: начатые задачи остаются на своих pin из `log.md` и переходят только явной записью ([process.md](../process.md),
«Версия и переход»); принятые ADR не переписываются; прежнее исключение 2026-10-18 касалось только задачи 061 и исполнено.
Следствие нового pin: промпт С4 содержит проверку предпосылок плана (п. 7), которой на `a449bd2e` не было, — задача, начатая
на новом pin, проверяется с ней, начатая раньше — по своей версии. Цена: каждое следующее обновление основы — новая дельта и
новая строка таблицы; опытные нормы практикой не подтверждены и могут измениться в методике.
