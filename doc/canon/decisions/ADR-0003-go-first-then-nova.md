# ADR-0003. Сервис на старте — на Go, с правилами под перенос на Нову

## Контекст

Владелец, 2026-10-07: «целевая схема — язык Нова, но сейчас на старте можно для скорости написать — предложи на чем,
чтобы затем по максимум было удобно портировать на Нова». Нова (https://github.com/nv-lang/nova): статические типы,
объявления `name type`, суммы-типы и `match`, `Option` вместо null, `Result`/`Fail` вместо исключений,
алгебраические эффекты с обработчиками, волокна + `Channel` + `select` без `async`, сборщик мусора, нативная сборка;
HTTP — во внешних пакетах; компилятор пишется на самой Нове (самохостинг).

## Варианты

1. **TypeScript** (как плагин). + логика плагина переносится почти как есть. − `async`/`await` повсюду, исключения,
   нетипизированные объекты — перенос на Нову труднее всего.
2. **Go.** + горутины/каналы/`select` без `async` ≈ волокна Новы; объявления `name type`; ошибки значениями;
   сборщик мусора; один нативный бинарник, Windows. − нет сумм-типов и эффектов — их надо имитировать дисциплиной.
3. **Rust.** + суммы-типы, `Result`. − заимствования и `async` на Нову не похожи; медленнее писать.
4. **Сразу Нова.** + без переноса; HTTP-сервер есть (пакет `http` поверх `std.net`, с SSE). − процессы — только
   «запустить и дождаться кода возврата»: нет потоков ввода-вывода дочернего процесса, pid, остановки, PTY; мало
   зрелых библиотек; скорость старта ниже.

## Решение

Вариант 2, с правилами написания:

- эффекты — интерфейсы Go, передаются параметром; без глобальных `os.*`, `time.Now` вне реализаций эффектов;
- суммы-типы — запечатанный интерфейс и `switch`; без `nil` как «нет значения»;
- ошибки — значения; `panic` — только «не может быть»;
- конкурентность — горутины, каналы, `select`, `context`;
- данные — простые записи и JSON-файлы; без рефлексии, кодогенерации и «магии» фреймворков;
- логика — чистые функции над состоянием, ввод-вывод по краям.

## Последствия

- \+ Перенос на Нову — по модулю, почти построчно; тестовые подделки становятся обработчиками эффектов.
- − Логику плагина нельзя взять как есть: переносится по смыслу, с тестами — поведение плагина фиксируют его тесты.
- − Дисциплина правил не проверяется компилятором Go: её проверяет ревью (С6) по списку правил выше.

## Границы

Браузерная часть пульта — JS в любом случае (Нова собирает только нативные программы); она держится тонкой.
Срок переноса на Нову — отдельная задача.

Когда пересмотреть: у Новы появились потоки ввода-вывода дочернего процесса, управление процессом (pid, ожидание,
остановка) и PTY (POSIX и ConPTY на Windows) — то, без чего сервис не держит агентов, — тогда задача переноса; или
правила выше не удаётся держать без ломки кода Go.
