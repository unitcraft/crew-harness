# Канон

**Канон** — всё, где записаны правила разработки CrewHarness (владелец, 2026-10-07); «слой канона проекта» в терминах
методики. Канон — единственный источник истины: код расходится с Каноном — это находка, а не повод тихо поправить
одно под другое; спор с Каноном — только новым решением в [decisions/](decisions/README.md).

| Часть Канона | Где |
|---|---|
| Методика — основа | [unitcraft/ai-dev-methodology](https://github.com/unitcraft/ai-dev-methodology/tree/main), по ссылке, без копии |
| Отличия и дополнения к методике | [process.md](process.md) |
| Правила репозитория и машины | [AGENTS.md](../../AGENTS.md) — в корне, потому что агенты читают его оттуда при старте |
| Решения (ADR) | [decisions/](decisions/README.md) |
| Планы с подпланами | [plans/](plans/README.md) |
| Утверждённые спецификации задач | `spec.md` со статусом «утверждено» в [doc/tasks/](../tasks/README.md) |
| Документация частей | README корня и частей (`opencode-plugin/README.md` и т.д.) |

Не Канон: черновики (статус «черновик»), проверки по заходам, журналы задач, исследования ([doc/research/](../research/)).
Новая часть Канона появляется здесь тем же коммитом, что её заводит.
