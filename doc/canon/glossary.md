# Словарь Канона

Часть Канона проекта ([состав Канона](README.md)). Одно название на одно понятие (владелец, 2026-10-09: «не должно быть
нескольких названий одного и того же, сверься с индустрией»). Решение и варианты —
[ADR-0011](decisions/ADR-0011-one-name-per-concept.md).

Колонки «Индустрия» — ориентир, а не источник: названия взяты по общей практике CI/CD, трассировки и управления
проектами, единого русского слова для части понятий нет.

| Понятие | Название в Каноне | Индустрия (англ.) | Индустрия (рус.) |
|---|---|---|---|
| Крупный отрезок цикла: РАЗБОР, ПЛАН, РЕАЛИЗАЦИЯ, СДАЧА, ОБРАТНАЯ_СВЯЗЬ | фаза | stage, phase | стадия, фаза |
| Пара «проверка ↔ правка» одного артефакта | цикл проверки | review loop | цикл ревью |
| Один проход проверки (`review-3.md`) | заход | iteration, round | итерация, раунд |
| Выполнение одного промпта методики (С1 … С9, их правки и продолжение) | сессия | job | задание, запуск |
| Строка о выполненной сессии в `usage.log` | запись о сессии | record | запись |
| Признак, по которому сессии группируются в сводке (С1, С2, …) | вид сессии | step name, role | вид работы, роль |
| Сумма по сессиям одной фазы | итог по фазе | aggregate | итог, агрегат |
| Нумерованная строка раздела «План» `plan.md` | пункт плана | task, work package | задача плана, пакет работ |
| Остановка, где решает человек (В1 … В13) | ворота | gate | ворота качества, контрольная точка |
| Перенос проверенной ветки в `main` | слияние | merge | слияние |
| Право на слияние, которое держит одна сессия | замок слияния | merge lock | блокировка слияния |
| Проверка кандидата до взятия замка | предпроверка | pre-merge check | проверка перед слиянием |

Слово «этап» в Каноне не используется: в индустрии это stage, то есть наша фаза, а в русских стандартах (ГОСТ 19.102)
этап лежит внутри стадии. Три прежних смысла слова названы заново: этап проверки — цикл проверки; этап набора моделей
(разработка, планирование, приёмка, приёмка плана) — роль в наборе; этап плана эпика — пункт плана, то есть дочерняя
задача.

Слово «шаг» оставлено за единицей счёта внутри сессии и за шагами алгоритма методики; пункт плана «шагом» не называется.

**Прежние слова.** В тексте методики и в уже написанных документах задач стоят прежние слова: этап проверки, шаг плана,
вливание, замок вливания. Они читаются как их замены из таблицы; написанное не переписывается. Новые тексты — только
новыми словами. Машинная строка `шаг <n>: сделан` в `result.md` остаётся, пока раннер и страж не научатся читать
`пункт <n>: сделан` рядом с ней; после этого допустимы обе формы, как и в журналах с датой.
