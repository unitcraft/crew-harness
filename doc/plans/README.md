# Планы opencode-peers

Здесь только планы: что делаем, в каком порядке и как проверяем, что сделано. Справка для
пользователя — в [README](../../README.md) и `peer_help`; история — в git.

## Правила плана

Формат взят у планов Nova (`nv-lang/nova/docs/plans`) и поправлен там, где он мешал.

1. **Один файл — один план**, `NNN-<slug>.md` (три цифры с ведущими нулями), подпланы через
   точку: `001.1-<slug>.md`, заголовок `# План 001.1 — <о чём>`. Номер — порядок заведения, не
   очерёдность работы.
2. **Самодостаточность.** «Выполни план NNN» должно хватать: цель, решения, фазы, проверка — в
   файле, без чтения переписки.
3. **Шапка из трёх строк:**
   - `**Статус:**` ЧЕРНОВИК / ОТКРЫТ / В РАБОТЕ (Ф.N) / ЗАКРЫТ — с датой. Это единственное место
     статуса; сводных таблиц статусов нет нигде (они протухают);
   - `**Где остановились:**` — одна-две строки для того, кто подхватывает: последняя
     сделанная фаза, что следующее, что мешает;
   - `**Проверено:**` — чем подтверждён статус (тесты, живая проверка, коммит). «Числится
     сделанным» без проверки не пишется.
4. **Решения — таблицей**: что решено, кто решил (владелец / интегратор / замер), когда. Отменённое
   решение не стирается, а помечается «отменено решением №…» — иначе через неделю непонятно,
   почему сделано так.
5. **Фаза закрывается только критериями приёмки**, записанными до работы: что проверяется,
   каким тестом или замером, и какая **красная проба** (намеренная поломка) этот тест валит.
   Заглушка или TODO фазу не закрывает.
6. **Замеры, а не догадки.** Поведение OpenCode, на которое опирается план, — замер с версией и
   датой (`OpenCode 2.0.22, 2026-10-05`). Догадка помечается словом «не проверено».
7. **Чего в плане нет:** рабочих журналов, хроники «что пробовали» (это git и коммиты),
   повторов из других планов (ссылка вместо копии).
8. **Закрытие плана:** все фазы закрыты, README и `peer_help` описывают новое поведение, план
   переходит в ЗАКРЫТ с датой и коммитом; открытые хвосты уезжают в раздел «Хвосты» следующего
   плана или в новый план.
