# План 005 — очередь машины для тяжёлых команд

**Статус:** ЗАКРЫТ 2026-10-05 (проверка у владельца — по первым гейтам через очередь).
**Где остановились:** сделано; включается, когда плагин перезагрузится (OpenCode перегружает плагин при изменении его
файлов) и когда окна начнут ставить гейты через `peer_watch {machine: true}` — это правило проекта, его вносит
интегратор nova.
**Проверено:** `test/peers-watch.test.mjs` (п. 5; красная проба — без предела), `peers-mcp`, `peers-cfgtool`.

## Цель

Тяжёлые прогоны окон (гейты, сборки, полные тесты) не идут разом. Случай 2026-10-05: три воркера и два приёмщика
гоняли гейты одновременно с CI-повтором интегратора — машина владельца «сильно загружена», сервер OpenCode повис
(ни записи в журнале с 18:19, обрыв связи окна) и перезапустился в 18:26.

## Решения

| № | Решение | Кто | Дата |
|---|---------|-----|------|
| 1 | Очередь машины — у плагина: `peer_watch {command, machine: true}` ждёт места; мест в проекте — `machine_slots` (по умолчанию 1, 0 — без предела) | владелец («да») | 2026-10-05 |
| 2 | Слово `machine`, а не `heavy`: `heavy` — ступень модели (Opus), а здесь нагрузка на машину | владелец | 2026-10-05 |
| 3 | Очередь — по времени постановки; предел `minutes` — от запуска; письмо по концу говорит, сколько команда ждала очереди | Claude | 2026-10-05 |

## Как устроено

`watch.ts`: задание с `machine: true` и проектом окна. Проход плагина берёт задания по порядку имён (они начинаются
со времени постановки); тяжёлое задание запускается, только если в его проекте работает меньше `machine_slots`
тяжёлых, иначе остаётся в очереди (`*.req.json`). `machineQueue(project)` — очередь; `peer_watch` отвечает «перед ней
N», `peer_watch` без команды и сводка `/peers` показывают «в очереди машины с HH:MM». Обычные наблюдения и тяжёлые
команды других проектов очереди не ждут.

## Что за пределами плагина

Очередь работает, только если окна ставят тяжёлые прогоны через неё, а не в своём Bash. Это правило проекта:
интегратор nova вносит его в правила окон и шаги приёмки («гейт и gate-novac — через `peer_watch {machine: true}`»).
