# Задание: служба координации I — задачи, приёмка, замок слияния, уборка, сводка, настройки

Заказчик и владелец: владелец репозитория `unitcraft/crew-harness` (он же отвечает на вопросы и принимает результат).
Репозиторий кода: `unitcraft/crew-harness` (https://github.com/unitcraft/crew-harness, ветка `main`). Дата задания: 2026-10-10.
Эпик: [001-crew-service](../../001-crew-service/) (дочерняя задача «служба координации I»). Закрывает требования эпика: REQ-01, REQ-02, REQ-03,
REQ-04, REQ-05, REQ-12, REQ-14; сценарии AC-02, AC-03, AC-04; границы DNC-01…DNC-04 действуют. Источник:
[спецификация эпика](../../001-crew-service/spec.md), [следование](../../001-crew-service/spec-trace.md) (D-17), решения владельца 2026-10-09 в
[журнале эпика](../../001-crew-service/log.md).

Задача полная: разбор, план, реализация, сдача.

## Чего хочет владелец (его слова, 2026-10-10)

- «по рекомендации, но раннер на паузе» — разбиение эпика одобрено; эта задача не зависит от раннера.
- Решение 2026-10-09: один исполняемый файл с подкомандами (`crew serve`, `crew mcp`); остальные модули сервиса — по ADR-0003
  (Go на старте) до уточнения владельцем; основной путь MCP — HTTP в сервисе.

## Что есть сейчас

- Правила задач, приёмки, замка слияния, уборки и сводки работают в плагине `opencode-plugin/` (`core.ts`, `tasks.ts`, `review.ts`,
  `precheck.ts`); вне OpenCode их нет. Плагин продолжает работать для проектов-пользователей до их переезда (DNC-01).

## Что нужно

- Перенос правил с тестами в службу: задачи (номер на проект, приоритеты, очередь, лимиты), приёмщик не автор и не исполнитель, замок
  слияния с предпроверкой без замка, уборка веток и деревьев с проверкой, сводка «кто чего ждёт», настройки проектов из
  репозитория настроек.
- Тесты — те же сценарии, что у плагина, записанные данными, чтобы их мог прогнать любой язык реализации.
- Хранилище: вопрос эпика В-09 (то же, что у плагина, или своё); решение — в разборе.

## Что надо выяснить в разборе

- Язык реализации (Go по ADR-0003) и правила кода REQ-40 эпика; какие из правил плагина переносятся один в один, какие меняются из-за
  выхода из OpenCode.
- Хранилище и синхронизация файлов и базы (вопрос эпика В-09 с рекомендацией эпика).
- Как служба и плагин делят данные, пока плагин жив (DNC-01, DNC-02).

## Связи

- Зависит от: [018-agent-survey](../../018-agent-survey/) — выбор транспорта MCP и возможности CLI; решения по хранилищу эпика
- Блокирует: координацию II и III, драйверы
- Пересекается (файлы): `service/` (новое), `opencode-plugin/` — только чтение; журнал эпика
- Начинается после: слияния 018 и ответа владельца по хранилищу (В-09)

## Границы

- Плагин `opencode-plugin/` не меняется (DNC-01, DNC-03, DNC-09); репозитории проектов-пользователей только читаются.
- Раннер методики (задача 013 и оболочка) на паузе по слову владельца и этой задачей не затрагивается.
- Машина общая и нагруженная: тяжёлые прогоны — по одному ([AGENTS.md](../../../../AGENTS.md)).
