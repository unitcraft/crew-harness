## Что нужно

Цель одной фразой: три внешние функции по ролям вместо одной с таблицей «по роли».

1. `parse_witness_reply` → `[]WitnessAnswer`; `parse_author_reply` → `EditResult`; `parse_lens_reply` → `LensResult`.
2. Таблица «по роли» из реестра уходит; реестр хозяина получает три строки.
3. Сценарии: ключ `host` отвечает по имени примитива, поэтому в сценариях (83 сценария `agent-step` и др.) имя `parse_agent_reply` заменяется нужным из трёх — скриптом, а не вручную; скрипт вне репозитория, отчёт о замене (число сценариев, число замен) — в журнал.
