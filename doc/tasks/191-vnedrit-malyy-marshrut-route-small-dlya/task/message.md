# Задание: Внедрить малый маршрут (route small) для правок по фразе вла

Заказчик: crew-harness.integrator; задание собрано плагином из полей crew_spawn.
Репозиторий: проект crew-harness, ветка main. Дата задания: 2026-10-25.
Источник: слова владельца с датой — раздел «Чего хочет владелец».

## Чего хочет владелец

- «сделай X, я проверю» / «сделай X, я сам проверю» сами выбирают малый маршрут и назначают проверяющим владельца, без вопросов; главное — быстро (владелец, 2026-10-25, чат Методики; норма — п. 8 расширения «Соразмерности исполнения», Методика, ветка overhead-budget, SHA пришлют после публикации)

## Что нужно

1. Внедрить малый маршрут (route small) для правок по фразе владельца «сделай X, я (сам) проверю»: вход по фразе, таймер, тестовый контур.

## Критерии приёмки

1. ПЛАГИН: маршрут small (поле route задачи), создаваемый crew_task по вызову: папка задачи из шаблона 3 строки (что; T одной строкой; слова владельца дословно), без слота reviewer, приёмка = слово владельца на тестовом контуре. 2. ТАЙМЕР: метки «слово владельца» (время сообщения) → «ссылка на контур выдана» пишутся в журнал задачи автоматически (плагин ставит, воркер не пишет вручную), отношение к 10 минутам в строке. 3. ТЕСТОВЫЙ КОНТУР КАК КОМАНДА: scripts/test-contour (ps1+sh) — экземпляр пульта управления из дерева задачи на свободном порту (конфиг web_dir на src/web дерева задачи, свой data_dir, порт 8100+), печатает ссылку; сборка hub/front только если задача серверная (иначе бинарники основной копии); останавливается по команде. 4. КАНОН (doc/canon/process.md + при необходимости ADR) — перевод нормы Методики после её SHA отдельным коммитом, не молча. 5. ПИЛОТ: следующие пять малых задач сверять с 10 минутами и показывать владельцу таблицу (слово → ссылка, T оценка/факт, что вышло за 10 и почему). 6. Приёмка этой задачи — одна итоговая (воркер + проверка оркестратора), без этапных. Бюджет обвязки самой этой задачи ≤2× работы (она не малая).
