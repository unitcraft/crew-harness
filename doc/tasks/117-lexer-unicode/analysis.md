## 1. Что сделано

- **AC-1, байтовые смещения.** `tx_chars`, `tx_slice` и `tx_cp` удалены. Место в строке — байтовое смещение: `tx_at(s, at)` декодирует символ на смещении, `len_utf8()` — его ширина, срезы `s[from..to]` берутся только в точках обхода (границы символов). Столбец ошибки по-прежнему в буквах: он ведётся вместе со смещением (`tx_cols(s, from, to)` = `s[from..to].chars().count()`), без копирования строк. Переписаны `tx_lex`, `tx_cell`, `tx_split_cells`, `kv_head`, `is_call_start`, `prose_key_of`, `expansion_name`, `tx_classify_in` (`lex.nv`), `kv_read`, `header_norm` (`doc.nv`), `header_line` (`lang.nv`), `trim_end_blanks`, `normalize_definitions` (`defs.nv`: метка порядка байтов — `starts_with("\u{FEFF}")`), `tx_distance`, `tx_lower`, `tx_translit` (`names.nv`), `state_hint` (`event.nv`), `looks_like_type` (`parse.nv`), `snake_of` (`decl.nv`), читатель типов `RnTy` (`render_expr.nv`) и читатель JSON `RjP` (`rj.nv`). `TxEntry.colon` и `TxKvHit.colon` теперь байтовые смещения; `indent`, `shift` и столбцы остались в буквах. Все 162 прежних теста юнита `machine_text` и тесты остальных юнитов зелёные без правки ожиданий (правились только вызовы: `tx_distance` принимает строки, тестовый помощник `line_literals`).
- **AC-2, буквы по Юникоду.** `tx_is_letter` (ASCII-буквы, `_`, выше U+007F — `char.is_alphabetic()`), `tx_is_upper`/`tx_is_lower` (`is_uppercase()`/`is_lowercase()`), `tx_is_space` (пробел, табуляция, `is_whitespace()`), после первой буквы имени — цифра `0-9` и сочетающий знак (`Mn`, `Mc`). Имена греческие, немецкие (`größe`, `Größe`, `ÄRGER`), китайские (`数据`), иврит, деванагари, хангыль, четырёхбайтные (`𝒜`) принимаются лексером; `looks_like_type` различает тип и константу в любом алфавите с регистром (`Größe`, `Ärger`, `Δείγμα` — типы; `ÄRGER`, `ΔΕΙΓΜΑ` — нет; китайский — ни верхний, ни нижний, не тип). Круг `md → JSON → md → JSON` проверен на лямбда-параметре, имени `пусть`, имени данного автора (русский и английский файл) и на машине с состояниями на греческом, немецком, китайском и смешанном (`src/machine_text_unicode`): JSON равен, у машины с переименованными состояниями JSON равен JSON исходной машины.

## 5. Решения и расхождения

- **`colon` — байтовое смещение**, а не индекс в символах (в задании «позиции — байтовые смещения»); единственный прежний тест на `colon` использует ASCII-ключ, ожидание не менялось.
- **Цифры и число.** После первой буквы имени — только ASCII-цифры; добавлены сочетающие знаки `Mn`, `Mc` после буквы (разложенная форма `ö`).
- **Неразрывный и идеографический пробелы** теперь пробелы (раньше — «недопустимый знак»): следствие `is_whitespace()` по заданию.
- **Регистр JSON-имени.** `tx_translit` приводит к нижнему регистру любую букву, поэтому имя данного из заглавных (`ΔΕΙΓΜΑ`, `ÄRGER`) в JSON строчное, и обратная запись даёт строчное имя; круг по JSON равен. Так и раньше было для кириллицы.
- **Правила таблиц не менялись:** имена данных, типов и сторон по-прежнему из словаря или латинское имя рядом (раздел 1а); «имена на любом языке» — лексер, регистр, `tx_lower`/`tx_translit`, лямбда-параметры, `пусть`, данные автора во фрагментах, названия состояний.
- **Тесты не меняли ожиданий.** Правились только вызовы и тестовый помощник `line_literals`.
