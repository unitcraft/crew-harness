## Решения

1. **Образец Методики и продукт.** Продукт держит поле остатка транспорта в типах ответа как `usage` (сценарии и движок говорят `usage`), образец Методики пишет `transport_usage`; таблица продукта `agent_step.alula.txt` — образец Методики 2.14 плюс ключи проекта плюс `расход (usage)` в пяти типах ответа. Английский образец с теми же правками (`en_keyed`) равен продуктовому дереву с точностью до внутренних имён.
2. **Имена вложенных машин** (`шаг_агента`) Методика JSON-именем не снабжает; имя берётся из реестра хозяина `names_host.tsv` (`machine`), латинское читается само. Вопрос Методике: как нелатинское имя вложенной машины получает JSON-имя.
3. **Поле с двумя JSON-именами.** Образец «Совещание» пишет `утверждение (statement)` и `утверждение (claim)` в разных типах и `находки (findings)` / `находки (lens_findings)`. Переводчик находит поле по владельцу (литерал `Тип { поле: … }`, образец `Случай(поле)`, сигнал `имя(поле: …)`); ссылка без владельца (`x.поле`, строка таблицы запроса) на такое поле — ошибка «объявлено в машине с разными JSON-именами». Следствие: запись «Совещание» читается целиком, кроме двух мест с `находки` без владельца. Вопрос Методике: как ссылка на такое поле называет владельца (тип выражения переводчику неизвестен).
4. **Образец «Совещание»: заглушки.** Четыре параметра имеют значение `0 (заглушка источника)`: это не значение выражения. Тест убирает примечание в скобках перед разбором, больше ничего не меняет; числа Методики (30 состояний с состоянием фрагмента — 29 заголовков `###`, 67 строк переходов, 12 строк концов, 29 данных, 22 примитива) считаются по тексту.
5. **Пустые значения.** `Запрос: нет`, `Читает: —`, `Срок тишины: —`, `При входе: —` — ошибка с названием правила (иначе файл 2.12 читался бы молча); настоящие умолчания (`Срок тишины: 0`) читаются.
6. **Имена в деревьях.** Внутренние имена (константа, параметр, определение, сторона, привязка) входят в дерево как написаны, кириллицей тоже: деревья русских таблиц и английского образца различаются этими именами (общий круг ru → en → ru равен по тексту и по дереву, а en-образец и ru-образец сравниваются с заменой внутренних имён). Привязки полей сигналов протокола (`автор`, `источник`, `слово_человека`, `идентификатор_запроса`) получают JSON-имя реестра, чтобы фрагмент «Пауза» любого языка давал одно дерево.
7. **`chat.alula.json`** остаётся рукописным (латинские имена сторон); его таблица сравнивается с деревом с поправкой на имена в `chat_test` (`machine_text`), общая проверка «compile даёт JSON продукта» пропускает чат с пояснением.
8. **`ScEvent.party`.** Запись события сценария получила поле `party` (сторона-владелец сигнала; пустое — любая); это изменение API пакета (0.3.0).
9. **Новая проверка стороны сигнала.** Шаг `signal` сценария с `party` на стороне, не объявившей сигнал, — ошибка сценария; `Incoming.word(...)` остаётся конструктором события вида `Input` (код, не формат).
10. **Не сделано (названо Методикой открытым):** ворота человека как событие без запроса, сигнал стороны без строки в текущем состоянии, две записи `Находка`, общий файл типов вызова; формат 2.15 и позже. Не публиковалось, `push` не делался.
