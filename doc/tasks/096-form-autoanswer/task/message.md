# Задание: плагин сам отвечает на формы встроенного вопросника по рекомендации (answer_mode для форм)

Заказчик: владелец репозитория `unitcraft/crew-harness` (он же принимает результат).
Репозиторий: `unitcraft/crew-harness`, ветка `main`. Дата задания: 2026-10-19.
Источник: слова владельца в чате оркестратора, 2026-10-19; доработка [ADR-0010](../../../canon/decisions/ADR-0010-question-answering-modes.md) и задач [007](../../007-question-answering/), [059](../../059-answer-form-from-outside/), [078](../../078-loop-after-answer/).

Задача полная: разбор, реализация, сдача. Быстрый путь. Основа — свежий `origin/main`. Правки только в `opencode-plugin/`, `doc/canon/decisions/ADR-0010-*` (дополнение) и папке задачи.

## Чего хочет владелец (его слова, 2026-10-19, чат оркестратора)

- «answer_mode: recommendations работает только для текстовых вопросов определённого вида - я был уверен, что это автоответы на вопросники, это упущение, надо доделать».
- «я же тебе говорил отвечать автоматически на вопросы по рекомендациям, почему так получались что какая-то вкладка затормозила на сутки процесс, как исключить такие тормоза без моего участия» — вопросы сессий не должны ждать владельца там, где есть рекомендация.
- «по рекомендации, с учетом выше сказанного тут» — принят пакет: автоответ плагина на формы, правила методики «предположение вместо ожидания» и потолок доказательства.
- Ранее (2026-10-18): «Не должно быть ручных команд там, где их может сделать программа» (AGENTS.md п. 14); ключ `answer_mode` ставит только человек.

## Что есть сейчас (разбор исходного)

- `answer_mode` (ADR-0010) отвечает только на текстовые вопросы-блоки с `Тип:`, `Рекомендация:` и `Автоответ: допустим`. Формы встроенного вопросника (инструмент `question` OpenCode: вопрос, 2–4 варианта, рекомендованный первым с пометкой «(Recommended)») плагин сам не закрывает: ответ ставит оркестратор командой `node scripts/crew-answer.mjs <форма> --option N --quote "…"` по слову владельца; плагин применяет его прерыванием хода вкладки и письмом (`owner-answer.ts`, `form-wait.ts`).
- Итог: вопросы интеграторов, исполнителей и приёмщиков стоят часами, пока оркестратор не получит от владельца «проверь сессии». Расчёт за 2026-10-18: десятки ответов вручную по одной и той же рекомендации.

## Что нужно

1. **Автоответ на формы.** Форма (открытая запись `forms/`, вид `question`, есть варианты) закрывается плагином сам, если одновременно: (а) объединённые настройки проекта (с блоком `local`) дают режим `recommendations` для типа вопроса (тип формы по умолчанию — `default`; если в тексте есть `Тип:` — он); (б) среди вариантов ровно один помечен «(Recommended)» (нет пометки, две пометки, пометка не у первого — владельцу, без догадок); (в) вопрос не из закрытого списка (п. 2); (г) не исчерпан предел `answer_max` подряд для этой сессии; (д) форма не заменена новой и не устарела (повторы и «без ответа после повторов» не трогать).
2. **Закрытый список (остаётся за владельцем при любом режиме):** тип `gate`; ворота методики (утверждение спецификации и плана, пуш в `main`, слияние, удаление и уборка, перезапуск службы, живая проверка); `tag`, выпуск/публикация/asset/pin; `force`, пароль, ключ, токен, оплата, деньги; слова «слово владельца»; изменение ключей `answer_*`; снятие запретов и границ задачи («разрешить … вне границ», расширение объёма). Слова ищутся и в вопросе, и в тексте рекомендованного варианта; список — таблицей в коде с тестами на каждый пункт, расширяется без правки логики. Сомнение (сбой разбора, неоднозначность) — владельцу. Вопросы приёмщиков и интеграторов — НЕ закрыты отдельным правилом (слово владельца 2026-10-19 отменяет прежнее исключение для сессий приёмки); остаётся закрытый список.
3. **Задержка и отмена.** Ответ ставится не раньше чем через `answer_delay_sec` после появления формы (ключ проекта, по умолчанию 60; 0 — сразу; владелец успевает ответить сам, его ответ главнее и снимает автоответ). Ключ ставит только человек, как `answer_mode`; `crew_config set` его отвергает.
4. **Доставка.** Через существующий механизм ответа на форму снаружи (`owner-answer.ts`): письмо вкладке служебное («ответ по настройке answer_mode, не слово владельца»), запись в `answers/` и событие задачи (источник: плагин, режим, вариант, причина разрешения), показ в разделе «Автоответы» панели `/crew` и в `crew_doctor` (счётчик за сутки, последнее закрытие, сколько форм ушло владельцу и по какой причине: закрытый список, нет рекомендации, предел). Отзыв — слово владельца, как в ADR-0010.
5. **По умолчанию выключено:** без `answer_mode` или с `owner` поведение прежнее; включается ключом проекта у человека (у владельца уже стоит `default: recommendations` в блоке `local` для пяти проектов).
6. **Проверки (`npm test` из `opencode-plugin/`, параллельно до 4 файлов):** красная проба до кода — новые тесты красные; тесты: автоответ на форму с «(Recommended)» через задержку; отмена владельцем до срока; каждый пункт закрытого списка → владельцу; нет/две пометки → владельцу; предел `answer_max` и сброс; замена и устаревание формы; режим `owner` и без ключа — как прежде; ключ не пишется плагином; запись и показ; повторный тик не отвечает дважды (идемпотентность);
   «смерть между изменениями» (правило 13/34(е) методики): запись об ответе сделана до прерывания хода, перезапуск между ними не даёт ни повтора, ни потери.
7. **ADR-0010 дополнить** (не переписывать): раздел «Дополнение 2026-10-19» — формы входят в режим `recommendations`, закрытый список, задержка, снятая оговорка про приёмку (слово владельца); обновить README плагина (раздел про ответы) и справку `crew_help`; в `analysis.md` — что замерено по журналу ответов за 2026-10-18 (число ручных ответов по рекомендации и сколько из них не попало бы под автоответ).

## Критерии приёмки

- Форма с «(Recommended)» в проекте с `answer_mode.default: recommendations` закрывается плагином без участия оркестратора и владельца через `answer_delay_sec`; закрытый список, отсутствие рекомендации и предел уходят владельцу; тест на каждую ветку.
- Красная проба до кода показана; полный набор тестов плагина зелёный; стражи — 8 и больше, FAIL 0.
- Ключи `answer_*` плагин не пишет; без ключа поведение прежнее; в `/crew` и `crew_doctor` виден счётчик автоответов и причины ухода к владельцу.
- Коммит по правилам AGENTS.md: английское сообщение, `-s`, без трейлеров, без `#число`, файлы перечнем; в коммите только `opencode-plugin/`, дополнение ADR-0010 и папка задачи.
