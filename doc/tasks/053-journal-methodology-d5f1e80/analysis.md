## 2. Что сделано

- **`progress_line`.**
  - Сессия — от строки запуска (или первой строки) до итоговой. После итоговой той же сессии принадлежат только её повтор с тем же k и ключевым словом и `стоп:` после `готово` при k меньше N.
  - Вторая строка `старт` в открытой сессии отклоняется; старт, которого нет, дописывается сейчас (`0/N старт`), k не сбрасывается.
  - `готово`: k = max(прежний k, n), сравнение с N старта, `9/8 готово` пишется; при k меньше N, без старта и после второго старта — отказ с тремя исправлениями по делу. `готово` с текстом `N завышено: …` — итоговая с тем же k. Написанное руками `готово` при k меньше N итоговой не считается.
  - После `стоп:` единица и `готово` отклоняются — продолжение новой сессией; повтор `стоп:` не меняет вид.
  - Поправка: `to` — начало подписи после времени, 10–30 знаков (короткая подпись — целиком); вся строка отклоняется.
- **Запускающий (письмо оркестратора, 2026-10-15).**
  - Запускающий — вкладка, которая держит исключительную роль integrator своего проекта (замок роли, `holdsExclusive(roleKey(проект, "integrator"), сессия)`), и в её визитке нет task и review — она сама не исполняет и не принимает задачу (`isLauncherCard` в `journal.ts`; `index.ts` передаёт предикат `launcher(sessionID)` в `registerJournalTools`). Сбой проверки — не запускающий.
  - Почему так: роль integrator исключительная, держатель один и подтверждён замком; тем же критерием плагин уже пускает интегратора к его действиям (`isIntegrator` в `core.ts`). Не «автор поручения»: у сессий методики С1–С9 в ручном цикле нет записи задачи плагина, связать вызов с поручением не по чему.
  - `progress_line` вида `launch` от запускающего: сначала пишет в `log.md` запись `ГГГГ-ММ-ДД ЧЧ:ММ пуск: запуск №<n> <код> [ГГГГ-ММ-ДД ЧЧ:ММ]`, затем строку `<код> 0/0 [ГГГГ-ММ-ДД ЧЧ:ММ] запуск №<n>`; n — 1 + наибольший номер в `progress.log` и `log.md` папки (или явно; занятый — отказ); создаёт `progress.log` в существующей папке. Агенту сессии — отказ. `log_line` принимает запись «запуск №…» только от запускающего.
- **Панель:** `finishes` — одна строка старт и (k ≥ N старта или «N завышено»); `готово` при k меньше N не итоговая; строка после итоговой открывает новую сессию; метка `restart` — новый старт при незаконченной прежней сессии без строки запуска между ними; `запуск №3` читается как запуск.
- **Страж:** `journal-fix` — начало подписи после времени прежней строки того же кода, 10–30 знаков; `journal-done` — добавленное `готово` при k меньше N старта, не исправленное по делу; только для журналов, начатых не раньше 2026-10-16 00:00, — `journal-time` (`[ГГГГ-ММ-ДД ЧЧ:ММ]`) и `journal-launch` (`<код> 0/0 [время] запуск №<n>`, номер без повтора, запись в `log.md`).
- **Канон:** ссылка на `ab2a4ef`; «журнал — сигнал, не доказательство»; правила инструмента; граница сессии — `запуск №<n>`, сверенный с записью в `log.md`, пишет запускающий (в ручном цикле — интегратор через `progress_line`); повтор сессии — закрыть прежнее окно и проверить, что процессов нет (ручной цикл и раннер); каждый промпт со строкой «Сессия:» — новая сессия, коды совещания А, Ф, Л1…; существенные исключения по `ab2a4ef`; пропуск единицы — правило приёмки.
- README плагина и тестов — по новым правилам.

## 3. Что не ослаблено

- Время ставит машина, в форме `[ГГГГ-ММ-ДД ЧЧ:ММ]`; строки только дописываются; при отказе ничего не пишется (каждая проба сверяет файл до и после).
- Пропуск и повтор единицы, k больше n, подпись длиннее 80 знаков, вид остановки не из списка — отказ.
- Поправка — только к строке той же сессии и не после итоговой; итоговая исправляется только повтором.
- Агент сессии запуск не пишет ни в `progress.log`, ни в `log.md`; повтор номера — отказ до записи; запись в `log.md` и строка журнала пишутся вместе, страж `journal-launch` их сверяет.
- Страж держит неисправленные длинную подпись и вид остановки; добавлены `journal-done`, `journal-time`, `journal-launch`; ничего не снято.
- **Переход:** страж судит только добавленные строки; `journal-time` и `journal-launch` — только для журналов, начатых не раньше 2026-10-16 00:00. В прежних журналах строки запуска без номера и время `[ЧЧ:ММ]` были законны; дописать номер задним числом — значит переписать историю (силовой пуш запрещён, AGENTS.md, п. 5).
