# Задачи

Работа над CrewHarness идёт по [методике](https://github.com/unitcraft/ai-dev-methodology): цикл сессий
(`task-sessions.md`) под управлением раннера (`task-runner.md`). Одна задача — одна папка `NNN-<slug>/`:

```text
task/                  всё от заказчика как есть (task/message.md — само задание)
task-algorithm.md      копия алгоритма методики, на неё ссылаются промпты сессий
spec.md                спецификация; статус в первой строке («черновик» / «утверждено, дата, кто»)
spec-review-N.md       проверки спецификации по заходам
plan.md                план; статус и базовая ревизия в первых строках
plan-review-N.md       проверки плана
result.md, review-N.md реализация и её проверки
delivery/              тексты наружу
log.md                 журнал владельца: каждый заход и решение
progress.log, profile.log  машинные строки прогресса и профиля запуска
```

Код задачи пишется в отдельном рабочем дереве на ветке задачи; папка задачи меняется в `main` и коммитится на
воротах (утверждение spec, утверждение plan, сдача). Репозиторий публичный: в папке задачи нет локальных путей и
приватных данных.
