# Разбор 083: задачи проекта подписываются одинаково — номером из трёх цифр, независимо от того, есть ли у задачи папка

Задание — `task/message.md`. Источник: владелец, 2026-10-17, чат оркестратора: к скриншоту панели («081 …» рядом с «#22 …») и «по рекомендации» на предложение подписывать все
задачи проекта тремя цифрами без решётки.

## 1. Как места шли к подписи

Раньше `taskNo` (`tasks.ts`) решал по наличию папки: три цифры с папкой, иначе «#N». Задача #22 заведена до задач с папками (065), поэтому панель писала «#22».

- Через `taskNo` уже шли: заголовки сессий (`index.ts`, `idle-tab.ts`), письма, письмо приёмке; запись задачи несёт `project`, правки там не потребовались.
- Склеивали «#N» вручную (теперь берут номер из `taskNo`): `status.ts` (`tabOf`, `tabRef`, колонка «кто», заголовки задач в /crew и панели, строка `lock`; `ref` в
  сводке теперь ставится всегда, для сводок старой версии без `ref` — запасной `refOf`), `profile-cmd.ts` (запасной вариант), `review.ts` (строка «ждут замок», письмо «замок свободен»),
  `precheck.ts` (четыре отказа, строки замка вливания, журнальная строка), `core.ts` (отказы замка, письма о заказе, записи legacy, `sessionLabel`, тексты справки), `index.ts`
  (письмо и уведомление о застое замка, список занятых приёмщиков), `answer.ts` (`taskRef` с проектом и папкой), `mcp.ts` (описание инструмента).
- Не подписи, не менялись: ключи вида `project#n` в `index.ts`/`tui.ts`, адрес `parent: "проект#N"`.
- Чужие проекты не затронуты: у задач без папки `#номер`.

## 2. Правило

`taskNo(t)` — единственное место подписи. Три цифры с нулями слева (22 → «022», больше 999 — как есть, «1000»), если у задачи есть папка или `t.project === "crew-harness"`
(`OWN_PROJECT` = имя ящика плагина из `paths.ts`); иначе `#N`; без проекта и без папки — `#N`. Проект передаётся явно: наличие папки о проекте не говорит. Файлы реестра и
имена папок не менялись. `doc/canon/process.md` — одна фраза о том, что задачи самого crew-harness подписываются тремя цифрами с папкой и без.
