1. **Экран после выбора набора (`use`, и ответ `/crew-sets use …`)** — по макету:
   ```
   Набор «kimi» включён (был «codex»)
   Работа:    k3-256k   (было luna / sol / astra по размеру задачи)
   Приёмка:   k3-256k   (было те же)
   Идущие сессии остаются на прежних моделях (сейчас N: #94, #98…); новые пойдут на k3-256k.
   Контекст модели: 220К, вывод до 131 072 (у codex было 525К).
   ⚠ Приёмка на той же семье, что и работа: проверяет та же модель, что пишет. Другая семья есть: claude.
   Не закоммичено — это локальная настройка проекта.
   ```
   Этапы называются по-человечески («Работа», «Приёмка», «Планирование», «Проверка плана» — точный перечень и слова
   согласовать в разборе с `P.STAGE_RU`), вместо ступеней heavy/medium/light — «по размеру задачи»; если у набора на всех ступенях
   одна модель — одно имя; «было → стало» по каждому этапу (одинаковое схлопнуто); «идущие сессии» — число и номера задач с названием
   (из записей плагина: сессии со сводкой, чья модель не из нового набора; если посчитать нельзя — строка опускается, не выдумывается);
   служебное («файлы окон: записано N, снято M», «приёмка — по рукописным настройкам») — в подробный вид (`show`), в экране только
   если что-то записано или мешает (например, окна не записаны из-за ошибки).
2. **Экран после выбора семьи (`/crew-profiles`, Enter на семье и `show <семья>`)** — по макету:
   ```

     heavy   gpt-6-astra   контекст 525К, вывод 128К
     medium  gpt-6.1-sol   то же
   ```
