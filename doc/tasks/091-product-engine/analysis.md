## 2. Что вошло из методики (state-machine-engine-automaton, коммит 03b93a2)

Правило 6 (типы ровно настолько подробны, насколько по ним ветвится движок); 8 (пишет только исполнитель: машина возвращает выходы, журнал и хранилище пишет движок); 11 частично (шаг читает только состояние и событие — Oracle отказывает при эффекте в `step`: `E_RAW_EFFECT_OP_UNDECLARED`, проверено подстановкой `Time.now()`); 12–13 (повторный вход ничего не шлёт по отправленным запросам; порядок журнал → снимок → отправка; номера шагов без пропусков); 14 частично (ответ проверяется на приходе по открытым запросам); 15 (идентификатор запроса `<сторона>-<попытка>`); 16 (три исхода и закрытый список из 10 кодов, код вне списка → `NoResult`); 17 (чужой и поздний ответ отбрасывается и журналируется); 18 и 22 частично; 31 (конверт в каждой строке журнала); 35 частично.

Не вошло: правила 19–21 и 28 (ворота человека, наборы запросов), 23–24 и 36 (стоп человека, «продолжить», пауза), вложенные машины, «запуск заново», конец ОШИБКА, подготовка при возобновлении, очередь входящих в снимке. Полный список — в `src/engine/README.md`.

## 3. Расхождения с методикой и заданием

1. Открытые запросы к ролям после перезапуска остаются открытыми и ответ принимается (как требует задание); методика велит отменять.
2. Тип `Outcome` назван `Response[R]` (`Answer`/`Refusal`): имя `Outcome` занято прелюдией, свой тип с этим именем ломает C.
3. Состояние машины через протокол — кодированный текст, а не обобщённый тип.
4. Выход `Save` избыточен (каждая фиксация и так сохраняет снимок) — решение: оставить или убрать из `Output`; рекомендация — убрать, когда появится боевой обработчик.
5. Таймаут: событие `Expired` закрывает запрос само, движок сам шлёт `Agent.cancel`.
6. Коды `MaxTokens`, `MaxTurnRequests` добавлены по заданию и пока не порождаются.

## 4. Ограничения Oracle 0.1.0 (воспроизведения в `spikes/env/repro_engine/`, README п. 8–13)

Обобщённая сумма с вариантом `str` не компилируется; пользовательский `Outcome` даёт два `Nova_Outcome` в C; вложенный образец `Some(Answer(reply))` над обобщённой нагрузкой не линкуется; поле записи типа «протокол» нельзя вызывать; обобщённая функция с границей протокола с параметрами типа и выводимыми параметрами даёт неверный C. Обходы описаны; передать интегратору Нова.
