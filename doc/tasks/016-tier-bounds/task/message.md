# Задание: параметры `tier_min` и `tier_max` вместо отдельных наборов ступеней

Заказчик и владелец: владелец репозитория `unitcraft/crew-harness` (он же отвечает на вопросы и принимает результат).
Репозиторий кода: `unitcraft/crew-harness` (https://github.com/unitcraft/crew-harness, ветка `main`). Дата задания: 2026-10-09.
Источник: раздел «Этапы и модель» [методики](https://github.com/unitcraft/ai-dev-methodology/blob/main/task-runner.md) и параметры проекта в [process.md](../../../canon/process.md), набор `codex-light` в `.opencode/crew-harness.json`.

Задача полная: разбор, план, реализация, сдача.

## Чего хочет владелец (его слова, 2026-10-09)

- «сейчас кстати я завел сет codex-light только для того, что ограничить сверху уровень сложности при выборе модели, предлагаю
  добавить отдельный параметр для min\max и не заводить отдельные сеты».
- «согласен» на задачу плагина с двумя параметрами.

## Что есть сейчас

- Ступень модели (`heavy`, `medium`, `light`) задаётся в ячейке набора явно или значением `task` (по весу задачи, ступень выбирается на входе
  `crew_spawn`). Ограничить её сверху можно только отдельным набором, где у каждого этапа явная ступень (набор `codex-light`).

## Что нужно

- Два параметра проекта в `.opencode/crew-harness.json`, группа «Профили моделей» схемы настроек: `tier_min` и `tier_max`
  (`light`, `medium`, `heavy`; без параметра ограничения нет).
- Любая ступень любого этапа — явная, унаследованная и `task` — срезается в границы; срез записывается в журнал и виден в
  `/crew-sets show` (ступень по набору и ступень после среза); `tier_min` выше `tier_max` — ошибка настройки с понятным текстом.
- `crew_config`, справка `crew_help`, README плагина описывают параметры; набор `codex-light` после них не нужен (решение о его
  удалении — владельца).

## Что надо выяснить в разборе

- Порядок ступеней и поведение на краях (`task` тяжелее потолка; явная ступень ниже нижней границы).
- Где виден срез: в ответе команд, в панели, в письме о задаче.
- Нужен ли потолок «по семье» (дешёвый Codex при полном Claude): сейчас одна настройка на проект; решение — по данным использования.
- Как параметры сочетаются с `spawn_models` и `tiers` и с окном контекста профиля.
