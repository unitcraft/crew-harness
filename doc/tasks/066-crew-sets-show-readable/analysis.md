## 1. Разбор

**1.1. Что выводил `show` и где это теперь.** Прежний `showSet` печатал одним полотном заголовок, абзац на каждый из восьми этапов
(клетка, наследование, срез, модели по ступеням, окно), затем ошибки и заметки. Краткий вид — `/crew-sets show [набор]`; подробный —
`show [набор] <этап>`; прежний полный текст — `show [набор] all`.

| Было | Где теперь |
|---|---|
| «Набор «n» — включён (имя в файле проекта)» / «не включён» | краткий: «Набор «n» — включён / выключен»; подробный: заголовок прежний слово в слово |
| имя этапа и клетка «семья/ступень» (`codex/task`) | подробный (`show <этап>`); в кратком клетка не печатается |
| «(унаследован от «X»[, ступенью ниже])» | подробный; в кратком `как «X»`, если три модели этапа не отличаются от исходного, иначе строка моделей |
| «по ступени задачи: heavy → M, medium → M, light → M» | краткий: три колонки (короткие имена) |
| «(срез границами ступеней)», «срез границами ступеней: heavy → medium» | подробный; в кратком уже срезанные модели в ячейках |
| «не описан — модель по spawn_models» | краткий: строка «не описан: по spawn_models»; подробный: прежняя строка |
| «нет профиля» | краткий: ячейка «нет профиля» и строка ⚠; подробный: прежнее |
| «контекст профиля в рабочем дереве задачи (ступень): контекст · ввод · вывод» (разработка, планирование) | краткий: расшифровка под таблицей, по разу на модель; подробный: по ступеням как было |
| «контекст профиля здесь не применяется (приёмка идёт в основной папке): модель M берёт контекст из рукописных и глобальных настроек: … (путь к файлу)» | только подробный (`show приёмка`, `show приёмка плана`, `all`); пути к файлу в кратком нет |
| «окно не применяется: у этапа пока нет сессий» | подробный |
| «! <ошибка набора>» (повисшая ссылка, пустой профиль, конфликт окон) | краткий: строка ⚠, обрезанная до 72 знаков («…»); подробный: полный текст |
| «заметка: «приёмка» идёт на той же семье X, что «разработка»; в справочнике есть другая (Y) — правило проверки…» | краткий: одна строка ⚠, пары одной семьи слиты («все приёмки на той же семье X, что авторы; есть Y»); подробный: полная заметка по каждой паре |
| (не было) модель не найдена в каталоге OpenCode | краткий: строка ⚠ «модели M нет в каталоге OpenCode»; каталога нет — молчит |

Разбор слов в `show`: первое слово — имя набора, если такой набор есть (имя набора главнее одноимённого слова этапа). Дальше этап
(латиница, русское название, `приёмка плана` из двух слов, `accept`) или `all`.

**1.2. Правило коротких имён.** Строка «провайдер/id[#вариант]» превращается в имя так:
1. id без провайдера делится по «-». Если все части — слова из латинских букв или числа-версии, берётся слово модели: единственное
   слово (`haiku`) или второе после марки (`claude-opus-5-5` → `opus`, `gpt-6.1-sol` → `sol`, `gpt-6-luna` → `luna`). Марки —
   `claude, gpt, gemini, kimi, glm, qwen, llama, deepseek, mistral, grok`; слово-уточнение (`fast, mini, nano, pro, turbo, preview,
   latest, thinking, flash, lite, max`) именем не берётся.
2. Иначе (`gpt-5.5`, `gpt-5.5-fast`, `k3-256k`) — id без провайдера.
3. Если у двух разных моделей имя одно, обе переходят на ступень полнее: слово → id без провайдера → «провайдер/id». Перебор
   повторяется до различимости. Вариант (`#high`) добавляется как «·high».

**1.3. Решения по краткому виду.** Ширина 72 (`DIALOG_WIDTH`); ⚠ обрезаются «…», полный текст — в подробном виде. Если у всех
этапов одна тройка моделей — одна строка «все этапы: heavy/medium/light → M». Унаследованный этап с отличающимися моделями
показывается своими моделями без пометки; причина — в подробном виде.

**1.4. п. 6: остальные ответы.** Единый шаблон: первая строка — итог, ниже только изменившееся и ⚠, внизу одна короткая строка.
`use`: «Набор «X» включён (был «Y»); новые сессии пойдут на нём, перезапуск не нужен.», таблица или «все этапы», окна «было → стало»
(без изменений — «окна прежние»), ⚠ предупреждения, последняя строка «Без коммита; файлы окон: записано N, снято M». `off`, правки
(`set`, `unset`, `new`, `rename`, `delete`, `/crew-profiles`) и `check` — тот же вид; все прежние сведения сохранены (длинные пояснения
