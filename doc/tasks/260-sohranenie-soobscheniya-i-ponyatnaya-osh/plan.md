# 260 — сохранение сообщения и ошибки

Ветка: task/260-sohranenie-soobscheniya-i-ponyatnaya-osh

1. Красные тесты: ошибка без `turn` должна быть в ленте; исходящий текст должен сохраняться до отправки, неизвестный исход не разрешает повтор.
2. Локальный журнал исходящих сообщений (по origin пульта), запись до передачи сокету; отсутствие подтверждения и reload означают неизвестный исход, не неотправку. Автоматической повторной отправки нет.
3. Ошибки без хода — отдельный блок; ошибки хода — рядом с ответом, с безопасными подробностями. Возврат текста дополняет, не затирает черновик. Retry доступен только при доказанной неотправке.
4. Сохранение локальных ошибок и черновиков; позднее эхо убирает локальную копию из ленты, не создавая дубликата. При отсутствии корреляции принятие не угадывается.
5. Затронутые тесты, затем полный web-набор и стражи через очередь машины; отчёт независимой приёмке.

Диагностика только read-only. В PostgreSQL найдена «Сессия 3», новых сообщений в журнале нет. Синтетические ошибки хаба не журналируются; точная причина инцидента неизвестна. Старое файловое хранилище не является источником инцидента.
