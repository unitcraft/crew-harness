## Предложение оркестратора, принятое как основа проекта

1. **Один номер.** В проекте с папками задач (`doc/tasks`, имя каталога — настройка проекта, если её нет — выяснить)
   номер задачи — номер папки. Заведение задачи (`crew_spawn`, `crew_task order`) создаёт папку `doc/tasks/NNN-<slug>/`
   (`task/message.md` с заданием, `log.md` с первой строкой) с тем же номером; отдельного счётчика поручений нет.
   В проекте без папок (Нова) номер плагина — номер задачи, как сейчас.
2. **Сессии — без своих номеров.** Исполнитель, приёмщик, доработка, сессии методики (С1, С2, С4…) — части задачи;
   идентификатор сессии — номер задачи + код сессии + номер запуска (`045 С4 №3`), фиксируется в папке задачи:
   `progress.log` (строка `запуск №<n>`), `log.md` (запись о запуске, задача 053), отчёт сессии — файлом в папке.
3. **Подзадача — отдельная задача** со своим номером и папкой; в `task/message.md` первой строкой «Часть задачи NNN»,
   в `log.md` родителя — строка о заведении подзадачи. Правило различения: своя приёмка или отдельное попадание в
   `main` — подзадача; следующий шаг той же работы — сессия.
4. **Одно слово.** «Поручение» уходит из всего, что видит владелец (панель, `/crew`, `/ask`, уведомления, письма,
   описания инструментов, Канон); остаются «задача» и «сессия задачи». Панель группирует сессии под задачей:
   `045 реестры раннера` / `↳ С4-3 исп ✓ сдана`.
5. **Старое не переписывается:** заведённые поручения доживают со старыми номерами.
