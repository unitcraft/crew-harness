ADR и строка реестра честно имеют статус «предложено»: принятие и дата требуют конкретного решения ворот; нельзя применить этот draft и назвать ADR принятым.

ADR-0011 и единый образец задания, правила вопроса на воротах, legacy022, сводка при сжатии и её defaults/ограничения сохранены из target. Номер0012 — свободный кандидат относительно этого exact реестра, не резерв: при будущей коллизии остановиться. Все существующие ADR unchanged. ## Три поля замысла

1. Цель — approved spec REQ-01/02/05/06 и plan шаги1–3, затем отдельно разрешённые4–10. Полная061 должна внести и проверить Канон, не закончиться исследованием.
2. Граница обхода — защита от тихого изменения основания пройденных ворот, потери истории/ограничений, расширения полномочий, превращения task-copy в норму. Не обещается поймать нарочную подделку всех bytes одним hash. Снятые031/045/013 не возвращаются. Нормы самой проверки здесь не переписываются; их исключение из поля границы сохраняется.
3. Подозреваемые старые дыры: target README37 содержит только стартовый commit; process5–12 — плавающую основу; process203–205 допускает смешение predicate стража и срока current; process165–168 не противопоставляет смысл подзадачи S110; process354–355 допускает смешение helpers и opinion. Это предмет сверки и цель patch, не автоматическое «не по адресу» для будущих находок. Новые соседние нормы target не удалены.

M711 pin соответствует observed M713; M1550 — observed M1552. Замысел не доказательство/не сокращение цикла; opinion не помощник, не проверка и не approval. В авторской сессии свежий собеседник не запускался по прямому запрету. Единственную последующую Kimi назначает интегратор по отдельному разрешению владельца; будущему мнению нельзя приписать прошлое согласие. Переданные факты, итог и несогласие должны быть записаны отдельно.
