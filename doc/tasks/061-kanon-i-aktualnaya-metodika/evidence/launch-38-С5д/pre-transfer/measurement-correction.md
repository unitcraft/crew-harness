# Поправка к раннему after/fingerprints38

Первый whole-after завершился assertion: rootlog изменён, появился transfer-authorization.md. Автор сначала ещё не видел двух новых писем; inbox затем доставил разрешение владельца04:25/04:32. Rootlog сохранил весь ранний byte-prefix, новый authorization создан интегратором, автор его не менял. Это внешние concurrent изменения полномочия, не неразрешённая запись автора и не разрешение исключить прочий config/историю. Исходные after/fingerprints сохраняются со своей ошибочной фразой «rootlog не изменён». Новый финальный transfer-after и проверка префиксов будут отдельными файлами.

После этого новое назначение изменило границу работы ДО итоговой строки; прежняя обещанная остановка подготовки/ожидание latest больше не актуальны. Ранний отчёт сохранён побайтно рядом; proposed/decisions c550 не редактируются и остаются историей. Новая primary программа ограничена применимыми нормами a449 и готовой дельтой, не всем поздним upstream. Это не задним числом PASS ранней неполной подготовки.
