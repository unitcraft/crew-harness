# ai-dev-methodology

Переносимая методология разработки с ИИ-исполнителями и документы для работы по ней: от постановки задачи до проверенного результата.

**[Открыть визуальную презентацию](https://unitcraft.github.io/ai-dev-methodology/)**

## Документы

| Файл | Назначение |
| --- | --- |
| [methodology.md](../../../publication/originals.zip) (историческая цель: `methodology.md`; точный оригинал — в архиве) | Полный текст методологии: правила проекта, роли, проверки и порядок внедрения. |
| [task-algorithm.md](../../../publication/originals.zip) (историческая цель: `task-algorithm.md`; точный оригинал — в архиве) | Алгоритм исполнителя для одной задачи. |
| [task-sessions.md](../../../publication/originals.zip) (историческая цель: `task-sessions.md`; точный оригинал — в архиве) | Схема сессий, проверок и повторов. |
| [task-runner.md](../../../publication/originals.zip) (историческая цель: `task-runner.md`; точный оригинал — в архиве) | Алгоритм оркестратора, который ведёт задачу между сессиями. |
| [completeness-check.md](../../../publication/originals.zip) (историческая цель: `completeness-check.md`; точный оригинал — в архиве) | Источники и проверка полноты методологии. |
| [presentations/](../../../publication/originals.zip) (историческая цель: `presentations/`; точный оригинал — в архиве) | HTML-презентации методологии и отдельных частей процесса. |

Методология абстрактна: проект переносит подходящие правила и заводит собственный канон, роли и договорённости.
