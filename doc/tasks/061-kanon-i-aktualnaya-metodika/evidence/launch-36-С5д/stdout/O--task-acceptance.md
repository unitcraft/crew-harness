Это общие шаги приёмки любой задачи проекта по методике ([task-sessions.md](../../../publication/originals.zip) (историческая цель: `task-sessions.md`; точный оригинал — в архиве), сессии С6 «Проверка реализации» и С8 «Проверка сдачи»). Их читает механизм приёмки из целевой ветки; они не заменяют критерии конкретной задачи.

| id | текст | обязателен |
|---|---|---|
| dod-evidence | Каждая строка DoD доказана воспроизводимой командой с выводом или именем теста. | да |
| trace-decisions | В трассировке нет NOT VERIFIED и FAIL без решения владельца с датой. | да |
| secrets-scan | Поиск по diff и файлам сдачи проверяет секреты, реквизиты, пути машины и персональные данные; результат указан отдельной строкой, в том числе если нарушений нет. | да |
| reverse-probe | Для исправления проверка при отложенной правке красная по названной причине; после возврата правки она зелёная. | да |
| test-counts | Итоговые числа тестов и пропущенных сверены с базовыми; каждое расхождение объяснено поимённо. | да |
| single-commit | Статистика индекса показана до коммита; один коммит содержит только нужные файлы и имеет английское сообщение без подписей, трейлеров и имён моделей. | да |

> Публикационная копия: изменены только ссылки, кодировка или служебная разметка.
> Точные исходные байты и SHA — в [описании происхождения](../../../publication/provenance.json) и архиве оригиналов.
