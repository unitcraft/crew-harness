# Совещание агентов: псевдокод

Вынесено из [task-runner.md](../../../publication/originals.zip) (историческая цель: `task-runner.md`; точный оригинал — в архиве), «Совещание агентов»: там правила режима, здесь `meeting` и `check_meeting`; `loop_review` — [task-runner-pseudocode.md](../../../publication/originals.zip) (историческая цель: `task-runner-pseudocode.md`; точный оригинал — в архиве). Схема опытного режима, раннером не выполняется. Та же схема состояниями — [task-runner-meeting-states.md](../../../publication/originals.zip) (историческая цель: `task-runner-meeting-states.md`; точный оригинал — в архиве).

> **Устарело (2026-10-17).** Схема не приведена к контракту машины (`state-machine-spec.md`, правило 35: вызов, один ответ, отмена, пауза цепочки, коды отказа). Актуальна форма состояниями — [task-runner-meeting-states.md](../../../publication/originals.zip) (историческая цель: `task-runner-meeting-states.md`; точный оригинал — в архиве); приведение этого файла — открытый вопрос со сроком 2026-11-15 (`doc/open-questions.md`).


```text
алгоритм meeting(proposal, lenses, witness):
    пока истина:
        verdict ← loop_review(meeting)               # checker(meeting) — check_meeting, fixer(meeting) — автор
        выбор verdict:
            halt:               log(«совещание остановлено: <причина>», незакрытые находки); вернуть     # итог не принимается; незакрытые — state.open[meeting] и находки последнего засчитанного захода, не вошедшие в него
            stopped(«вопрос»):  fixed ← stopped(«вопрос»)                          # любое стоп-слово автора совещания читается как «вопрос»
                                пока fixed = stopped(_):                          # автор может спросить ещё раз — снова В7
                                    answer ← gate(В7, вопрос автора)
                                    fixed ← run(автор, source=answer, pass=state.pass[meeting] − 1)   # номер захода с находками (state.pass уже увеличен); ответ сразу идёт автору; новая версия proposal.md — вход следующего захода
                                если fixed = halt: log(«совещание остановлено: <причина>», незакрытые находки); вернуть
                                continue
            clean:              выйти
    gate(«принять итог»)                             # решения закрытого списка и потолок — только человек
    записать решение с источником, числом заходов и находками state.open[meeting] как «открыто» и припиской «значимые находки прежних заходов, не вошедшие в «открыто», — в файлах заходов» в log.md

алгоритм check_meeting(n):                           # вместо run(checker(stage), pass=n) в loop_review, когда stage = meeting
    если есть вопросы автора (proposal.md) и проверяющих (файлы захода N−1): witness-n.md ← run(свидетель, source=вопросы, pass=n); если halt: вернуть halt
    если witness-n.md есть: проверка выдержек (поиск строки); несовпадение → один ход свидетелю «исправь выдержку»; снова несовпадение → строка помечена «не подтверждено»   # до того, как линзы читают файл
    копия ← копия proposal.md с хешем                 # в начале захода
    proposal.md ← только чтение                       # на время проверок линз; запись возвращается в finally
    для каждой линзы: файл линзы ← run(проверка_линзы, source=proposal, pass=n)    # линзы читают proposal.md и witness-n.md, но не файлы других линз этого захода; verify_formats внутри run
        если run вернул failed: lost[линза] += 1
            если lost[линза] ≥ 2: choice ← gate(В13, «линза потеряна второй раз подряд»)
                «остановить совещание»: вернуть halt
                «повторить»:            перезапустить линзу в этом же заходе (lost не обнуляется); получила ответ — lost ← 0, дальше следующая линза
            если линза так и не ответила: она отброшена (log; в счёт по моделям, если причина «модель»); P линзы ← 0; если линз не осталось: вернуть halt   # halt означает, что решает человек
        иначе: lost[линза] ← 0
        если run вернул halt (В13 для автора или свидетеля: «остановить»): вернуть halt
    если proposal.md ≠ копия: choice ← gate(В13, «proposal.md изменён за время проверок», показать копию и изменённый файл)   # заход недействителен; его находки в счёт и в потолок не идут
        «оставить правку» | «вернуть копию»: (копию вернуть, если выбрана); файлы линз и свидетеля этого захода переименовать в `*.void-<k>.md`, k — номер недействительного захода в этом заходе (в контекст не входят); повторить check_meeting(n) с начала на выбранной версии
        «остановить совещание»: вернуть halt
    для каждой линзы: признаки несостоятельного мнения → убрать из файла, записать в счёт по моделям; если у линзы отброшены все критические находки, её P ← 0   # такой заход не считается чистым
    proposal-review-N.md ← первая строка «Заход N: критических K, значимых Z, желательных D, проб P» (K, Z, D — суммы, P — наименьшее по линзам),
                           затем находки с меткой линзы
    вернуть proposal-review-N.md                      # дальше loop_review: parse_summary (K — критические), В3, В9
```
