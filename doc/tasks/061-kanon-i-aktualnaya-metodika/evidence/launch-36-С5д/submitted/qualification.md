## Существенная собственная процессная оговорка

Загрузка safe_io.py через importlib создала __pycache__/safe_io.cpython-314.pyc вне разрешённого перечня. Это нарушение output-контракта, не разрешённый новый файл и не чистый path gate. Он остаётся на месте; expected не расширялся задним числом, before не переснимался. Сразу после обнаружения интегратор уведомлён письмом; затем только -B, новых pyc не создавалось. Файл исключён из frozen публикуемого пакета, а его наличие/hash фиксируются after/fingerprints. Бинарный cache потенциально содержит локатор машины; его payload не печатается и не копируется. Публикация/удаление не разрешены. Судить и выбирать дальнейший маршрут должен владелец/независимая проверка, автор себя не принимает.
