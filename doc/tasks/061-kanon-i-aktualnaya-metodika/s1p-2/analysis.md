## Решения владельца и границы

### Обязательность и provenance — отдельные оси

`process.md:5–12` принимает методику как основу, а явные project deviations требуют собственного основания. Поэтому после выбранного pin действующая норма действует по собственным условиям, пока владелец явно не утвердил override/отключение. Метка `partial`, `not tested` или `unconfirmed` из `completeness-check.md` характеризует доказанность практикой/происхождение, но не отменяет норму. Условная применимость — только установленное самой нормой условие; открытый вопрос остаётся вопросом и не стирает соседние обязательные фразы.

Применение: `methodology.md:1550–1552` задаёт second opinion по умолчанию с явным owner-off switch; provenance partial не является выключателем. §10 `:709–718` задаёт протокол сходимости в собственных условиях; отсутствие plugin runtime не приостанавливает обязательство по процессу. §4 `:154` разделяет решение оркестратора вне списка (с записью) и owner gates; `doc/open-questions.md` остаётся вопросом о координаторе, не отменой owner gates. `task-sessions.md:108–110` и `process.md:151–160` используют «подзадачу» в разных смыслах: значение проекта — явный semantic override, а не нейтральное расширение.

- Политика pin и перехода активных задач: рекомендация — неизменяемый pin при старте, переход конкретной задачи только явным решением с сохранением исходного журнала.
- Оценка редакции 031 ведётся по трём независимым осям: новые данные/refs; изменения нормативной семантики, REQ/AC и приёмочных пар (возможны при прежней JSON shape); новые поля/shape. Отсутствие missing-field gap не исключает семантической редакции: конфликт progress уже доказан. Сначала отдельное предложение изменений и проверка правил versions/compatibility, затем отдельные ворота владельца; сохранение или повышение schemaVersion заранее не обещается. Approved 031 не переписывается.
- Источник и владелец registry/signatures 045 остаются отдельным внешним выбором.

Полная задача должна актуализировать Канон в `doc/canon/` (и `AGENTS.md`, только если доказательства покажут необходимость), создать `current.md` как указатель и сохранить старые pins/reviews. Approved 031 не правится. Историческая папка 031 не является единственным действующим местом результата.
