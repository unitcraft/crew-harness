# Заход 6 — пробы и контроли

## Корректированные пары

Лёгкая Python-проверка строк `spec.md`, без изменения входов; для каждого контроля ожидалось, что исходная точная строка находится, а подменённая в памяти — нет. Все шесть фактических результатов совпали с ожиданием, exit 0:

| Пара | Input | Expected → actual | Exit |
|---|---|---|---|
| P1+ | `REQ-03. Снят решением владельца` | True → True | 0 |
| P1− | та же строка после in-memory `Снят решением владельца` → `Оставлен активным` | False → False | 0 |
| P2+ | первая передача любого результата создаёт `current.md` | True → True | 0 |
| P2− | точная фраза после in-memory `создаёт` → `не создаёт` | False → False | 0 |
| P3+ | AC-06: при drift перенос остановлен | True → True | 0 |
| P3− | та же фраза после in-memory `перенос остановлен` → `перенос продолжается` | False → False | 0 |

Это только дискриминация конкретных текстовых утверждений, не проверка полноты или смысла.

## Ошибочные первые проверки — сохранённые

Первый запуск имел три ошибочных ожидания/предиката: P1 ожидал отсутствия текста REQ-03, хотя он явно присутствует в пометке снятия; P2− проверял broad substring по всему документу и находил повторное упоминание в другом разделе; P3 использовал не совпадавшую с текстом фразу. Результаты не зачтены: первый mismatch P1 actual false против expected true, P2− фактически true против expected false, P3+ фактически false против expected true. Исправленные пробы выполнены отдельно выше, исходные ошибки не объявлены PASS.
