**Исход:** добавлена шестая явная категория «семантический конфликт»; вместо прежнего требования единственного verdict введён непустой набор категорий с областью каждой. `spec.md` REQ-03/AC-02, `analysis.md`, `spec-trace.md` и уточнение в `spec-fixes-1.md` согласованы. Отдельный исход progress не объявляет новые поля доказанными и не сводит семантическую редакцию к данным.

Проверена каждая строка именно против объявленных категорий (это не новый полный аудит её expressibility):

| 1. state.launches | внешний контракт | Mutable state не статическая декларация сессии; категория объявлена |
| 2. process lifetime/retry | уже выражается; внешний контракт | Декларации recovery отдельно от фактического shutdown/restart; обе категории объявлены |

Итог: 7/7 строк имеют непустой набор объявленных категорий, неизвестных labels нет. «Нужен формат» и «открытый вопрос» остаются допустимыми категориями, но не назначены этим строкам. При первой строгой пробе дополнительно обнаружены формы labels «уже выражаются» в строках 2 и 5; они приведены к точной категории «уже выражается» без изменения предметного смысла. Отрицательный контроль на неизменном `s1p-1/031-impact.md` обнаруживает строки 2/3/5: две словоформы и, независимо от них, необъявленный semantic verdict в строке 3.

Воспроизведение проверки категорий из корня дерева (Python, без записи файлов):

```python
from pathlib import Path
import re
p = Path('doc/tasks/061-kanon-i-aktualnaya-metodika')
def check(path):
    text = path.read_text(encoding='utf-8')
    declaration = next(x for x in text.splitlines() if x.startswith('Вердикты'))
    declared = {x.casefold() for x in re.findall(r'\*\*([^*]+)\*\*', declaration)}
    rows = [x for x in text.splitlines() if x.startswith('| ')][1:]
    assert len(rows) == 7
    bad_rows = []
    for n, row in enumerate(rows, 1):
        cell = row.rsplit('|', 2)[-2]
        labels = {x.casefold() for x in re.findall(r'\*\*([^*]+)\*\*', cell)}
        bad = labels - declared
        print(n, sorted(labels), sorted(bad))
        if not labels or bad:
            bad_rows.append(n)
    return declared, bad_rows
declared, bad = check(p / '031-impact.md')
assert len(declared) == 6 and bad == []
assert check(p / 's1p-1/031-impact.md')[1] == [2, 3, 5]
```
