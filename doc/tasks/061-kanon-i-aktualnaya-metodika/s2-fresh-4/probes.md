# Собственные пробы

Из корня дерева: `python doc/tasks/061-kanon-i-aktualnaya-metodika/s2-fresh-4/run_probes.py`.
Каждый вложенный вызов и exit — `probe-exits.json`; исходные stdout/stderr
сохранены побайтно в `probe-1…3.stdout.txt` и `probe-1…3.stderr.txt`.

1. `probe-integrity.py`: root/frozen/manifest всех семи совпадают. Отрицательный
   контроль для каждого — добавление SPACE только в памяти: digest отличается.
   Вывод: 7 положительных и 7 отрицательных контролей, exit 0, stderr пуст.
2. `probe-progress.mjs`: прямой вызов чистых функций plugin на синтетических
   строках. Полное 0/2→2/2 допустимо; done до первой единицы отвергнут; N=1 в
   финале после startN=2 не обходит проверку. При одинаковой дроби 1/2 raw строка
   без причины не итог, с «N завышено» — итог. `готово:` распознаётся, `Готово` нет.
   Exit 0, stderr пуст. Причина не аттестуется по артефакту этой пробой.
3. `probe-authority.mjs`: агенту launch отказан; запускающему свободный номер
   разрешён; повтор номера отвергнут. Поправка к существующему началу подписи
   не меняет k=1; к несуществующей цитате — отказ. Exit 0, stderr пуст.

Дата 2000-01-01 — явно фиктивная константа теста, не время настоящего журнала.
Пробы 2/3 не пишут файлы журнала и не вызывают session.create, launcher,
реестр, reader или stateful runner. Они свидетельствуют только об этих
чистых операциях на защищённых байтах 492c166.

Первый запуск также дал три exit 0. При повторе через сохранённый wrapper
вывод сохранён raw bytes вместо text-mode записи, чтобы не удваивать CR в Windows.
Sources/subject/ожидаемые исходы после запуска не изменялись.
