## Как читать адреса и основания

Каждая строка `Axx / n` указывает **два точных исходных адреса**: `task/message.md:n` и одноимённый блок `scope-revision-1/before/spec-trace.md`, `### Axx / n` (его bytes неизменны). Исходный атом назван в строке; буквальный старый constraint доступен по этому адресу, не теряется при сужении. Текущий адрес `C-Axx` — constraint именно этой строки таблицы; REQ/AC/DNC — одноимённые абзацы `spec.md`. Снятие — не исполнение и не PASS.

Основания: **О** = `author-setup/owner-input.md:3–15`, владелец 2026-10-17 (сужение и одно разрешение правки/полной С2); **П** = `owner-gate-decisions.md:8–22`, владелец 2026-10-16 (В-01/В-01а); **З** = исходный `task/message.md` по строке в первом столбце, применённый в границах О; **Н** = назначение С1п-7 интегратора, 2026-10-17, программа N6, сохранённое в `scope-revision-2/session-contract.md`. Проверка в последнем столбце — конкретное ручное сравнение входного смысла с названным адресом; автор его выполнил для каждой строки при составлении карты. Это не независимый PASS и не выполнение будущего переноса.
