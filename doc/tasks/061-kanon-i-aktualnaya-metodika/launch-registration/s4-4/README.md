# Подготовка регистрации заключительной С4

Регистрацию интегратор выполняет инструментом progress_line здесь и переносит её raw-строки в журналы подготовленного дерева проверяющего до старта. Номер определяется по максимуму записей сессий и журналов первичного дерева/деревьев сессий, как в nextLaunch плагина. До crew_spawn корневые журналы первичного дерева не продвигаются: плагин сам зарегистрирует там этот же запуск. Это предотвращает новый сдвиг номеров после восстановления штатного запуска.

Старые журналы, номера и записи не переписываются; их расхождения остаются историей. Второй экземпляр сессии не создаётся. Файлы этой папки — служебная история регистрации, не нормативный результат задачи.
