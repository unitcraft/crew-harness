## Критерии приёмки

На С1 есть конкретная матрица old pin → актуальная методика → действующий Canon → наблюдаемое поведение плагина/раннера → затронутый контракт 031/045, со source anchors и квалификацией доказательств. По каждому предполагаемому несовпадению — точное место и наблюдаемое последствие, а не общий вывод «устарело».

Проверены первоначальные блокеры 045 и найден конкретный маршрут закрытия каждого без выдуманных signatures/compatibility/PASS. Возможные изменения 031 разделены на изменения только данных, схемы/версии и отсутствующие внешние контракты. Новый текст утверждённого формата пока не создан. Исторические документы не переписываются.

Чёткий scope полной задачи и место действующего результата в Каноне; в папке задачи только анализ/спецификация/доказательства и будущий current.md по норме. Нет молчаливой смены pin активных задач, сброса потолков/номеров/серий или объявления автоапрува требований. Сформирован короткий список реальных решений владельца и next step независимой С2.
