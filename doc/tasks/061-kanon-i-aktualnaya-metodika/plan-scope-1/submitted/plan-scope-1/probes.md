# Пробы автора: контракт до запуска

Входы — только текущий draftplan и новые test-only пути внутри plan-scope-1.
Ни Канон, ни будущий runtime не исполняются. Ожидания закреплены здесь и
в expected-probes.json до запуска; actual пишется отдельно, не подгоняется.

## P1 — ручной маршрут «От подготовки до первого переноса»

Открыть plan/шаги1–10 и абзац после них, spec31/39 и trace127.
Обойти последовательно1/2/3: какой файл допускает запись и что остаётся readonly.
Затем4 без решения: должна быть остановка, не5. С решением4 и freshstableupstream
провести5: README/process плюс current одновременно. Провести6–8: current дополняется.
Альтернативный разрешённый ADR-first из абзаца после10 также сразу с current.
Отрицательные входы: process пересказывает D0 на шаге3; README внесён безcurrent;
ADR внесён раньше любых остальных результатов безcurrent. Каждый должен быть
отвергнут конкретной строкой плана. Это реальные проведённые чтением маршруты,
не запуск записи будущего Канона. Actual — отдельный ручной протокол с адресами.

## P2 — команда «Целый nameset и чужой before»

Подготовка: `python doc/tasks/061-kanon-i-aktualnaya-metodika/plan-scope-1/path_probe.py prepare`.
Прогон: та же команда с `run`; cwd — корень своего дерева.
Фикстуры точно перечислены в скрипте и создаются только если отсутствуют.
Проверить: complete nameset до/после одинаков; подмена oldbefore внутри него
обнаружена по hash; existingoldbefore не может стать exclusion; занятый E — отказ,
отсутствующий E для нового реально назначенного кода — разрешённый путь.
Скрипт не создаёт настоящего futureE, только test-only модели/фикстуры.
Actual JSON и rawstdout/exit — отдельные новые outputs.
