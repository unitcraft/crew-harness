Снятый форматный смысл не скрывает сохранённый канонический — например A30/31/33/42/50/56/73/80/92/94.

Адресная таблица судеб охватывает каждый исходный fragment, не только семь букв D. Все последствия согласованы с новым результатом.

## Обязательность, применимость, практика, код — разные оси

Канон `process.md:5–12` принимает внешнюю основу целиком без пересказа. Норма действует по своим условиям; точное отключение/override требует принятого решения и источника. `partial/not tested/unconfirmed` в реестре — статус практики, не отмена нормы. Открытые вопросы не ответы. Q5 — процедура, уже принятая `process.md:125–144`, а не нерешённый вопрос. Замысел/сходимость M709–718 не равны optional согласованию §18; отключение helpers (`process.md:245–246`) не отключает second opinion M1550–1551. Полномочия M154–155 и проектные owner gates/ADR0010 квалифицируются отдельно от факта программной реализации.

Термин «подзадача» имеет два смысла: C S108–110 — пункт плана без собственных ворот; project `process.md:151–160` — отдельная нумеруемая задача со своей приёмкой. Это semantic override с источником владельца 2026-10-15, а не нейтральная разница счётчика. Будущее уточнение D2 должно назвать отличие и причину, не менять уже выбранный смысл.

Кодовые свидетели относятся только к Git `492c166fbd12e00a6a924efab065f6adb4bd91f6`, не live: EJ — `opencode-plugin/journal.ts`, EL — `task-folders.ts`/`index.ts`/тип `tasks.ts` той же папки, ES — запись Task tmp+rename, EG — инструкции в `core.ts`. Точные пути/ranges/callsites и ограничения — `method-delta.md`, раздел «Кодовые свидетели». Они не доказывают честность артефакта, полный state/runtime, second opinion или semantic review. EØ означает «этими местами не доказано», не глобальное отсутствие механизма и не отмену нормы. Новой реализации/контракта раннера эта работа не проектирует.

## Результат на своих местах

REQ-05/AC-05 и таблицы spec/trace дают только канонический маршрут: README строка версии/источника; process «Основа» и правило перехода, только точные проектные отличия с причинами; принятые границы — новый ADR/реестр/ссылка из входа. AGENTS — лишь при доказанном воздействии на конкретное правило и отдельном разрешении. Каждый delta имеет адрес и проверку. D0 — внешняя основа по ссылке, не её пересказ.

**Первый любой реальный перенос061**, даже одного README или ADR, тем же шагом создаёт current; каждый следующий дополняет адреса. В нём нет нормы, только уже действующие места и пометка истории. Ни ожидание других результатов, ни отсутствие result.md не откладывают указатель. В этой сессии перенос/current не выполняются. После будущего внесения «Поадресная сверка результата Канона» проверяет source→REQ→destination→действующий текст→evidence и diff/commit, единственность вне задач, сохранность истории, current и свежесть. Это не нынешний PASS.
