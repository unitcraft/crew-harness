# Алула 2.26 — целевая схема (решения владельца, 2026-10-26/27, чат методики)

Статус: проект для параллельных потоков пакета; тексты спецификации и журнал (AL-137…) пишет методика и присылает следом. Версия ломающая, скрипт миграции, переходного периода нет. Дерево `machine/2` меняется только там, где сказано (см. «Дерево»).

## 1. Файл машины: разделы по порядку

шапка (`# Машина:` + `- machine:`, `- machine_version:`, `- format: 2.26`, `- language:`), `## Типы`, `## Имена` (необяз.), `## Константы`, `## Параметры`, `## Вход`, `## Данные`, `## Стороны`, `## Подключения` (библиотеки), `## Внешние функции`, `## Функции`, `## Состояния`, `## Выход`.
Пустой раздел не пишется (вместо строки `—`). Прежний `## Концы` → `## Выход`. Прежний `## Примитивы`/`Подключения`-строки функций убраны (см. 5).

## 2. Строки-ключи состояния

Только с маркером `- ` (`- Сторона: …`, `- Срок тишины: …`, `- Правит: …`, `- Возвратов формы: …`, `- Запрос:`, `- При входе: …`, `- При приёме:`, `- Кроме: …`). Без маркера — ошибка (режим «маркер необязателен, совместимость 2.5» убран). Строки `- Читает:` нет (ошибка «с 2.26 чтения выводятся»).

## 3. «Запрос» обращения

`- Запрос:` и таблица `| поле запроса | выражение |`. Пустая ячейка «выражение» = «то же имя» (выражение равно имени поля). Столбца «читает» нет; в запрос идёт всё, что в таблице. Поле запроса с именем данного и другим выражением — как раньше (читают данное, не поле). Срок тишины читает имена «Запроса» (как раньше).

## 4. Строки переходов

- Обращение: `| Событие | Условие | Действия | Куда |`; развилка: `| Условие | Действия | Куда |`; операция: `| Действия | Куда |` (одна строка; событие `сразу` и условие убраны); общие события библиотеки — как обращение.
- Столбца `№` нет нигде (в `## Выход` тоже).
- Пустая ячейка «Условие» = «нет условия»; пустая «Действия» = «нет действий»; пустая «Куда» — только у строки с `ошибка_машины` (как раньше `—`); строка с `—` в этих ячейках — ошибка (одно написание).
- Действия: `<br>` (HTML-перенос) между действиями в ячейке; `;` по-прежнему допустим. Разбор: `<br>` ≡ `; `.
- `иначе` у развилки не пишется, если условия исчерпывают значения (доказано типом) ИЛИ автор не хочет своё действие: непокрытая развилка сама ведёт в ОШИБКУ, движок пишет `ошибка_машины("fork_no_match", fork: "<JSON_имя>")` (журнал и коды те же). Строка `иначе` по-прежнему допустима, если у неё свои действия.

## 5. Чтения и запись

- Чтения состояния выводит проверка: из выражений строк, «Запроса», «При приёме», «При входе»; плюс скрытые чтения внешних функций из реестра хозяина; у ОШИБКИ все данные. Сверка «читает ⊆ объявленное» (правило 11 методики) снимается; проверка остаётся «имя существует и допустимо» (по «Запросу»/«Читает» ровно как сейчас для срока тишины: срок читает только имена «Запроса»).
- Столбца `пишет` в `## Данные` нет: `имя | тип | начальное [| не убывает]`. Данные, которые пишет только движок, объявлены в библиотеке `контракт` (раздел «Данные движка»); запись в них из строк, `При приёме`, действующих функций — ошибка проверки. К ним относятся: счётчики попыток сторон, `открытые_запросы`, `запрос_вызова`. `к_отправке` пишут и действия, и движок — разрешено.
- Счётчик стороны: столбец `счётчик` в `## Стороны` называет имя (или путь `имя[*].поле` у набора); загрузчик сам заводит данное (`число>=0`, `0`, не убывает), писать из действий нельзя, читать можно. Строки в `## Данные` под него не пишутся.

## 6. Библиотеки (вместо фрагментов и файлов функций)

Одно слово «библиотека»: подключаемый файл. Шапка `# Библиотека: <Имя>`, `- library: <латинское_имя>`, `- format: 2.26`, `- language:`. Разделы (все необяз.): `## Параметры` (`имя | тип | комментарий`; закрытые наборы слов прямо в типе `"a" | "b"`; виды `сигнал`, `строка`, `[]машина`, `поведение` заменены обычными типами; параметр-«примечание» убирается), `## Требует` (`имя | тип`: данные и стороны головной машины, нужные библиотеке; проверка типов чтений/записей при компиляции библиотеки и существования/типа при подключении), `## Типы`, `## Имена`, `## Константы`, `## Данные`, `## Данные движка` (только в `контракт`), `## События стороны` (только в `контракт`), `## Внешние функции` нельзя (запрет как у файла функций), `## Функции`, `## Общие события`, `## Состояния`.
Параметры — локальные константы библиотеки, в тексте библиотеки читаются по имени (`сигнал_остановки`), без `<…>`; менять нельзя.
Видимость: функции, типы, константы библиотеки видны в машине без префикса (совпадение — ошибка); данные и состояния библиотеки — с префиксом экземпляра (`Пауза.предыдущее`); имя экземпляра по умолчанию — имя библиотеки, `- Имя:` задаёт другое. Библиотека с состояниями и общими событиями подключается один раз.
Подключение в `## Подключения`, по подзаголовку на библиотеку:
```
### Пауза
- Файл: libs/pause.alula.md
- Хеш: f757b8aa7b08
- Имя: Пауза2              необязательно
| параметр | значение |
|---|---|
| сигнал_остановки | остановить |
```
Хеш — как у файла функций (12 знаков SHA-256, нормализация без изменений); версии `N` нет. Файл ищется по пути относительно файла машины, затем в папке `--lib`/настройке проекта; вшитая только `контракт`. Файлы функций — такие же библиотеки (только `## Функции`, `## Типы`, `## Константы`); строка `функции: имя версия N хеш H` убрана.
Строки подключения со старым синтаксисом — ошибка с подсказкой («с 2.26 — подзаголовок `### Имя` в `## Подключения`»).

## 7. Библиотека `контракт` (вшита, подключается неявно)

Типы: `КодСбоя` (10 кодов: НетРезультата=no_result, ОтказМодели=model_refused, СоединениеОборвалось=connection_lost, ФормаНеИсправлена=form_not_fixed, НетОтветаВСрок=timeout, ОстановленоЧеловеком=stopped_by_human, ПотолокЗаходов=ceiling_reached, ОтмененоРодителем=cancelled, ПредельТокенов=max_tokens, ПредельЗапросовХода=max_turn_requests) — объявлять в машине не нужно; продукт добавляет коды своей библиотекой.
Данные движка: `запрос_вызова` (строка, ""), `открытые_запросы` ([]строка, []).
События стороны: `ответ`, `сбой(код)`, `часть(поля)`, `срок`; тип части — обычный тип машины/библиотеки (`тип КусокОтвета запись { содержание строка }`), сторона в `## Стороны` называет, что присылает (синтаксис столбца — на ваше решение, предлагается столбец `части` по образцу `сигналы`). Раздел «Части ответа» и слой `keywords_product.tsv` убираются; слова `часть`, `срок`, действие `сторона` переходят в таблицу слов.
Срок тишины: каждая пришедшая `часть` отсчитывает срок заново (решение владельца 2026-10-26).

## 8. `## Выход` (был `## Концы`)

`- Результат: <тип>` и таблица `| конец | когда | ответ |` (без `№`).

## 9. Внешние функции

`## Внешние функции`: строки без слова «внешняя функция»: `имя(арг тип, …) [<класс>] [-> тип]`; английская форма — те же без `external fn`.

## 10. Слова и тексты

«Исполнитель» (в смысле движка Алулы) → «движок» в спецификации, таблице слов, документах, сообщениях ошибок; «хозяин» остаётся. Столбец «допустимые значения» у параметров библиотеки заменён типом. Прежние записи «с 2.21…2.25 не бывает» — из спецификации (раздел 10) в журнал изменений; сообщения-подсказки старых форм остаются в проверке только для 2.25→2.26 (одна версия назад).

## 11. Дерево (`machine/2`) и версия

`alula_version "2.26"`. В дереве: убирается `reads` по умолчанию из `Запроса`? — НЕТ: чтения остаются в дереве как ВЫВЕДЕННОЕ (проверка заполняет), поле `to_party` у поля запроса остаётся (всё поле запроса идёт стороне); узел подключения библиотеки несёт имя экземпляра, хеш, параметры; `primitives` не трогаем. Решение по деталям дерева — за потоком пакета с письмом мне.

## 12. Порядок потоков
