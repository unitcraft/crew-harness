# Разбор 055: в панели видно, кто ждёт владельца и о чём

Задание — `task/message.md`. Быстрый путь, основа — `main` `cd4d778`. Записан оркестратором по отчёту исполнителя (инструмент записи у исполнителя отказал).

## 1. Почему владелец не видел, кто ждёт

1. **Ширина.** OpenCode 2.0.23 даёт боковой панели 42 колонки; отступы 2 + 2 и 1 справа у прокрутки оставляют под текст около 37 знаков. Плагин сам режет каждую строку по своему пределу `SIDE_WIDTH = 32` (`status.ts`), а строку без колонки «кто» печатает с отступом 4. Сводной строке `Ждут вас: 1 · с 18:55 · claude-limits #33 исп` доставалось 28 знаков — хвост «· clau». Обрезал плагин, а не OpenCode.
2. **Текст вопроса** есть в состоянии вкладки (`status/<сессия>.json`, поле `question`): вопрос вопросника (`forms/`, `form-wait.ts`) или строка с «?» в конце хода (`endsWithQuestion`). В панель он не выводился.
3. **`/crew`** уже печатал строку ждущего целиком (проект — заголовком группы, вкладка и `detail` с текстом вопроса).
4. **`/ask`** перечислял только вопросы вопросника: вкладку, чей ход кончился вопросом, не называл, и счёт «Ждут вас» в `/ask` расходился с панелью.

## 2. Что сделано

1. `status.ts`, `waitingRows`: три строки панели по всем проектам — `Ждут вас: N · с ЧЧ:ММ`; `? <проект> <вкладка>` у самого давнего ожидания; `  ↳ <вопрос>`, обрезанный по ширине. Нет текста вопроса — нет третьей строки; никто не ждёт — строк нет. Строки печатаются с первой колонки (`SideRow.flush`), вторая не обрезается и при ширине 24. `sideText` и `sidebarLines` принимают ширину (по умолчанию 32). Сводная строка `/crew` (`waitingLine`) не менялась.
2. `form-wait.ts`, `tui.ts`: `/ask` получает и ждущих без записи в `forms/` (состояние `owner` без `formId`): проект, вкладка, сколько ждут, текст вопроса; они входят в счёт.
3. Значки — по слову владельца (2026-10-15, чат оркестратора): «? — ждёт вас; ▶ — задал вопрос текстом, ждёт ответа интегратора (или вашего);». Общая таблица `MARK` в `status.ts`: owner «?», question «▶», working «•» — по ней панель, вторая строка сводки и `/crew`; в `/ask` — «?». «▶» в шагах приёмки (`stepBar`) — другой смысл, оставлен.
4. README плагина описывает три строки и значки; снимок `test/answer-golden.json` принял новые тексты `/crew` и панели (изменились только ключи «crew: formatStatuses», «crew: sidebarLines», «crew: sidebarLines, texts»; `answer-golden-base.json` не тронут).

Пример (тест `crew-sidebar`, ширина 32):

```
Ждут вас: 1 · с 18:55
? claude-limits #33 исп
  ↳ Продолжать #31 или переключ…
```
