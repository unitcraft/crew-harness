## 4. Находки и вопросы владельцу

Правка Канона по ним не делалась: правило от себя вводить нельзя.

1. **Быстрый путь заданий и условия быстрого маршрута методики.** Методика требует в постановке быстрого маршрута строки `AC-N` и `Ветка: <имя>` и раздел «Признаки маршрута»; образец задания проекта (ADR-0011) ведёт критерии списком, ветку в шапке, раздела признаков нет; плагин принимает форму проекта как равную (`opencode-plugin/route.ts`), в Каноне отличие не записано. → open-questions #10.
2. **Включать ли вратаря.** По умолчанию методики вратарь-агент выключен, проект его не включал; усиленный вратарь — отдельное слово владельца с датой. → не нужно, потому что вопрос появляется только по инициативе владельца; Канон фиксирует «выключено».
3. **Закрытый список автоответа плагина и ворота В14, В15.** Эти ворота попадают в `gate` по типу вопроса, а не по тексту; отдельной проверки, что их слова есть в списке, не делалось. → не нужно, потому что вопросы ворот несут `Тип: gate` по форме вопроса, а ADR-0010 отдаёт `gate` владельцу при любом режиме; если окажется иначе, это дефект плагина, отдельная задача.
