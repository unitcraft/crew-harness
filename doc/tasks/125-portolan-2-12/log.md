## Находки по ходу

- Выход `portolan compile -o` дописывает перевод строки в конец файла, а дерево машины в репозитории хранится без него (тест сравнивает байты): после пересборки конец файла срезан. Для Методики/продукта: либо `-o` не пишет перевод строки, либо тесты его допускают.
- Текст фрагмента «Пауза» говорит `ОСТАНОВЛЕНО` и `усиленный`; канонический файл пишет заголовки состояний латиницей, а сторону без слова словаря — тоже латиницей, поэтому фрагмент не находил их. Решение: синонимы словаря для состояний, строка `party усиленный enhanced` в `names_format.tsv`. Вопрос Методике: как фрагмент называет состояние и сторону машины, если машина записана каноническим видом.
- В тестах 4 КБ вывода: при красных тестах видны только последние четыре; счёт красных в красной пробе взят из строки `N/M passed` (`NOVA_DEBUG_RUN_DUMP=1`).
- Известный предел языка, обход без метки: функция с параметром `ro` типа сумма не может вернуть этот параметр, если тип результата не `ro` (`E_READONLY_COERCE`); `rn_without_fragments` вызывают только при наличии фрагментов.
