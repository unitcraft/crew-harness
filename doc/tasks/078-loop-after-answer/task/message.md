# Задание: вкладка зациклилась на вопросе после ответа владельца

Заказчик: владелец репозитория `unitcraft/crew-harness` (он же отвечает на вопросы и принимает результат).
Репозиторий: `unitcraft/crew-harness`, ветка `main`. Дата задания: 2026-10-17.
Источник: 2026-10-17 исполнитель #94 «Выпустить Windows seed Carina 0.2.1» (проект nova, вкладка `nova.worker`) шесть раз подряд задал
владельцу один и тот же вопрос «Разрешить Phase 1?» (формы `frm_14a3f1d8…`, `frm_14a76c5a…`, `frm_14aae3a9…`, `frm_14abc31d…`,
`frm_14abd0fc…`, `frm_14af2ad4…`, `frm_14b…`), хотя владелец ответил «Разрешить Phase 1» через `crew-answer` пять раз и интегратор с
приёмщиком подтвердили то же письмами. По записи сессии вкладка на каждое служебное напоминание («Не завершено: задача #94 …
Продолжай работу») за секунды вызывает `question`, не читая письма с ответом, которые приходят в том же пакете доставки. Phase 1 не
начата около пяти часов; владелец видел в списке то дубли форм, то «ждёт вас», хотя ответ уже был. Это третий случай за день, когда ответ
владельца не доходит до вкладки (1: форма устарела после повтора — задачи 071 и 073; 2: ответ не применён, ход вкладки кончился; 3: цикл
«вопрос → ответ → напоминание → тот же вопрос»).

Задача полная: разбор, реализация, сдача. Быстрый путь. Основа — свежий `origin/main`.

## Чего хочет владелец

- «по рекомендации» (владелец, 2026-10-17, чат оркестратора) — на предложение оркестратора завести задачу: если вкладка задала тот же
  вопрос с теми же вариантами трижды после ответа владельца, плагин не будит её письмом, а показывает владельцу одну строку «вкладка
  зациклилась на вопросе» и предлагает переназначить.

## Что нужно

1. **Разбор:** как возникает цикл по коду и по данным (`form-wait.ts`: `form-repeat`, `nudge` по обязательствам вкладки, `owner-answer.ts`:
   письмо `owner-answer-<id>`, `crew-answer.mjs`; запись сессии в `opencode.db`, только чтение): что видит вкладка в пакете доставки
   (порядок письма-напоминания и письма-ответа, текст), почему письмо с ответом не меняет её поведения; можно ли это исправить текстом
   (например, ответ владельца идёт первым и отдельным сообщением, напоминание вкладке с открытой формой не отправляется, пока ответ в
   пути) или нужен отдельный признак цикла. Не угадывать: показать пакет доставки одной вкладки (сообщение пользователя целиком) и число
   повторов вопроса по записи.
2. **Признак цикла:** у одной вкладки трижды (константа) подряд форма с тем же `formKey` (071: текст и варианты) или с тем же набором вариантов
   (073) создана ПОСЛЕ ответа владельца на предыдущую форму (есть `answered`/`owner-answer` для предыдущей). Тогда:
   - вкладку больше не будить напоминаниями об этом вопросе (письмо-напоминание «Ты остановился, не закончив» не уходит, пока цикл
     открыт);
   - владельцу — одна строка в «Ждут вас» и `/crew` (счётчик `loop`): «вкладка зациклилась на вопросе: <вопрос> (ответ дан N раз)» с
     предложением: переназначить задачу (`crew_task reassign`) или написать вкладке прямо; значок отметки — по соглашениям 055/056/062;
   - интегратору проекта (автору задачи) одно письмо: «исполнитель зациклился на вопросе, владелец ответил N раз; переназначь задачу с
     ответом в цели»;
   - признак снимается рабочим ходом вкладки (вызов инструмента не `question`), её закрытием, переназначением или словом владельца.
3. **Не ложные срабатывания:** вкладка, которая задаёт тот же вопрос после ответа, потому что ответ не дошёл (ход не был прерван,
   `interrupted=false`, письмо не доставлено) — это не цикл, а потеря доставки (задачи 071/073); цикл считается только после доставки письма с
   ответом. Разные вопросы с одним общим набором «Да/Нет» не считаются, если текст различается и между ними был рабочий ход.
4. **Тесты:** красная проба до кода (источник: трижды подряд вопрос после доставленного ответа → признак, одна строка владельцу, письмо
   автору, напоминание не уходит; границы: ответ не доставлен, рабочий ход между вопросами, разные вопросы); полный `npm test` по 8
   параллельно ([AGENTS.md](../../../../AGENTS.md), п. 9); golden — только изменившиеся ключи.
5. README плагина — абзац.
