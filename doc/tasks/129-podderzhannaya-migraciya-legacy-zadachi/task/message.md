## Критерии приёмки

1. Документирована команда legacy→fast с явным owner word; metadata вручную не редактируется.
2. Миграция сохраняет номер, session IDs, branch, worktree, sessions, rounds, history и evidence; дубликат 092 невозможен.
3. Есть негативные тесты без owner word и с некорректной постановкой, плюс позитивный тест.
4. Повторная миграция идемпотентна либо безопасно отказывает.
5. Exact-SHA CI, precheck, independent acceptance и merge lock не обходятся; старые FAIL и waiver не преобразуются в GREEN.
6. Независимая приёмка CrewHarness и точная инструкция Nova.
