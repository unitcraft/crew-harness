## 1. Что перенято из образца `claude-limits/src/web`

- Страницу отдаёт бинарник целиком: CSP запрещает встроенные `<style>` и `<script>`; три отдельных файла (`index.html`, `app.css`, `app.js` как модуль), в `index.html` комментарий-объяснение.
- Нет внешних ресурсов (шрифты с внешних адресов в образце — ловушка): системные шрифты, проверка внешних ссылок.
- `check-page.py` образца ловит четыре вещи: внешние URL (включая IP и IPv6), встроенный код (в том числе `on*=` без учёта регистра, после вырезания комментариев), локальные `href`/`src` на несуществующий файл, `var(--x)` без определения. Перенесено на Node в `test/page-check.mjs`; сверх образца: `style=""`, `url()` в css, `import` в модулях, `ws:`/`wss:` как внешние, `innerHTML`/`outerHTML`/`insertAdjacentHTML`/`document.write`/`eval`/`new Function`/`setAttribute("style")`/`DOMParser`, наличие тёмной темы; переменные ищутся во всех блоках `:root`.
- `live.js` образца (транспорт с внедрёнными таймерами, разрыв без браузера) перенят в `transport.js` (поддельные таймеры и сокет, ступени повтора); `format.js` (чистая логика отдельно под тестами) перенят как `state.js`.
- Не перенято: настройки, графики, перетаскивание.

## 3. Формат события страницы

`{ id, trace, step, kind, input, time }`: `trace` — идентификатор сессии, `step` — номер в цепочке, `input` — объект, `time` — мс эпохи. Виды: `session_created{name,agent}`, `user_message{turn,text}`, `agent_chunk{turn,text}`, `agent_done{turn}`, `agent_refused{turn,reason}`, `permission_request{turn,request,action,detail}`, `permission_decision{request,decision}`, `cancel{turn}`, `error{turn,message}`. Решения владельца страница шлёт теми же событиями и сама не применяет: они приходят обратно в потоке.
Расхождения с `Event` из 091 (`id, trace, step, kind: EventKind(Input|Progress|Answered|Refused|Expired), name, request, input: str, at`): у страницы `kind` — имя события, у 091 имя в `name`, а `kind` — класс; `input` у страницы объект, у 091 строка; `time` ↔ `at`; `request` у 091 — у страницы в `input`; у 091 нет видов `session_created`, `permission_request`, `permission_decision`, `error`. Рекомендация: сервер при отправке по `/ws` делает проекцию «091 → страница» (`name → kind`, `at → time`, `input` разобрать в объект), а не меняет страницу.
