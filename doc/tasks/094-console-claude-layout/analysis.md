# Разбор 094: пульт продукта — раскладка и стиль по образцу интерфейса Claude Code

Задание — `task/message.md`. Источник: слова владельца в чате оркестратора, 2026-10-18: «бери за основу дизайн Claude Code» (дважды, со скриншотами вкладки Code настольного приложения Claude); до этого — «тема светлая и тёмная». Берутся только раскладка и приёмы; названия, логотипов, иконок и текстов образца в странице нет.

## 1. Состав: что менялось, а что нет

- Остались без изменения по сути: чистый редьюсер (`state.js`, дополнен новыми видами событий), `transport.js`, `serve.mjs`, `package.json`.
- Переписаны: `view.js`, `app.css`, `strings.js`, `mock.js`, `index.html`.
- Новые: `lists.js` (чистые функции: фильтр и группировка сессий; `state.js` их переэкспортирует), `theme.js` (ставит тему до первой отрисовки), `icons.svg` (32 своих символа-значка).
- Тесты: новые `work.test.mjs`, `list.test.mjs`, `theme.test.mjs`; расширены `mock`, `page`, `state`, `strings`; `page-check.mjs` проверяет `icons.svg` (обязателен; каждый `'i-имя'` из модулей есть в спрайте; внешняя ссылка внутри — красная), имя образца в файлах страницы — красное.

## 2. Решения

- Три колонки: слева поиск, «Новая сессия» (в форме поле проекта), группы «Закреплённые» и по проектам со «+», дочерние сессии с уголком, точки состояния, закрепление, статус соединения; в центре верхняя полоса, плашка владельца справа, ответ агента обычным текстом (абзацы, списки, код в строке и блоками), строка работы с точками и таймером, поле ввода; справа карточки «Окружение», «Контекст» (красная от 90 %), «Результаты», «Фоновые задачи».
- Рабочие строки: подряд идущие инструменты, запросы разрешений и фоновые команды сворачиваются в одну серую строку-сводку («Выполнено действий: 3 · с ошибкой: 1»), раскрываются по клику, `aria-expanded`, доступно с клавиатуры. Текст до и после инструмента делится по `step`.
- Карточка «Изменено файлов: N» — отдельное событие `file_diff{path,added,removed}`; файлы с иконкой, именем, серым путём, `+N −M`, «Показать все (N)».
- Новые виды событий: `usage_update`, `tool_call`, `tool_call_update`, `output_file`, `file_diff`, `background_task`, `background_task_update`; повтор `id`, мусор и устаревшие обновления — как в README.
- Таймер идущей работы — через `turnStartedAt` и `view.tick()`; отмена хода снимает идущие инструменты и фоновые команды хода (для реального сервера пересмотреть); закрепление живёт на странице до перезагрузки; `--fill` и `--ring` задаются через CSSOM, а не `style`.
- Темы: светлая, тёмная и «как в системе» с переключателем и `localStorage`; `theme.test.mjs` проверяет контраст не ниже 4,5:1 по всем парам обеих тем и равенство двух блоков тёмной темы; цели нажатия 40 px.
- Список запрещённых имён ловит в `app.css` числовые значения размеров; значения заменены соседними.

## 3. Расхождения с заданием

- Не сделано: плашка обновления и строка учётной записи внизу левой колонки (у продукта нет таких данных); внизу только статус соединения.
- Заглушки без действия: «/» для команд, «+», микрофон, режим разрешений, выбор агента, модели, усилия; названия моделей нейтральные.
- Порог узкого экрана 800 px (в 093 было 760); правая колонка до 1100 px скрыта и выезжает по кнопке (из двух вариантов задания выбран этот).
