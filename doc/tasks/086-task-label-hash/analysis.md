# Разбор 086: все задачи везде подписываются одинаково — «#N»

Задание — `task/message.md`. Источник: владелец, 2026-10-18, чат оркестратора: «разве задачи мы не называем через # ?» и «а где унификация?» — задача 083 свела подпись crew-harness к трём цифрам без `#`, у
задач других проектов осталось «#94»: два вида подписи рядом.

## 1. Как места шли к подписи

Весь вывод идёт через одну функцию `taskNo` в `tasks.ts`; после 083 отдельных мест, где подпись склеивается руками, не осталось (страж TL-4 в `crew-task-label`).
- `taskNo` теперь пишет «#N» для любого проекта, с папкой и без, без нулей слева; больше 999 — как есть («#1000»); строковый «061» тоже даёт «#61». Параметры `project` и `folder` остались в
  сигнатуре, подпись от них не зависит; `OWN_PROJECT` и импорт `CREW_DIR` из 083 удалены.
- `taskRef` и `sessionRef` идут через `taskNo` без правок. Заголовки сессий строятся через `taskNo` и `sessionRef`: `syncTitles` (`index.ts`), запуск сессии, приёмщик (`ctx.session.create`),
  `sessionTitleRef` (`task-folders.ts`), `sessionLabel` (`core.ts`). Панель, `/crew`, поле `ref` сводки (`status.ts`), письма и уведомления (`core`, `index`, `review`, `precheck`, `answer`, `profile-cmd`),
  тексты `idle-tab.ts` и `crew_task` (`mcp.ts`) правок не потребовали.
- `TAB_RE` в `status.ts` остался `^(?:#\d+|\d{3,}) \S+` и читает обе формы заголовка; теперь экспортируется. `tabOf` для старой формы («061 исп») заменяет ведущие цифры на «#61». `syncTitles` строит
  заголовок «#61 …» и сравнивает с `titleShown`: вкладки, названные до 086, переименовываются сами (лимит 3 за проход и порог в сутки сохранены).
- Стражи в `scripts/` подпись не разбирают (`^\d{3}` там — номера папок на диске). Номера на диске остались тремя цифрами: `pad3` в `task-numbers.ts`, `index.ts:1787`, `review.ts:516`.
- Тексты для агентов обновлены: справка `crew_help`, описание `crew_spawn`/`title`, «One task, one number», пример «#45 С4-3» в `core.ts`; README плагина и `doc/canon/process.md` — одной фразой на место.
