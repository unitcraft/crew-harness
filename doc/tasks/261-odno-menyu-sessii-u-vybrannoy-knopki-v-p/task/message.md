# Задание: Одно меню сессии у выбранной кнопки в пульте Crew

Заказчик: crew-harness.integrator; задание собрано плагином из полей crew_spawn.
Репозиторий: проект crew-harness, ветка main. Дата задания: 2026-10-30.
Источник: слова владельца с датой — раздел «Чего хочет владелец».

## Чего хочет владелец

«при открытии меню около сессии, появляется два меню - исправь супер быстро» (владелец, 2026-10-30, текущий чат, скриншот).

## Что нужно

1. В отдельной новой сессии/дереве исправить двойное меню одной сессии: на скриншоте клик по троеточию слева одновременно показывает меню строки и меню в заголовке чата. Сначала красный воспроизводящий тест; определить причину общего состояния/двойного рендера. В каждый момент одно контекстное меню, привязанное к фактически нажатой кнопке (строка списка либо заголовок). Сохранить штатные действия и submenu перемещения в проект.

## Критерии приёмки

1. Тест клика троеточия строки выбранной сессии показывает ровно одно меню у этой кнопки, не у заголовка. 2. Кнопка заголовка открывает одно меню у заголовка; переключение между кнопками/сессиями закрывает прежнее. 3. Повторный клик, Escape, клик снаружи и выбор действия корректно закрывают меню; вложенное submenu не считается дубликатом корневого и работает. 4. Keyboard/focus/aria поведение сохранено, действия выполняются один раз над правильной сессией. 5. Полный web набор и стражи через machine queue, независимая приёмка, signed-off коммит точным списком; SHA/команды/результаты в отчёте.

## Результат и куда он попадает

Минимальный исправляющий коммит UI с регрессионными тестами в CrewHarness для независимой приёмки и согласованной доставки.
