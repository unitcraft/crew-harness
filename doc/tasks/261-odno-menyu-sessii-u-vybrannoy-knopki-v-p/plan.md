# План 261 — Одно меню сессии у выбранной кнопки в пульте Crew

## Диагноз

Состояние меню в `src/web/session-row.js` — `menu = { id, sub }` — ключуется только по id сессии.
Выбранная сессия рисуется дважды: строкой в списке (`view.js` `sessionRow` → `sideKit.menuFor(s, …)`) и шапкой чата
(`syncHeadMenu` → `sideKit.menuFor(headCtx.session, …)`). Оба вызова видят совпадение id и рисуют меню — на экране два
меню одной сессии. aria-expanded тоже «true» у обеих кнопок.

## Решение

Привязка меню к нажатой кнопке: `menu = { id, sub, at: 'row' | 'head' }`.

- `menuFor(session, ctx, at)` отдаёт меню только своему месту; в `view.js` шапка зовёт с `'head'`.
- `moreButton` → `at: 'row'`, `headButton` → `at: 'head'` (общий `menuButton`): повторный клик по той же кнопке
  закрывает, клик по другой кнопке переносит меню к ней (прежнее закрывается).
- Переходы в submenu «Переместить в проект» и «Назад» сохраняют `at` (`{ ...menu, sub }`).
- Подпись списка `sig()` уже включает `menu` целиком — `at` перерисовывает обе кнопки.
