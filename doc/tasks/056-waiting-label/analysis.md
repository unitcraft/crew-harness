# Разбор 056: фраза ожидания показывается «ждёт указаний», а не «вопрос»

Задание — `task/message.md`. Быстрый путь, основа — ветка `batch5-1015` `a7a0ce1` (влита в `main` как `a393a2e`). Записан оркестратором по отчёту исполнителя (инструмент записи у исполнителя отказал).

## 1. Почему панель показывала вопрос, которого нет

1. `endsWithQuestion` (`opencode-plugin/status.ts`) находит в конце хода и строку с «?», и фразу ожидания (`WAITING_PHRASES`) — нарочно, чтобы ждущая вкладка не получала «продолжай». Что именно нашлось, она не сообщала, и `statusOf` всякий найденный конец хода сессии задачи звал `question`: панель — «вопрос — ждёт ответа», `/crew` — «ждёт ответа (интегратора или вас)».
2. Из двух фраз источника `endsWithQuestion` узнавала только «Ожидаю дальнейшего решения по #23.» (слово «решени»). «Сообщил интегратору, что жду дальнейших указаний.» перечень не знал: в источнике вкладку, видимо, пометила другая строка из трёх последних. Перечень по своему правилу расширяется по реальным примерам — добавлено «указани» (и в `NOT_OWNER_WAIT`: «жду указаний приёмщика» — не ожидание владельца). Следствие: вкладка с фразой «жду … указаний» теперь не получает «продолжай».

## 2. Что сделано

1. `endOfTurn(text)` → `{ text, wait }`: `wait` — найденная строка без «?» в конце, то есть фраза ожидания. `endsWithQuestion` стала обёрткой и возвращает строку, как прежде: сторож потока и подталкивание в `index.ts` не менялись.
2. Состояние вкладки то же (`owner` у вкладки владельца, `question` у сессии задачи), добавлено поле `wait: true`. Подпись: сессия задачи — `ждёт указаний с ЧЧ:ММ: <фраза>` (`ждёт указаний интегратора` / `владельца`, если фраза их называет — `waitLabel`); вкладка владельца — `ждёт вас с ЧЧ:ММ: <фраза>`, слова «вопрос» нет.
3. Значок ожидания — `‖` (`WAIT_MARK`, `markOf`): пауза в одну колонку. `⏸` в терминале бывает шириной в две и сбивает колонки узкой панели, `…` уже значит обрезку. `?` — ждёт вас, `▶` — задал вопрос текстом, как в 055.
4. Панель: строка сессии задачи — `ждёт указаний` или `вопрос — ждёт ответа`, под ней приглушённой строкой — фраза или вопрос (`↳ …`, до 26 знаков). Сводка «Ждут вас» у вкладки владельца с фразой ожидания — `‖ <проект> <вкладка>`. `/crew` — тот же значок. `/ask` — `‖`, «ждёт указаний N мин».
5. README плагина описывает значок `‖` и подписи. Снимок `test/answer-golden.json`: изменились только «crew: sidebarLines» и «crew: sidebarLines, texts».

Пример (тест `crew-sidebar`, ширина 32):

```
‖ #22 прм   ждёт указаний
    ↳ Сообщил интегратору, что жд…
▶ #7 исп    вопрос — ждёт ответа
    ↳ Базу опустить?
```
