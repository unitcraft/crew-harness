- **Сличение типов операндов** (`цвет == 5` принимается): пробел проверки пакета, не голых имён; записан в README пакета как остаток. → не нужно, потому что в 2.22 это кандидат Методики (вопрос в её письме), а не работа этой задачи.
- **Итог стороны `machine` принимает встроенный тип**, спека говорит «как прежде»: отказ был бы изменением поведения вне списка. → не нужно, потому что вопрос к Методике, поведение прежнее.
- **Левый операнд `??`** получает тип места, а спецификация такого места не называет. → не нужно, потому что вопрос к Методике; README исправлен.
