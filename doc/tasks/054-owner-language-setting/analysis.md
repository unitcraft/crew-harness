# Разбор 054: язык владельца — настройка; письма между вкладками — на языке владельца

Задание — `task/message.md`. Быстрый путь; основа — `main` `cd4d778`. Записан оркестратором по отчёту исполнителя (инструмент записи у исполнителя отказал).

## 1. Что было

- Системный блок вкладки (`opencode-plugin/index.ts`, хук `context`) держал зашитое правило: «Everything the owner reads (replies, questions, option texts, reasons) is in Russian». Язык — в коде; письма вкладкам (`crew_send`) и отчёты задач в перечне не названы. Владелец видит их во всплывающем уведомлении и во вкладке получателя — отсюда письмо исполнителя Новы по-английски (владелец, 2026-10-15: «а почему на англ?»).
- В описаниях инструментов о языке текстов не было ни слова.

## 2. Настройка

- **Ключ `owner_language`** (группа «Прочее», рядом с `project_rules`), значение — имя языка по-английски: `Russian`, `English`, `Brazilian Portuguese`. Проверка `crew_config set`: латиница, до четырёх слов через пробел или дефис; пустое, кириллица и предложения отвергаются; `loadConfig` такое значение из файла не берёт и откатывается к умолчанию.
- **Умолчание — `Russian`.** Довод: сейчас все проекты владельца получают русское правило; с этим умолчанием ни один проект не меняет поведения, и правка файлов настроек владельца не нужна. Имя — по-английски: оно встаёт в английский системный блок (тест TT-1d держит блок без кириллицы), а проверка формы не даёт вписать в блок посторонний текст.

## 3. Что сделано

- **Правило блока строится из настройки:** «Everything the owner reads (replies, questions, option texts, reasons, letters to other tabs and task reports) is in ${owner_language}; code, commands and identifiers stay as they are.» Имена инструментов в правило не вписаны: тест TT-1b запрещает блоку пересказывать инструменты (блок указывает на `crew_help`); «letters to other tabs and task reports» называет то же словами.
- **Предел TT-1e (1100 знаков):** правило выросло на 43 знака, блок стал 1127. Сокращены три фразы без смены смысла: «explain why you think it is needed» → «explain why»; «A task is what changes» → «A task changes»; «only the question tool shows it to the owner» → «only the question tool reaches the owner». Блок по умолчанию — 1092 знака; смена значения, как и `project_rules`, один раз заново оплачивает историю вкладок.
- **Описания инструментов** — общими словами («the owner's language named in your system block»): описания регистрируются один раз на весь плагин, а он обслуживает проекты с разными настройками. Затронуты `crew_send` (текст письма видит владелец), `crew_task` (`submit`, `rework`, `order`, `push`, `cancel`), `crew_spawn` (`title`, `goal`, `criteria`); `crew_config` называет ключ. Остальные инструменты текста владельцу не несут — не тронуты.
- **Справка и документы:** опросник и показ `crew_config` берут ключ из схемы; README плагина (рядом с `project_rules`) — новая настройка.
