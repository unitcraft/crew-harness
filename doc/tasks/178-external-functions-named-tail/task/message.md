## Чего хочет владелец

Слова владельца, 2026-10-25 (чат Методики и оркестратора): ввести хвост параметров `...имя` только для внешних функций, правило AL-129. Формулировка передана исполнителю оформления оркестратором (пересказ); дословная цитата владельца лежит в чате и вносится в журнал при приёмке постановки.

## Что нужно

Цель одной фразой: хвост `...параметры: строка` в объявлении внешней функции и пары в вызове, только у внешних функций.

1. Объявление `...параметры: строка` — последний параметр внешней функции; внутри тела хвоста тип — `словарь[строка,строка]`.
2. У вызова — поле дерева `named:[{name,value}]`; точный вид пар в тексте — как в разделе AL-129 спецификации (здесь не пересказывается).
3. У функции автора хвост — ошибка. Повтор ключа в вызове — ошибка.
4. Рендер дерево → текст сохраняет хвост и пары один в один; схема `machine-2.schema.json` обновляется.
