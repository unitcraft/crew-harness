# Разбор 052: отметка «застряла» не снималась ответом владельца и рабочим ходом

Задание — `task/message.md`. Записан оркестратором по отчёту исполнителя (инструмент записи у исполнителя отказал). Улики живой службы (журнал плагина, файл обязательств, база ходов OpenCode) — только чтение.

## Причина (приёмщик #85 проекта nova, 2026-10-15)

Отметка поставлена до задачи 043: в файле обязательств `{"nudges": 2, "empty": 3, "stuck": true}` без `stuckAt`, поэтому в панели «⚠ застряла» без времени. После перезапуска службы (18:49) `nudge` для этой вкладки вызывался, но снятие молча пропускалось — ни строки `unstuck`, ни `nudge`, ни `nudge skipped`: этот путь журнал не пишет (обязательство `stuck`, `turn.tools` ложно → `continue`, `changed` ложно → выход).

Почему `turn.tools` ложно у работающей вкладки: `busySince` ставится в хуке запроса на каждом запросе модели, то есть на каждом шаге хода, а `nudge` читал ход `lastTurn(session, busySince)` — строки не раньше последнего запроса минус 5 с. Последний шаг хода — обычно текст без инструментов. По базе ходов приёмщика: вызов инструмента в 19:21:17 и итоговый текст в 19:21:27, вызов в 19:38:42 и текст в 19:38:53 — разрыв 10–11 с, больше запаса в 5 с. Рабочий ход читался пустым. Это же, по всей видимости, и поставило отметку раньше (`empty: 3` у работавшей вкладки).

Ответ владельца на вопросник — не строка `user` в базе, а результат инструмента: `turn.owner` он не даёт, а событие `form.replied` только удаляло запись вопросника (задача 040), обязательств не касалось.

## Все пути, где отметка оставалась при живой работе или ответе владельца

1. Ход из нескольких шагов, инструмент не в последнем шаге: ход читается пустым (причина выше).
2. Режимы ответа (`answerTurn` → `handled`): выход из `nudge` до снятия.
3. Сторож потока: сессия задачи кончила ход вопросом, есть не застрявший спросивший — выход до снятия.
4. «Ждёт по-честному»: открытое наблюдение `crew_watch` или открытый вопрос вкладки (`asksOpen`) — выход до снятия.
5. Ход, где писал владелец, без вызова инструментов: снимал только `turn.tools`.
6. Слово владельца посреди хода: до конца хода ничего не происходило.
7. Ответ владельца на вопросник (`form.replied`): отметку не трогал.
8. Показ: вкладка с открытым вопросником (ждёт владельца) показывалась ещё и «застрявшей».

## Что сделано

- `core.ts`: `clearStuck(session, why)` — снимает отметку у всех обязательств вкладки (и у записей без `stuckAt`), счётчики заново, как после `crew_task push`; на каждое — строка журнала `unstuck <сессия> for <qid>: <причина>`. У визитки новое поле `turnStart` — время первого запроса хода.
- `index.ts`: `setBusy` ставит `turnStart` на первом запросе хода и не сдвигает его на следующих; `nudge` читает ход от `turnStart` и снимает отметку первым делом — рабочим ходом (`a working turn`) или ходом владельца (`the owner wrote in the tab`), до режимов ответа, сторожа потока и «ждёт по-честному» (пути 1–5); снятая на этом ходу отметка не даёт напоминания. Проход сводки: у вкладки с отметкой есть слово владельца после `stuckAt` (у записи без `stuckAt` — после старта процесса службы) — снятие на ближайшем проходе (путь 6). Ответ на вопросник — сразу из события `form.replied` (путь 7).
- `form-wait.ts`: `removeForm` возвращает сессии снятых записей (событие ответа бывает без сессии); `handleFormEvent` и `startFormWait` принимают `onReplied`.
- `status.ts`: при состоянии `owner` (вопросник, вопрос владельцу, залипший ход) `stuck` в состояние не пишется — в `/crew` и боковой панели нет «⚠ застряла»; отметка в обязательствах остаётся (путь 8).
- README плагина: ход — от первого запроса; правила снятия.

## Что не ослаблено

- Пустые ходы (письмо плагина, без инструментов) по-прежнему растят `empty` и ставят «застряла» со временем, спросившему — вызов; следующий пустой ход отметку не снимает (клетки 7, 7a нового теста; строки T1–T7 матрицы 042).
- `crew_task push` снимает, как раньше (T1e матрицы); код push не менялся.
- Открытый вопросник сам по себе отметку не снимает, только скрывает показ (клетка 6a); застрявшая вкладка без вопросника показывается «застряла с ЧЧ:ММ» (клетка 6b).
