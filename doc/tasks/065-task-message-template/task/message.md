1. **Образец в Каноне** (`doc/canon/process.md` или отдельный файл Канона со ссылкой из входа — решить в разборе по

   «Критерии приёмки», «Результат и куда он попадает» (норма методики, process.md), «Связи» (если есть — по
   `task-sessions.md`), «Границы». Для каждого раздела — одна строка, что в нём и чего в нём не бывает. Пустой раздел пишется
   «нет: <почему>», а не пропускается. Отличие от методики (методика формы не задаёт) — записать как отличие проекта с причиной.

   попадает, связи), — добавить; без обязательного поля — понятный отказ с подсказкой, что дописать (как у других отказов
   инструмента). Длинную цель не сливать в один абзац: «Что нужно» — пунктами. Совместимость: прежние вызовы `crew_spawn` без

   `task/message.md` есть все разделы образца в порядке; старые задания не судятся. Красная проба: задание без раздела —
