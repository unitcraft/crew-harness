## Существенные находки

1. Правило «какая строка запуска действует» при отсутствии времени в строках записывает в «запущена» уже закончившуюся или остановившуюся сессию.
   - Что не так: по REQ-14 строка запуска для С5 пишется в основную копию, когда дерева ещё нет, а сама сессия потом пишет в дерево. По REQ-03 запуск
     исключён из сравнения копий и «действует» над выбранной копией, если в той нет строки после него; сравнение по времени возможно, только когда время есть
     у обеих строк, «иначе — когда последняя сессия выбранной копии закончена (состояния 1 и 2 REQ-04) или её код отличается от кода запуска». Поле времени
     необязательно (REQ-12, В-09 (а)), строк без него много (забытые часы, переходный период), страж такую строку не красит. Пример: основная копия
     заканчивается строкой `С5 0/0 запуск`, в дереве `С5 0/14 старт … С5 14/14 готово` (или `С5 13/14 стоп: ворота — …`) без `[ЧЧ:ММ]`. Выбранная копия — дерево;
     времени нет — берётся запасная ветка «последняя сессия закончена»; запуск «действует» и перекрывает «готово» или «остановилась: ворота» состоянием
     «запущена, шагов нет» (строка 3 REQ-04), а через 10 минут — «давно нет вестей», с меткой «внимание» и на 24 часа. Код запуска совпадает с кодом закончившейся
     сессии, поэтому условие «код отличается» не спасает. Тот же сбой для С7, С7п, С8, С9, которых REQ-14 тоже ведёт в основную копию, если они работают в
     дереве (источник места их работы в spec.md не назван). Это противоречит желанию «закончившиеся исчезают сами» и «остановилась — не пугать» (Пр-01, О-04),
     а AC-24 («запуск в основную копию до создания дерева, затем `старт` в дереве») проверяет только случай со временем и со строкой `старт`, не конец сессии.
   - Цитата: «иначе — когда последняя сессия выбранной копии закончена (состояния 1 и 2 REQ-04) или её код отличается от кода запуска» (REQ-03).
   - Место: spec.md, REQ-03, REQ-14, REQ-04 (строки 1–3), AC-24.
   - Предложение: запуск не действует, если в выбранной копии есть строка `старт` (k = 0) с тем же кодом или любая строка сессии с тем же кодом после общего
     префикса; запасная ветка — только для кода, которого в выбранной копии после префикса нет; добавить в AC-24 случай «запуск в основной копии, в дереве вся
     сессия без времени до `готово` и до `стоп:`».
   - критичность: существенная (допустимый по тексту вход — строки без времени — приводит к неверному состоянию на главном экране задачи; сценарий приёмки этого не ловит)
   - уровень: требования

## Поверхностные находки

2. В-11, Р-14 и REQ-10 утверждают, что служба читает настройки «только по событиям, периодического опроса нет», а в коде такой опрос есть.
   - Что не так: `flowWatch` (`index.ts:888–897`) раз в 60 секунд проходит по проектам с задачами плагина и зовёт `loadConfig(any.directory)`; шаг `watches`
     (`index.ts:1227`) читает `machineSlots` проектов на каждом проходе. Поэтому «периодического чтения настроек по проектам нет» неверно. Вывод не меняется:
     окно читать настройки не может (0,55 с блокировки), у этого репозитория задач плагина нет, а общий файл смешал бы проекты; но владелец получает в В-11
     довод, который частично ложен.
   - Цитата: «служба читает настройки только по событиям (периодического опроса нет, Р-14)» (В-11); «а служба читает настройки не периодически, а по событиям» (REQ-10).
   - Место: spec.md, В-11, REQ-10, Р-14.
   - критичность: поверхностная — решение (а) и все требования верны по другим доводам (окно не читает, служба не меняется); меняется формулировка довода, а не число или сценарий.
   - уровень: требования

3. Регулярное выражение строки Д-11 в Python и JavaScript различается: `\d` в Python принимает цифры любых алфавитов, в JavaScript — только ASCII.
   - Что не так: проба 2 — `С5 ٣/٤ x` страж (Python) разберёт как строку, плагин — нет. Шаблон времени одинаков (проба 2), а общий набор строк AC-26 проверяет только его.
   - Цитата: «Регулярное выражение строки — `^(\S+) (\d+)/(\d+) (.+)$`» (Д-11).
   - Место: spec.md, Д-11, REQ-16, AC-26.
   - критичность: поверхностная — на реальных журналах (ASCII-цифры, проба 6) разницы нет; чинится записью `[0-9]` или `re.ASCII` в плане.
   - уровень: требования

   - Цитата: «рядом с «давно нет вестей» стоит «ветка N мин»» (AC-19); «и, если помещается, «ветка N мин»» (REQ-07).
