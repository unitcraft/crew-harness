4. Шаблон времени `[ЧЧ:ММ]`, записанный в REQ-04 дословно, не работает в языке плагина.
   - Что не так: в REQ-04 «шаблон `^[[](?:[01][0-9]|2[0-3]):[0-5][0-9][]] `». В JavaScript `[]]` — пустой класс символов и затем литерал `]`: он не совпадает ни с чем.
     Запуск `new RegExp("^[[](?:[01][0-9]|2[0-3]):[0-5][0-9][]] ").test("[10:05] готово")` даёт `false`; с экранированием (`\[` … `\]`) — `true`. В Python тот же текст
     работает, поэтому страж (Python) и плагин (TypeScript) получат разное поведение от одного шаблона. Реализация строго по тексту не распознает время ни в одной строке:
     время вести всегда «по файлу», ключевые слова после времени не найдутся (AC-14, AC-26, AC-03, AC-08, AC-23 с формой со временем упадут).
   - Цитата: «шаблон `^[[](?:[01][0-9]|2[0-3]):[0-5][0-9][]] `» (REQ-04).
   - Место: spec.md, REQ-04, AC-14, AC-26.
   - Предложение: записать шаблон с экранированием (`^\[(?:[01][0-9]|2[0-3]):[0-5][0-9]\] `) или только словами; в AC-26 добавить проверку, что один и тот же набор строк даёт одинаковый разбор в
     плагине и в страже.
   - критичность: существенная (дословный шаблон ломает главный путь распознавания времени и ключевых слов)
   - уровень: требования
