## Чего хочет владелец (его слова, 2026-10-17, чат оркестратора)

- «по рекомендации» — на предложение оркестратора: настройки проекта ищутся по проекту (имя в карточке вкладки), а не по папке
  вкладки; красная проба: вкладка в рабочем дереве, `/crew-sets use` пишет в основную папку проекта.

## Что нужно

1. **Разбор:** все места, где проект или папка настроек ищутся по `directory` вкладки (`projectFor`, `rawSettingsFor`,
   `profileState`, `tabDir` в `tui.ts`, `crew_config`, `configShowText`, `crew_doctor`, сводки), и какие из них должны идти по
   проекту. Как рабочее дерево сопоставляется проекту: имя проекта в карточке вкладки (`cards/<сессия>.json`, поле `project`), а
   не путь; рабочее дерево задачи — `git rev-parse --git-common-dir` указывает на основной репозиторий проекта — выбрать надёжный
   способ и обосновать (не угадывать по имени папки).
2. **Правка:** вкладка в рабочем дереве задачи проекта находит проект и его папку настроек (основная папка, не дерево); запись
   `profile_set`, наборов и файлов окон идёт в основную папку проекта; чтение — оттуда же (настройки ветки задачи не подменяют
   рабочую копию основной папки). Вкладка вне любого проекта — по-прежнему отказ, но другим текстом: «папка вкладки не относится к
   проекту …», а не «задан прежней формой опций».
3. **Тесты:** красная проба до кода (вкладка с `directory` в рабочем дереве задачи, проект с папкой настроек: `use`, `show`,
   `ls` и `crew_config show` находят проект и пишут/читают основную папку; вкладка вне проекта — свой отказ; вкладка в основной
   папке — как прежде); полный `npm test` параллельно до 4, упавшие — отдельно
   ([AGENTS.md](../../../../AGENTS.md), пп. 8–9); golden — только изменившиеся ключи.
4. README плагина — абзац: проект и папка настроек находятся по проекту вкладки, не по её папке.

## Критерии приёмки

1. Вкладка в рабочем дереве задачи проекта: `use`, `show`, `ls` и `crew_config show` находят проект и пишут и читают основную
   папку проекта, а не дерево.
2. Вкладка вне любого проекта получает отказ «папка вкладки не относится к проекту …»; вкладка в основной папке работает как
   прежде.
3. Красная проба написана до кода; полный `npm test` зелёный (упавшие при параллельном прогоне перепроверены отдельно); README
   плагина описывает поиск проекта по проекту вкладки.
