# Разбор 088: гонка «замок вливания — отметка о слитом» в precheck и остаток нестабильных тестов

Задание — `task/message.md`. Источник: слово владельца в чате оркестратора, 2026-10-18: «заводи 088» — на предложение после сдачи 085 починить настоящую гонку в коде и дотянуть тесты, найденные и не исправленные в 085.

## 1. Гонка в `releaseLandedLock` (`precheck.ts`)

- **Было.** Сначала `releaseMergeLock` (удаление файла замка и `wakeLockWaiters` с записью писем — не мгновенно), потом `cur.precheck.landed` и `taskEvent` (одна запись файла задачи). Между шагами другой процесс видит «замка нет, отметки нет»: accept (`core.ts`, около 2804: `holdsMergeLock || landedFresh`) отказывает «Сначала замок вливания».
  Хуже: если служба умирает между шагами, замок снят, отметки нет, вершина целевой ветки уже сдвинулась, повторное слияние невозможно (`sameTip`) — задача застревает насовсем.
- **Читатели `landed`:** только `landedFresh` (accept) и `markPrecheckStale` (снимает `landed`); больше никто.
- **Решение — порядок «сначала отметка, потом замок».** Отметка `landed` и событие истории — одна атомарная запись (`saveTask` пишет tmp и переименовывает), и только затем `releaseMergeLock`. Промежуточное состояние «отметка есть, замок держится»: accept держателя проходит по замку, чужой или второй — по `landedFresh`; ничего не теряется.
  Смерть между шагами оставляет замок при готовой отметке; следующий проход службы видит `landed` (`if (!cur.precheck.landed)`), не пишет отметку и событие второй раз и снимает замок (идемпотентно, в том числе при двух процессах-службах).
  Смысл проверок слияния (замок по проверенному кандидату, `sameTip`, маркеры `GATE:*`, доказательство красного `landing-red`) не тронут. Добавлен шов `seams.betweenLandedSteps` (синхронный, между шагами). Запись истории «замок отпущен: слияние…» теперь появляется на мгновение раньше фактического снятия замка; проверка REL-6 этого не замечает.
- **Красная проба до кода — детерминированная.** Две ячейки AC-19b в `crew-landing-race.test.mjs`: (1) «window» — внутри шва запускается настоящий второй процесс (`landing-child.mjs`) и делает accept; (2) «crash» — шов бросает исключение (смерть службы), следующий проход должен дозавершить отпускание.
  На старом порядке обе красные детерминированно («Сначала замок вливания … | lock undefined landed false»), после правки зелёные.

## 2. Остаток нестабильных тестов (приёмы те же, что в 085)

Положительные «успеет» — ожидание условия (`until`, предел 60 с) вместо фиксированных пауз; пауза остаётся там, где проверяется отсутствие события («ровно одно письмо», «нет второго письма», «окно не закрыто охранником»); фальшивое биение окна датировано на 30 с вперёд там, где свежесть окна не проверяется. Все ячейки и проверки (тексты, количества, состояния) прежние.

| Тест | Что изменено | Что проверяется по-прежнему |
|---|---|---|
| `crew-nudge-matrix` | биение +30 с; общий `until` по положительным рядам M01–M23 перед паузой 1500 мс; `turn()` ждёт конца доставок; пределы 3/4/8 с → 60 с; циклы 20×250 мс в T10 → `until` | все 52 ряда и три известные дыры (M15a, M11b, T9), паузы для «ровно одно» |
| `crew-answer-flow` | `go()`/`sessionTurn()` с `ready`; AC-01…AC-30 ждут условия; AC-30 б: 8 с → 60 с; AC-15: 8 с → 60 с | паузы 1300 мс и 800/1200 мс для «повтор ничего не меняет» |
| `crew-landing-tip` | абсолютные пределы (`<= 20+5 с`, `< 20+12 с`) → плюс запас, измеренный в том же процессе (30 × время запуска `git --version`, не больше 30 с); паузы «процесс виден/ушёл» → `until` | нижняя граница «>= 14 с» и «процессов git с адресом не осталось» |
| `crew-landing-gate` (AC-11 молчит) | абсолютные 30 с → `TIP_TIMEOUT_MS` + 10 с + тот же запас; пауза 1500 мс → `until` «git-процессов нет» | проверки прежние (на тихой машине предел чуть мягче, +1,5–4,5 с) |
| `crew-review`, `crew-submit`, `crew-owner-wait`, `crew-gate-stop`, `crew-idle-tab`, `crew-esc-question`, `crew-answer-loop` | фиксированные паузы перед положительными проверками → `until`; биение +30 с; в `crew-answer-loop` пределы 4–8 с → 60 с | паузы «нет письма / нет петли / окно не закрыто» |
