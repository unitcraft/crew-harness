## 1. Что сделано

- **AC-1, название.** `sidebarLines`: работающая сессия без задачи (`s.task` пусто, не вкладка интегратора) получает над строкой роли название карточки: `titleText`, `wrapWords` шириной `width - 2`, не больше двух строк, продолжение «· », последняя строка кончается «…», тон `base`. Строка роли (`• worker    работает 12 мин`) остаётся. Название не показывается, если оно пусто, равно роли, является номером сессии (`ses_…`) или заготовкой OpenCode («New session - …»). Строки сессий с задачей и вкладки интегратора не менялись.
- **AC-2, «завис?».** Новый ключ схемы `long_turn_minutes` (целое, минуты, по умолчанию 360, 0 выключает; группа «Подталкивание», как `idle_tab_minutes`), в `Config` — `longTurnMin`; задаётся в файле проекта или в блоке `local` настроек плагина. Проход службы пишет в статус работающей сессии `longTurnMs` (порог в мс, только если он включён и есть `since`). `sidebarLines` решает по своему `now`: `state === "working"` и `now - since > longTurnMs` (строго больше) — строка `завис? 42ч` (меньше часа — `завис? 45м`), тон `accent`, как у тревожных строк. `isFree` и `BUSY_MAX_MS` не менялись.
- **AC-3, снятие флага.** `index.ts`, `finishTasks`: новая `releaseBusy(sid, t?)`. Вызывается для сессий (исполнитель, приёмщик, прежние) задач в состоянии `done`/`cancelled` и для карточек с `spawned.status === "closed"` (переданная сессия, `releaseExecutor`). Снимает `busy`, `busySince`, `turnStart` (`setBusy(c, false)`, без письма-подталкивания); после этого прежний код закрывает сессию отменённой задачи (раньше `c.busy` его останавливал).

## 2. Зависший флаг и идущий ход: по каким полям решаем

Корень находки оркестратора (карточка с `busy: true` с 2026-10-17 при отменённой задаче): флаг снимает только событие простоя и, запасным путём, `idleAfter` в проходе, и только для карточек своего процесса службы (`c.pid === process.pid`). Если процесс, поставивший флаг, ушёл (или строка `idle` не пришла), флаг остаётся навсегда; `isFree` через 30 минут освобождает окно для писем, но панель продолжала писать «работает 2540 мин», а `finishTasks` не закрывал сессию отменённой задачи (`c.busy` его останавливал). Перезапуск службы как исправление не доказан (независимая проверка интегратора) и для этой правки не нужен: логика от него не зависит.

Флаг считается **зависшим** и снимается, только если выполнены все условия:

| поле | источник | условие |
|---|---|---|
| задача закрыта | задача `status` | `done` или `cancelled` (или карточка `spawned.status === "closed"`) |
| карточка не чужая живая | карточка `pid` | `pid` — этот процесс или процесса нет (`pidAlive`) |
| запрос не свежий | карточка `busySince` | старше 2 минут (ход мог ещё не дойти до базы) |
| вкладка не занята | окно, `tab.busy` | не занята |
| сессия не на другой открытой задаче | карточка `task`/`review` | нет такой (для закрытой карточки не проверяется) |
| **хода по базе нет** | база OpenCode, `session_message` сессии | `openTurn` ложно: нет строки новее последней `idle`, обновлённой за последние 5 минут, и нет ответа ассистента новее `idle`, начатого в этом процессе службы за последние 45 минут |

Ход **идёт**, если последняя строка сессии в базе не `idle` и обновлялась недавно (`time_updated` свежее 5 минут) либо ответ ассистента начат в этом процессе после последнего `idle`: тогда флаг не трогается, сессия не закрывается, в неё ничего не пишется. «Завис?» на панели решается независимо: только по карточке (`busySince` — последний запрос модели, ставится на каждом шаге хода — и порог); он ничего не снимает и не убивает. Свежий (моложе порога) ход неотменённой задачи остаётся «работает».
