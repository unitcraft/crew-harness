## Критерии приёмки

AC-1. Строка работающей сессии без живой задачи показывает название карточки (не больше двух строк, `…`), а не только роль; строка сессии с задачей не меняется.
AC-2. Сессия в «работает» без обновлений дольше порога показывается как `завис? Nч` другим тоном; порог настраивается, 0 выключает; `isFree` не меняется.
AC-3. При отмене или закрытии задачи флаг `busy` её сессий снимается, если ход не идёт по базе; идущий ход не убивается.
AC-4. Красная проба показана до кода; весь набор тестов плагина зелёный (`npm test`), затронутые файлы устойчивы под нагрузкой (`test:stable`); стражи 8 и больше, FAIL 0.
