## 3. Расхождения и решения

- **Папка модуля.** README и команды лежат в `src/portolan_cli/`, а не в `src/portolan/`: файл `src/portolan.nv` и папка `src/portolan/` — один модуль дважды, компилятор отказывает.
- **Без процесса в тестах.** Программа проверяется целиком через `execute()` под `mock_os`, `mock_fs`, `mock_io`, то есть теми же функциями, что работают в `.exe`; `.exe` проверен руками на реальных файлах.
- **`render` и `convert` с `--lenient`.** Прежний `--render` печатал текст и при заметках (код 1); теперь, как у `compile`, без `--lenient` при заметках текста нет, код 1. Переходных имён нет (слово владельца, 2026-10-19: «нету переходного периода»).
- **Файл `-o`.** Запись только по явному `-o`; существующий файл — код 2 без `--force`; при ошибках в файле ничего не пишется (с `--lenient` пишется). Запись идёт напрямую в файл, поэтому Windows не превращает `\n` в `\r\n`.
- **`test`.** Машины — `*.portolan.json` каталога; `*.portolan.md`/`.txt` переводятся только если сценарий просит машину, которой нет среди JSON. Имя машины — поле `machine` сценария, сопоставляется с `name` машины, а не с именем файла. Каталог без сценариев и несуществующий — код 2.
- **Комментарии при `convert`.** Заметка на стандартной ошибке печатается всегда (определять, были ли комментарии, переводчик не умеет).
- **«Каждый сценарий `agent_step` по строкам».** Понято как «каждый сценарий шага агента отдельным `run`»; покрытие строк машины остаётся за `src/machine_agent/cover_test.nv` (задача 109).
- **Номера пунктов.** В `spikes/env/README.md` последним был пункт 47 (до слияния 114 и 117), новые — 48 и 49; при перебазировании на `origin/main` нумерация сверяется оркестратором (раздел 7).

## 6. Что осталось

- Установка программы, запись в PATH, упаковка в релиз. → не нужно, потому что задание исключило их («без установщика и без изменения PATH»); по слову владельца отдельно.
- Строки в сообщениях об ошибках файла `.json` — всегда `1:1`. → не нужно, потому что JSON получает компилятор, руками его не правят, а путь дерева (`$.states[0].rows[1]`) называет место точно.
- Заметка «комментарии не переносятся» печатается всегда. → не нужно, потому что переводчик не сообщает, были ли комментарии; заметка короткая и идёт на стандартную ошибку.
- Тесты не запускают `.exe` процессом. → не нужно, потому что `execute()` — те же функции под подменой `Os Fs Io`, а сборка и прогон `.exe` на реальных файлах записаны в журнале; сборка в каждом юните стоит минуту.
- Обходы компилятора по остальному дереву не помечены. → задача 118 (отметка остальных обходов `ORACLE-WORKAROUND` по дереву и сторож меток).
- Вложенные машины, `Правит`, профиль стороны остаются `unsupported` переводчика. → задача 119 (Раннер, Запуск сессии, Проверка цикла и «Совещание» как машины Портолана).
