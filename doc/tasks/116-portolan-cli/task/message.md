## Что нужно

1. **Источники:** `src/machine_translate.nv` (текущая команда: `<файл>`, `--lenient`, `--summary`, `--no-check`, `--render [--language ru|en]`), `src/machine_text/` (переводчик, обратный генератор `render*.nv`, таблицы слов), `src/machine_run/` (интерпретатор `PortolanMachine`, прогонщик сценариев `scenario/0`), `src/machine_table/` (проверки), `src/machine/README.md`, `src/machine_text/README.md`, спецификация Портолана 2.11 методики (только чтение; разделы про расширения, язык, канонический вид), `spikes/env/README.md` (пп. 1–43: один каталог — один юнит; вывод юнита ≤ 4096 байт).
2. **Программа `portolan`** (`src/portolan.nv`, сборка `nova build src/portolan.nv -o target/portolan.exe`; `machine_translate.nv` переименовать в `portolan.nv` и убрать старое имя; переходных имён нет). Подкоманды (общая форма ошибок `файл:строка:столбец: вид: сообщение` + цитата строки; код возврата 0 успех, 1 ошибки в файле, 2 неверная команда или аргументы; без аргументов — справка и код 0, потому что `nova test src` запускает каждую программу без аргументов):
   - `portolan compile <файл.portolan.md> [-o <файл.portolan.json>] [--lenient] [--no-check]` — Портолан → JSON `machine/2` (язык файла по шапке); без `-o` JSON на стандартный вывод; с `-o` — в файл (рядом по умолчанию: `<имя>.portolan.json`, если указан `-o` без значения невозможно — запись только по явному `-o`); перезапись существующего файла только с `--force`.
   - `portolan render <файл.portolan.json> [--language ru|en] [-o <файл.portolan.md>]` — JSON → Портолан в каноническом виде спецификации 2.11 (раздел 1б), язык по параметру (по умолчанию `ru`).
   - `portolan convert <файл.portolan.md> --language ru|en [-o …]` — перевод файла с одного языка на другой через JSON (`compile` + `render`), без потери смысла; комментарии-абзацы не переносятся (сказать об этом на стандартной ошибке).
   - `portolan check <файл>` — файл `.portolan.md` (перевод + проверки загрузки) или `.portolan.json` (разбор схемы + проверки); печатает ошибки и предупреждения П-1, код 0 при отсутствии ошибок.
   - `portolan summary <файл>` — сводка машины (состояния, строки, действия, данные, стороны).
   - `portolan run <машина.portolan.json|.portolan.md> <сценарий.scenario.test.json>` — прогнать сценарий `scenario/0` на `PortolanMachine` и напечатать отчёт расхождения или `ok`; `portolan test <каталог>` — прогнать все `*.scenario.test.json` каталога против машин того же каталога (имя машины из поля `machine` сценария) и вывести итог `N из M`; код 1 при расхождении.
   - `portolan version`, `portolan --help` (справка по каждой подкоманде и по форматам).
3. **Круги и сверка.** Тесты (по образцу `src/machine_text_eq/`): на машинах чата, `agent_step` и четырёх пробных — `compile` → `render` → `compile` даёт равный JSON; `convert ru → en → ru` даёт равный JSON; `test` на каталоге `src/machine/` проходит все 131 сценарий и каждый сценарий `agent_step` по строкам; команды дают те же результаты, что функции переводчика. Каждая подкоманда — тест вывода и кода возврата на малых файлах (тесты запускают программу через `std.os` процессом или проверяют функции команды, как у `machine_translate.nv`).
4. **Сборка и поставка.** README `src/portolan/README.md` (английский; можно в `src/machine_text/README.md`, раздел «The program `portolan`»): сборка, подкоманды, примеры, формат ошибок, коды возврата. Скрипт `scripts/build-portolan.ps1`: `nova update` при необходимости, сборка `target/portolan.exe`, выводит путь; без установщика и без изменения PATH (запись в PATH и установка — не в этой задаче). Готовый пример в README: как проверить машину Портолана на русском/английском, превратить в JSON и обратно.
5. **Проверки.** Красная проба до кода (заглушка подкоманд: тесты красные; число красных в `log.md`); не менее 80 новых проверок; `nova test src --jobs 4` и `--strict-effects` зелёные (на временном контейнере PostgreSQL по необходимости: `src/pg/testdb.ps1`, затем `-Stop`); `target/portolan.exe` собран и проверен из окна с консолью на реальных файлах (результаты в `log.md`); стражи 8 и больше, FAIL 0; коммиты по правилам AGENTS.md (английское сообщение, `-s`, без трейлеров и без `#число`, файлы перечнем).
