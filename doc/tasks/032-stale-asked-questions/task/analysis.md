# Разбор задачи 032

## Где хранится

- Вопрос (`crew_send` с `expect_reply`) — обязательство адресата: `obligations/<сессия-адресат>.json`, запись `{qid, from_session, at, ...}` (`core.ts`, `addObligation`). Список «asked» автора в `status/<сессия>.json` не хранится отдельно, а вычисляется заново на каждом проходе `syncStatus` (`index.ts`) обходом обязательств всех визиток. Поэтому «закрыть вопрос» — снять запись обязательства.
- Раньше снимал только ответ с `reply_to` (`settleObligation` в `crew_send`). Висящие записи пережили всё остальное.

## Что сделано

- Письмо адресата автору (любое, без `reply_to`): `closeAskedByLetter` в `crew_send` снимает открытые вопросы этого отправителя к адресату письма (по id сессии или ключу роли автора). Сопоставление — по адресату и времени (вопрос раньше письма); в журнал пишется `asked closed: qid=... by a letter`.
- Сессия-адресат закрыта (спавн `closed`; или вкладки нет, а визитка не обновлялась дольше `LIVE_MS`) либо задача адресата очищена: `askedClosedWhy`, на каждом проходе статуса, в том числе на первом после запуска плагина (так вычищаются уже висящие записи).
- Срок `ASKED_STALE_MIN = 120` (`core.ts`): старше — вопрос идёт в `askedStale`, не даёт состояния `reply`, в `/crew` — отдельная строка «вопрос устарел: к … с ЧЧ:ММ (N м)». Запись обязательства при этом не удаляется (напоминания адресату идут по своим правилам).

## Риск ложного закрытия

Любое письмо адресата автору закрывает вопрос, даже о другом: эвристики по теме нет (она хрупче самой ошибки). Цена ложного закрытия мала: сводка перестаёт показывать «ждёт ответа», а сам вопрос адресат всё равно видел в письме. Письмо от другого адресата вопрос не закрывает (есть тест). Письма, ушедшие, пока плагин не работал, и письма на другую машину не учитываются.

## Не сделано

- Настройка срока в настройках проекта: достаточно константы, пока владелец не попросит иное.
- Закрытие по письму, найденному задним числом в `read/` (только в момент отправки).
- Обязательства сессий без визитки не вычищаются (в сводке они и так не видны).
