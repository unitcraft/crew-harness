## Что нужно

1. **Источники (только чтение).** Методика: `task-runner-review-states.md`, `task-runner-review-automaton.md` (таблица, данные, типы, контракт, «Решения при переводе»), `state-machine-call-protocol.md`, спецификация Портолана 2.11 (русский нормативен); у нас — `src/machine/machines/`, `src/machine_run/`, `src/machine_text/`, `src/portolan_cli/`, итоги задачи 119 (`analysis.md`, `src/machine/README.md`), план 105 (`matrix.md`, `primitives.md`; строки Э3, относящиеся к проверке цикла: D01 D11 D12 D17 D18 D20 D23 D27), тесты плагина `crew-task-route`, `crew-task-hash`, `crew-submit`, `crew-journal` (описывают поведение, которое должно сохраниться). Пути к методике — в промпте исполнителя; в файлах репозитория писать словами.
2. **Разбор (в `analysis.md` первой частью, до кода).** Состояния и переходы по таблице; данные, примитивы и внешние объекты (чтение документов задачи, разность дерева, статус документа); какие примитивы машина зовёт в условиях; что из таблицы не ложится на возможности интерпретатора (список, номера строк); как проверяется равенство с методикой.
3. **Реализация.** (а) `src/machine/machines/cycle_check.portolan.md` (русский вид) и `.portolan.json` (перевод командой `portolan compile`), английский вид — `portolan convert`; круг `compile → render → compile` равен; (б) запись в реестре вызываемых машин («Раннер» зовёт её в задаче 123); (в) примитивы, нужные таблице (`rd_task_document`, `pure_doc_status`, `rd_tree_diff` и другие из строк плана), — как данные реестра с тестовым исполнителем; боевые исполнители в эту задачу не входят; (г) сценарии `src/machine/scenarios/cycle-*.scenario.test.json`: по строке на каждую строку таблицы и сквозные (чистый цикл, доработка, отказ, перезапуск, смерть между изменениями).
4. **Равенство с методикой.** Журнальные коды и параметры на сценариях сверяются с таблицей журнала методики (`state-machine-journal.md`); расхождения — в `analysis.md` и письмом Методике через оркестратора.
5. **Проверки.** Красная проба до кода (число красных в `log.md`); не менее 100 новых проверок; `nova test src --jobs 4 --timeout 600` и `--strict-effects` зелёные (при необходимости на временном контейнере PostgreSQL: `src/pg/testdb.ps1`, затем `-Stop`); стражи `sh scripts/guards/run-all.sh` ок и больше, FAIL 0; `portolan check/compile/render/run/test` принимает машину; коммиты по правилам AGENTS.md (по темам); метки `// ORACLE-WORKAROUND(N): …` на обходах Oracle, новые пункты README — со следующего свободного номера, согласованного с задачей 121 (121 берёт с 70, эта задача — с 80).
6. **README** `src/machine/README.md`: машина, сценарии, что не поддержано.
