# Разбор 097: закрытый список автоответа проверяет действие, а не слово; приёмщики в текстовом пути

Задание — `task/message.md`. Источник: слова владельца в чате оркестратора, 2026-10-19: «не задавайте и не тормозите»; «answer_mode: recommendations … надо доделать»; «по рекомендации, с учетом выше сказанного тут». Быстрый путь. Основа — ветка задачи 096.

## 1. Что сделано

- `form-auto.ts`: `CLOSED_LIST` — таблица из 20 строк «действие → образцы (`act`: глаголы `v`, существительные-действия `n`, объекты `o`, слова предложения `p`) + примеры `yes` / `no`». Вопрос закрыт, если он ПРЕДЛАГАЕТ действие (глагол в предлагающей форме и объект; существительное после слова предложения или в заголовке, подписи, коротком вопросе; прошедшая форма только после «чтобы», «если», «ли»), либо рекомендованный вариант (подпись и описание) содержит такое действие. Причастие, существительное без слова предложения, прошедшая форма, действие после «не» или «без» — описание, не предложение. Новые строки против 096: `config`, `waive`, `rights`; `ceiling` ловит «сверх лимита».
- `answer-parse.ts`, `answer.ts`: исключение «сессия приёмки» снято в текстовом пути (проверка и маркер `GATE:review`, причина в `REST_REASONS` — теперь восемь причин, поле `review` в `ClassifyCtx`).
- Справка `crew_help`, README плагина, `test/README.md`, ADR-0010 («Дополнение 2026-10-19 (вторая часть)»).

## 4. Живая проверка после «обновляй» и перезапуска

Отдельный шаг оркестратора по слову владельца, не часть этой задачи.

1. Журнал плагина: `form <id> of <session>: answered by answer_mode (recommendations, type default)`, `owner answer auto-… applied`; для оставленных владельцу — `left to the owner (closed, <правило>)` со словом-действием, а не словом из описания.
2. Счётчики `/crew`: `form answers N`, `form to you K (closed …)`; строка панели `авто 24ч`. Ожидание: доля `closed` среди уходов заметно ниже прежней.
3. `forms/auto/<форма>.json`: у `held` — `reason: closed`, `rule`, `why`; просмотреть все `held` по `closed` за день.
4. `answers/auto-*.json`: просмотреть вопрос каждого автоответа: ни один не предлагает пуш, слияние, удаление, tag или выпуск, утверждение, принять результат, права, ключи `answer_*`; найден — дефект безопасности, правится строкой таблицы и тестом.
5. `crew_doctor`, «К сведению»: строка «автоответы на формы за сутки …; ушло владельцу …».
6. Текстовый путь: ответ приёмщика на блок `В-NN` без слов ворот пишется как автоответ, блок со словами ворот остаётся владельцу.

## 5. Решения исполнителя и сомнительное

- Пограничные вопросы про роли («разрешить координатора», «временно вернуть роль», «разрешить одному исполнителю … RED и прототип») плагин закрывает: расширение прав явным словом таблица держит; не нужно владельцу решать заранее, потому что владелец отвечал на них «по рекомендации» без правок, а отметки `forms/auto/` за неделю покажут, нужна ли строка.
- Лексика эвристическая: фраза без глагола из таблицы пройдёт; лечится строкой таблицы и тестом, записано в ADR; не нужно менять сейчас, потому что неточность чинится данными, а не логикой.
- «Сверх лимита» удержано у владельца: потолок заходов по ADR-0010 решает только слово владельца; не нужно ослаблять, потому что это закрытый пункт ADR.
