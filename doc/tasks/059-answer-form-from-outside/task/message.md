# Задание: ответ владельца на вопросник — снаружи окна, по слову владельца

Заказчик и владелец: владелец репозитория `unitcraft/crew-harness` (он же отвечает на вопросы и принимает результат).
Репозиторий кода: `unitcraft/crew-harness` (https://github.com/unitcraft/crew-harness, ветка `main`). Дата задания: 2026-10-15.
Источник: владелец переносит рекомендации оркестратора в вопросники окон OpenCode руками; письмо вкладке, у которой
открыт вопросник, не помогает — ход стоит, письма ждут его конца.

Задача полная: разбор, реализация, сдача. Быстрый путь. Основа — `main` (`2a0c283`). **Сначала — проверка
осуществимости** (п. 1); если OpenCode не даёт плагину закрыть вопросник ответом — остановиться и сдать разбор.

## Чего хочет владелец (его слова, 2026-10-15, чат оркестратора)

- «ты сам можешь отправить ответ интеграторам?»
- «заводи 059» — на предложение оркестратора: плагин принимает ответ владельца на открытый вопросник снаружи
  (скрипт с номером варианта или текстом) и закрывает вопросник этим ответом, как нажатие в окне; подаётся только по
  слову владельца в чате оркестратора и помечается в истории «ответ владельца через оркестратора».

## Что нужно

1. **Осуществимость** (`analysis.md`): есть ли у плагина способ ответить на вопрос инструмента `question` (OpenCode
   2.0.x: метод контекста плагина вроде `question.reply`/`permission`-подобного ответа, событие, HTTP-путь сервера
   через контекст плагина без учётных данных). Доказательства — строки бинаря/типов OpenCode (только чтение), как в
   разборе 048; учётные данные сервера не использовать. Запись вопросника плагином — `opencode-plugin/form-wait.ts`
   (задача 040).
2. **Вход снаружи** (если п. 1 — да): скрипт `scripts/crew-answer` (sh или node; имя — по соглашениям `scripts/`)
   кладёт ответ в папку данных плагина (отдельная папка входящих ответов, не ящик писем): проект, вкладка или номер
   вопросника, вариант (номер или подпись) или свой текст, отметка «по слову владельца» с цитатой. Плагин на ближайшем
   проходе отвечает открытому вопроснику, пишет строку журнала, событие в историю задачи вкладки («ответ владельца через
   оркестратора: …»), снимает запись `forms/`. Вопросника нет или он уже отвечен — ответ не применяется, причина — в
   журнале и в файле-ответе. Скрипт без аргументов печатает открытые вопросники (проект, вкладка, вопрос, варианты).
3. **Безопасность:** ответ принимается только из локальной папки данных службы; подделка ответа владельца — та же
   угроза, что запись в ящик писем (журнал — сигнал); в разборе — граница.
4. **Тесты:** красная проба до кода (ответ применяется; неверный вопросник — отказ с причиной; повтор — не применяется
   дважды; история и журнал); полный `npm test` — параллельно до 4, упавшие отдельно ([AGENTS.md](../../../../AGENTS.md),
   п. 9). README плагина — раздел о входе.
