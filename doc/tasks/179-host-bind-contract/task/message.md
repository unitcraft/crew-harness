## Что нужно

Цель одной фразой: `bind_pure(name, f fn([]Value) -> Value)`, `bind_volatile(name, f fn(ReadEnv, []Value) -> Value)`, `bind_acting(name, f fn(mut ActEnv, []Value) -> Value)` и защита от обхода классов.

**Инвариант (одной фразой): изменчивая реализация не пишет в среду; чистая не читает среду.**

1. `ReadEnv` и `ActEnv` — два отдельных `record` с приватным полем (не `protocol`): `ReadEnv` не допускает записи, `ActEnv` нельзя подделать конструированием снаружи.
2. Реализации лежат в отдельном модуле хоста.
3. Страж на импорты эффектных модулей входит в `scripts/guards/run-all.sh` пакета: модуль реализаций чистых и изменчивых функций не импортирует эффектные модули.
4. `nova check --strict-effects` на модуле — без замечаний; `nova info` — `effect_surface` пуста.
5. Тест-хост со счётчиками по классам и сверкой мира: до и после вызова сравнивается состояние среды; обход через замыкание ловится.
6. В спецификации (раздел AL-130) — запись «не доказано типами» готовой формулировкой из письма оркестратора, без правки; текст спецификации приходит из 182, здесь только сверяется, что он на месте.

**Двери инварианта** (пути, которыми реализация может выйти за свой класс; перечень уточняется поиском в первом заходе и записывается в журнал): запись через `ReadEnv`; конструирование `ActEnv` снаружи; привязка не тем `bind_*`; замыкание, захватившее изменяемую среду; глобальное состояние модуля; прямой импорт эффектного модуля.

Источник проб: пробы оркестратора вне репозитория (каталог `_probe-bind/` рядом с деревьями задач: `e/` и `guard_impl_effects.py`); исполнитель переносит нужное в пакет.

   - отрицательные компиляции дают ожидаемые ошибки: запись в `ReadEnv`; подделка `ActEnv`; не тот класс в `bind_*`;
   - тест-хост ловит обход через замыкание (счётчики по классам, сверка мира);
   - страж на 5 пробах: чистая реализация — 0 нарушений, четыре нарушающие — пойманы;

   - `nova test` затронутых папок зелёные.

   Ожидаемый вывод последней строкой: `ПРИНЯТО 179: отрицательных компиляций 3 из 3; обход замыканием пойман; страж 5 проб (1 чистая, 4 пойманы); effect_surface пуста`.
