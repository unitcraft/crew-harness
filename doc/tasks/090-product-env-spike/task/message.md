# Задание: среда и разведка продукта CrewHarness на Нове — Oracle 0.1.0 на Windows, дочерний процесс по каналам, сервер с WebSocket

Заказчик: владелец репозитория `unitcraft/crew-harness` (он же принимает результат).
Репозиторий: `unitcraft/crew-harness`, ветка `main`. Дата задания: 2026-10-18.
Эпик: [001-crew-service](../../001-crew-service/) («CrewHarness как свой продукт — сервис координации агентов, драйверы агентов, пульт в браузере»); это первая дочерняя задача этапа «продукт на Нове».
Источник: слова владельца в чате оркестратора, 2026-10-18: «когда начинаем продукт CrewHarness? … сейчас это реализовано … я хотел бы для начала в браузере иметь возможность открыть сессии и поговорить с агентом …
ядро концепции — всё сделано на движке стейт-машин, события должны быть самодостаточными и обрабатывать вход и генерить выход»; «пишем на Нова, для MVP компилируем Оракулом до тех пор, пока Карина не будет готова»; «заводи 1, делай быстрым способом».
Плагин OpenCode остаётся обкаткой идей; продукт — этот репозиторий (владелец, 2026-10-18).

Задача полная: разведка, сдача отчёта. Быстрый путь. Основа — свежий `origin/main`.

## Чего хочет владелец

- Продукт пишется на Нове; для MVP — компилятор Oracle (Rust), пока Карина не готова (владелец, 2026-10-18).
- Первый вертикальный срез продукта: в браузере открыть сессию и поговорить с агентом; ядро — движок стейт-машин, события самодостаточные (вход → выход).
- Эта задача — разведка: что из нужного уже работает на Oracle 0.1.0 на этой машине (Windows), что нет, и точные команды. Продуктовый код пока не пишется.

## Что нужно

1. **Среда.** Скачать релиз Oracle 0.1.0 для Windows (`nova-oracle-0.1.0-windows-x86_64.zip`, около 16 МБ, https://github.com/nv-lang/nova/releases/tag/oracle-v0.1.0; `gh release download` или `curl`) в рабочий каталог ВНЕ репозитория (например, во временную папку агента), проверить SHA-256 по `SHA256SUMS` релиза, распаковать; PATH не менять навсегда
   (только в командах сессии). Прочитать `docs/guide/quickstart.md` Нова на теге релиза (чтение, `gh api` или локальный клон в режиме чтения) и выполнить установку по нему. Нужен Clang: LLVM лежит в `C:\Program Files\LLVM\bin` (не в PATH), Visual Studio установлена; выяснить, что ещё требуется для сборки на этой машине. Ничего не устанавливать системно без вопроса.
2. **Привет, мир.** Программа на Нове `hello`: собрать и запустить; записать точные команды (рабочий каталог, переменные, флаги) и время сборки.
3. **Дочерний процесс по каналам.** Программа на Нове запускает `node -e` с коротким скриптом-эхо (читает строки stdin, пишет их в stdout с префиксом) через эффект `Proc` (`Command.new(...).start()` и чтение/запись каналов; паттерн ACP по stdio): послать две строки JSON, прочитать два ответа, завершить процесс, код выхода. Примеры — в `examples/os/` Нова (`agent_runner.nv`, `pty_session.nv`) и `std/src/os/`.
4. **Сервер и WebSocket.** Подключить пакет Polaris (`nova update`; пины — по релизным запискам Oracle 0.1.0: `polaris` 0.2.4, `http` 0.2.1, `tls` 0.2.1) и поднять на `localhost` сервер: страница `GET /` (статический HTML), WebSocket-эхо `/ws`. Проверить скриптом на Node 24 (глобальный `WebSocket`): открыть, послать сообщение, получить эхо, закрыть. Если пакет не собирается Oracle 0.1.0 — зафиксировать ошибку и минимальное воспроизведение.
5. **Мостик к агенту (информационно).** Скриптом на Node (не на Нове) проверить, что `opencode acp` на этой машине отвечает на `initialize` по stdio (одна строка JSON-RPC): версия протокола и возможности агента — в отчёт. Без записи ключей и входа в аккаунты.
6. **Отчёт.** Что работает на Oracle 0.1.0 на Windows, что нет, обходы; версии (Oracle, Clang, Visual Studio, Node, OpenCode); время сборки; список багов или пробелов для интегратора Nova (с минимальными воспроизведениями — файл и команда); оценка пригодности для первого среза («открыть сессию в браузере и поговорить с агентом»): готово / нужен обход / блокер, и что бы ты сделал дальше (порядок 2–4 следующих задач).

## Критерии приёмки

- Все шесть пунктов выполнены или названа причина, по которой пункт невозможен (с командой и текстом ошибки).
- Каталог `product/spike-env/` в рабочем дереве задачи: исходники `hello`, `child_echo`, `ws_echo` на Нове, скрипты проверки на Node (`child_echo_child.js`, `ws_echo_check.mjs`, `acp_initialize.mjs`) и `README.md` с точными командами сборки и запуска на Windows. Без бинарников, без скачанных архивов, без ключей и абсолютных путей машины владельца (в README — пути вида `C:/work/...`).
- Тест-проба в смысле «красное до зелёного»: для каждой программы — запуск, показывающий результат (вывод, код выхода); для сервера — скрипт проверки.
- Стражи: `sh scripts/guards/run-all.sh` — 8 и больше, FAIL 0; коммит по правилам AGENTS.md (английское сообщение, `-s`, без `#число` в сообщении).
