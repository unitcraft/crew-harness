## 2. Решения в пределах задачи

- Повтор M18a идёт и приёмщику, и автору (в 042 напоминание — пара писем); пятое письмо говорит, что оно последнее.
- Счётчик неудач доставки живёт в памяти процесса: после перезапуска считает с нуля, но письмо не повторится (постоянный id `session-lost-…`).
- Строка «застряла» видна там, где у сессии есть запись состояния; закрытая вкладка `assign` без своих задач её не получает.
- Приёмщик, которого создаёт сам плагин, без карточки не считается пропавшим: его запускает `assignReviewers`.
