# Задание: номер поручения Crew не совпадает с номером папки задачи

Заказчик и владелец: владелец репозитория `unitcraft/crew-harness` (он же отвечает на вопросы и принимает результат).
Репозиторий кода: `unitcraft/crew-harness` (https://github.com/unitcraft/crew-harness, ветка `main`). Дата задания: 2026-10-15.
Источник: наблюдение владельца 2026-10-15 в окне интегратора crew-harness: новое поручение получило номер #22, а папка `doc/tasks/022-worktree-base-origin/` уже существует; интегратор сначала объяснил это как норму, затем признал коллизию.

Задача полная, быстрый путь; временный фикс до решения об унификации.

## Чего хочет владелец (его слова, 2026-10-15, чат оркестратора)

- «быстрый фикс временно: плагин при создании поручения пропускает номера, занятые папками doc/tasks/NNN-* проекта — согласовано».
- «нам реально нужны оба понятия?»; «рассмотри унификацию понятий, если нет явной причины их разделять» — разбор в `analysis.md`.

## Что есть сейчас

- Номер папки `doc/tasks/NNN-<slug>/` (задача по методике) выбирают руками; плагин его не знает (`AGENTS.md` п. 1, `doc/tasks/README.md`, `doc/canon/process.md`).
- Номер поручения Crew `#N` считает плагин: `max(номеров файлов задач проекта) + 1` (`opencode-plugin/tasks.ts`, `createTask`); определён только в `crew_help`.
- Одна папка задачи обслуживается несколькими поручениями (шаги С1…С6), номера двух нумераций пересекаются случайно: #20/020, #21/021, #22/022.

## Что нужно

1. При создании поручения номер идёт после наибольшего из двух: номеров файлов задач проекта и номеров папок `doc/tasks/NNN-*` в каталоге проекта; проект без `doc/tasks` считает как раньше.
2. Тест: папки с номерами 001, 022, 031, 042 → первое поручение #43; следующая папка 050 → поручение #51; проект без папок — 1, 2.
3. В `analysis.md` — разбор: нужны ли оба понятия и как их свести в одно.

## Границы

- Только плагин `opencode-plugin/` и документы; проекты-потребители не менять.
- Перезапуск службы — владелец; слияние и «обновляй» — по его слову.
