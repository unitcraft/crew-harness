    Причина: у моделей Codex в настройках владельца `input` меньше `context` (461000 при 525000, в каталоге 922000 при

    записи Codex несут `input` явно (Ф-26), поэтому число и сценарии не меняются; затрагивается только запись без `input`,
    сделанная вручную.
    Место: REQ-08, Д-03, Д-16.

14. **Поверхностная: AC-33 объединяет около десяти проверок слоя и `save` в одном сценарии.** критичность: поверхностная;
    уровень: требования.

    Место: AC-33.
