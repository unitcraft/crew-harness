## Чего хочет владелец

Слова владельца, 2026-10-25 (чат Методики и оркестратора): дерево хранит полную запись внешней функции (вариант Т1), имя формата дерева `machine/2` не меняется. Формулировка передана исполнителю оформления оркестратором (пересказ); дословная цитата владельца лежит в чате и вносится в журнал при приёмке постановки.

## Что нужно

Цель одной фразой: в дереве — `primitives:[{name,params:[{name,type}],result,class}]`, рендер дерево → текст восстанавливает раздел `## Внешние функции` один в один.

1. Узел `primitives` дерева хранит для каждой внешней функции имя, параметры (имя и тип), результат и класс.
2. Имя формата дерева `machine/2` остаётся; схема `machine-2.schema.json` обновляется.
3. Рендер дерево → текст пишет раздел `## Внешние функции` (en `## External functions`) один в один.
4. Деревья образцов пакета пересобираются командой `alula compile`; сопровождающая проза версии — не здесь (181).
