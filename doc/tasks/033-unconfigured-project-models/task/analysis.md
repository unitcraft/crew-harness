# Разбор задачи 033

Быстрый путь, одобрено владельцем 2026-10-12.

## Где выбирается модель

- `crew_spawn` (`core.ts`): профиль этапа по включённому набору (`resolveStageProfile`), иначе `spawn_models[ступень]`, иначе `DEFAULT_SPAWN_MODELS` (heavy — claude-code/opus). Это место и закрыто отказом.
- Тот же запасной путь по умолчанию есть у запуска приёмщика (`index.ts`, `startReviewer`), шага авто-плана (`index.ts`) и переназначения (`core.ts`, `reassign`). Они работают только по задаче, которая уже создана через `crew_spawn`, поэтому отдельного отказа не получили.
- `crew_task assign` модель не выбирает: задача отдаётся уже открытой вкладке. Отказа там нет.

## Что считается «модель определена»

Любое из трёх:

1. Явный параметр `model` в вызове `crew_spawn` (новый параметр; он главнее набора).
2. У проекта включён набор профилей (`profile_set` задан), либо заданы `spawn_models`. `tier_max` сам модели не определяет, он только потолок.
3. В настройках проекта `allow_default_models: true` (новый ключ, по умолчанию выключен, группа «Профили моделей»).

Функция `modelsDefined` в `settings.ts`; её же использует `crew_doctor`.

## Как узнаётся модель сессии

Карточка вкладки (`card.model`): её пишет хук запроса (`model.request`, `index.ts`), запасной источник — база OpenCode. Отказ называет `me.model`; если модель неизвестна, так и сказано.

## Что сделано

- Отказ `crew_spawn` без записи в журнал и без сессии; текст с тремя вариантами для вопроса владельцу.
- `crew_config {action: "apply_template"}`: шаблон в `config-template.ts`; ключи проекта побеждают, связка model_profiles / profile_sets / profile_set дописывается только целиком; напоминание о коммите.
- `crew_doctor` и `/crew` (сводка и боковая панель): «проект X не настроен: модели».
- Справка `crew_help`, README, тест `crew-unconfigured-models.test.mjs`, снимок справки.

## Не сделано

- Состояние проекта в `crew_doctor` читается по закоммиченным настройкам; незакоммиченная правка профилей учитывается только отказом `crew_spawn` (он смотрит рабочую копию профилей).
- Проекты прежней формы опций (имя → корень) в сводке `/crew` не помечаются (у них нет записи последних хороших настроек); `crew_doctor` их проверяет.
- Запасной путь по умолчанию у приёмщика, шага авто-плана и переназначения не менялся.
