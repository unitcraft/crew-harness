## Находки

1. Правило адреса автора уходит в «судить нечего» с кодом 0 по отсутствию настройки, а не по среде: локально
   потерянная настройка установщика молча снимает проверку.
   - Материал: meth §20 «Код возврата решается до печати»: «Недоступная предпосылка — список, интерпретатор — даёт
     ненулевой код, а не тихий пропуск»; meth §19: «не выполнилась ≠ пройдена»; msg п.7: «страж не зелёный на пустом
     входе».
   - Место в spec.md: REQ-15 («В CI сверка с ожидаемым адресом не применима — установщик там не запускается; страж
     сообщения печатает «судить нечего: нет настройки установщика»»); REQ-35 («Судить нечего» законно и для правила,
     которое по шапке стража не применимо в среде); REQ-27 и Д-03 (красные предпосылки — «нет git, списка,
     интерпретатора», настройки нет); AC-09 («самотест (локальный и «как в CI», без настройки)»).
   - Факт (проба 4): строк, где настройка адреса связана с красным или отказом, — 2 (REQ-28 и Д-10), обе про отказ
     установщика без `user.email`, а не про страж; признак, по которому страж узнаёт CI, не назван нигде (0 строк);
     в AC-09 «как в CI» задано отсутствием настройки.
   - Следствие: условие «судить нечего» на деле — «нет настройки». Локально настройка теряется без установщика:
     другое рабочее дерево с общей конфигурацией, `git config --unset`, клон, где `core.hooksPath` поставлен руками,
     ручной прогон стража. Тогда сверка адреса — то самое правило, которое ловит подмену `user.email` агентом (П-08),
     — выходит с кодом 0, а самотест, сделанный по AC-09, это закрепит. Это класс meth §21 (молча зелёный страж при
     сломанной предпосылке).
   - Что сделать: в REQ-15 и REQ-35 назвать признак среды CI (например, переменная окружения раннера GitHub
     Actions), «судить нечего» — только при нём; локально без настройки — красный с подсказкой «запусти установщик»
     (добавить настройку в предпосылки REQ-27/Д-03); в AC-09 — проба «локально, без настройки — красный» и проба
     «как в CI» по признаку среды, а не по отсутствию настройки.
   - критичность: существенная
   - уровень: требования
