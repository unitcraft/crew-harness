## Находки

1. REQ-14 и REQ-38 не определяют, какая часть файла сообщения судится; при коммите через редактор с `-v` или
   `commit.verbose` хук `commit-msg` получает ещё и diff, и «все строки» делают законный коммит красным.
   - Что не так: REQ-38 (512–517) судит «ВСЕ строки сообщения, включая начинающиеся с `#`», REQ-14 (314–315) исключает
     «комментарии git» из правила ASCII, но только строки `#` и `>`. Проба 6 (одноразовый репозиторий, хук `commit-msg`
     копирует свой файл, `git commit -v` с редактором, дописывающим тему): в файле, который видит хук, после строки
     «Everything below it will be ignored» лежит весь diff индекса — с контекстом и удалёнными строками (`-…`); эти строки
     не начинаются с `#`, и git вырежет их после хука. Следствия: (а) коммит, который убирает из файла утёкший путь машины
     или имя из списка, при `git commit -v` краснеет по REQ-38 — по удалённой строке diff; именно такой коммит владелец
     делает, чистя утечку; (б) любой такой коммит, добавляющий в документ кириллицу (а документы репозитория русские), краснеет
     по REQ-14 — строка `+привет` не `#` и не `>` (проба 7). Обратная сторона: при `-F` и `-m` git ничего не вырезает, и
     строка-ножницы с хвостом остаётся в истории вместе с приватным образцом (проба 8); значит правило «судить до ножниц»
     пропустило бы утечку — поведение нельзя вывести ни из «все строки», ни из «до ножниц». Спецификация должна сказать:
     судится то, что уйдёт в историю. Прошлая проверка (заход 24, «Рассмотрено») разбирала шаблон без `-v` и нашла его
     безопасным; с `-v` это не так.
   - Цитата: «ВСЕ строки сообщения, включая начинающиеся с `#` (`git commit -F` оставляет их в истории, хук их видит)»
     (REQ-38); «кроме строк цитаты, начинающихся с `>`, и комментариев git» (REQ-14).
   - Место в spec.md: REQ-38 (512–517), REQ-14 (314–315), AC-32 (931–938).
   - Что сделать: в REQ-38 и REQ-14 записать, что судится текст, который git сохранит в историю: то, что git вырежет до
     записи (шаблон редактора и diff после строки-ножниц при `-v` в режиме редактора), не судится; всё сохраняемое, включая
     строки `#` и строку-ножницы при `-F`/`-m`, судится. В AC-32 добавить зелёную пробу: коммит через редактор с `-v`, где
     diff содержит удалённую строку с образцом из временного списка, а само сообщение чистое, — проходит; и красную: при
     `-F` строка-ножницы с образцом после неё — отказ.
   - критичность: существенная. Меняет то, что отклоняется (законный коммит `-v`, правка утечки), и сценарий AC-32.
   - уровень: требования
