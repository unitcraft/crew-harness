## Находки

1. REQ-38 не говорит, какие строки файла сообщения судятся, кроме строк цитаты, а AC-32 не имеет красной пробы ни для
   строки цитаты, ни для строки `#`; при `git commit -F` git оставляет строки `#` в истории.
   - Что не так: REQ-38 (510–514): «прогоняет текст сообщения (строки цитаты с `>` тоже)». Это единственное место, где
     проверка приватности нарочно отличается от REQ-14, который исключает строки цитаты и «комментарии git» (312–313). О
     строках `#` REQ-38 молчит. Проба 7 в одноразовом репозитории с хуком `commit-msg`: `git commit -s -F файл`, где в файле
     строка `# …`, строка `> …` и тело, — в сохранённом сообщении (`git log -1 --format=%B`) остались обе строки, и хук
     видел их обе; значит, строка `#` в сообщении, подготовленном для `-F` (так коммитят агенты по REQ-16 и О-07), попадает в
     публичную историю, которую без силового пуша не вычистить (AG п.15). Реализация, которая берёт для REQ-38 тот же разбор
     сообщения, что для REQ-14 (он по требованию пропускает «комментарии» и цитату), оставит путь машины в строке `#` без
     отказа. AC-32 (928–933): красные пробы названы без места образца в сообщении; зелёная проба «строка цитаты без
     приватных данных» есть, красной пробы «образец в строке цитаты» и «образец в строке `#`» нет. Мутант «приватность не
     ищется в строках цитаты и `#`» проходит AC-32 целиком.
   - Цитата: «прогоняет текст сообщения (строки цитаты с `>` тоже)» (REQ-38); «кроме строк цитаты, начинающихся с `>`, и
     комментариев git» (REQ-14); «строка цитаты без приватных данных — проходят» (AC-32).
   - Место в spec.md: REQ-38 (510–514), REQ-14 (312–313), AC-32 (928–933).
   - Что сделать: в REQ-38 записать «судятся все строки файла сообщения, включая строки цитаты `>` и строки `#`: при `-F`
     и `-m` git их в историю сохраняет»; в AC-32 добавить две красные пробы (путь машины в строке `> …`; образец списка в
     строке `# …`) и по одной зелёной на ту же строку без приватных данных. Расхождение с REQ-14 (там строки `#` и цитата
     исключены) оставить как есть: ASCII-правило — ответ владельца О-05.
   - критичность: существенная. Меняет то, что отклоняется (строки `#`), и сценарий AC-32; находка про сценарий поверхностной
     быть не может.
