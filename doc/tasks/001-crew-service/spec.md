## Спецификация

### goal

Свой продукт CrewHarness для владельца: сервис координации ИИ-агентов вне OpenCode (Go, с переносом на Нову), сменные
драйверы агентов на подписках (первыми Claude Code, Codex CLI, Kimi Code) и пульт владельца в браузере, ведущий задачи
по циклу методики task-runner, — с переездом проектов claude-limits и nova с плагина OpenCode без потери задач и писем.

Граница этой задачи (FACT, msg M-04): результат задачи 001 — утверждённые spec.md и plan.md; реализация — после
утверждения (как именно — В-01).

### expected_state

Сервис-процесс (Go) на машине владельца держит правила плагина и цикл task-runner; каждый агент — отдельный процесс
официального CLI в дереве своей задачи, запущенный драйвером; агенты обращаются к сервису по MCP `crew`; владелец
работает в браузерном пульте (доска, ворота, терминал, чат, картинки); проекты переезжают по одному по слову
владельца, плагин работает до переезда последнего проекта; есть документированный путь переноса сервиса на Нову.
