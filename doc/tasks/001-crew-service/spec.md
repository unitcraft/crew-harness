## Спецификация

### goal

Свой продукт CrewHarness для владельца: сервис координации ИИ-агентов вне OpenCode (Go, с переносом на Нову), сменные
драйверы агентов на подписках (первыми Claude Code, Codex CLI, Kimi Code) и пульт владельца в браузере, ведущий задачи
по циклу методики task-runner, — с переездом проектов claude-limits и nova с плагина OpenCode без потери задач и писем.

Граница этой задачи (FACT, msg M-04): результат задачи 015 — утверждённые spec.md и plan.md; реализация — после

### expected_state

Сервис-процесс (Go) на машине владельца держит правила плагина и цикл task-runner; каждый агент — отдельный процесс

### constraints

- C-01 Подписки, не ключи API: агент — официальный CLI вендора на подписке владельца (msg M-48).
- C-02 Claude — только немодифицированный Claude Code; имя «Claude Code» не входит в имя продукта и его логотип (msg
  M-49; S18).
- C-03 Windows 11 владельца без WSL; Git Bash есть (плагин им пользуется: `watch.ts:73`; Kimi Code требует Git for
  Windows — S32) (msg M-50).
- C-04 Очередь машины обязательна; локальная машина владельца — место работы агентов (msg M-51).
- C-05 Язык старта сервиса — Go; цель — Нова; код пишется под перенос (msg M-26, M-33). Установлен Go 1.26.2
  (`go version`).
- C-06 Зависимости сервиса — только те, у которых есть или будет аналог в Нове: JSON, файлы, процессы, TCP/HTTP, PTY;
  в std Новы нет HTTP, WebSocket, SQLite (nova N-11; draft D-13).
- C-07 Пульт — HTML и скрипты в браузере; Нова собирает только нативный код, пульт при переносе не трогается
  (nova N-09; draft D-19).
- C-08 Лимиты подписки общие для всех сессий аккаунта; объявленные лимиты Pro/Max рассчитаны на обычное
  индивидуальное использование (S16, S17, S18).
- C-09 Опора на быстро меняющиеся функции (agent view — research preview; правила `claude -p` и SDK) — риск,
