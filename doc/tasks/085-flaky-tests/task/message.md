## Что нужно

1. **Разбор:** для каждого теста из списка выше — почему он падает (общий ресурс: каталог временных файлов, журнал, порт, файл данных, часы; зависимость от времени: пределы в
   миллисекундах, таймеры, гонка «письмо — проход»; порядок запуска) и воспроизведение (запуск 10 раз по 8 параллельно вместе с нагрузкой — например, несколько копий самого
   набора — с подсчётом красных). Найти и другие тесты с теми же причинами: поиск по общим путям временных файлов (`os.tmpdir()`, `/tmp`, `%TEMP%`), абсолютным пределам времени
   (`< N ms`, `Date.now()` разностью), фиксированным паузам (`setTimeout`/`sleep` с константой), общим портам; перечень с указанием строк.
2. **Правила исправления** (никакого ослабления настоящих проверок «чтобы позеленело»):
   - общий ресурс — у каждого запуска свой: свой подкаталог временных файлов (по идентификатору процесса), свой журнал, свой порт (нулевой — выбирает система);
   - проверка скорости, которая правда измеряет скорость (AC-11 «б» и подобные), не зависит от загрузки машины: сравнение с замером в том же процессе в тот же момент
     (отношение, как уже задумано), с повтором при выбросе; если честного относительного способа нет — вынести в отдельную группу, запускаемую по одному, и записать в
     `package.json` и README, как запускать;
   - фиксированная пауза на «успеет» — ожидание условия с пределом, а не константа;
   - golden, который различается между прогонами, — найти источник различия (время, порядок, случайность) и сделать его детерминированным в тесте, а не в проверке.
3. **Тесты:** сами исправления — тесты; плюс проверка устойчивости: скрипт или команда в `package.json` (`test:stable`), которая гонит заданный набор файлов N раз по 8
   параллельно и печатает число красных по файлам. Красная проба до кода — воспроизведение из пункта 1 на прежнем коде (хотя бы один падающий из серии на каждом исправляемом
   файле); после исправления серия из 10 прогонов без красных. Полный `npm test` по 8 параллельно ([AGENTS.md](../../../../AGENTS.md), п. 9); golden — только изменившиеся ключи.
4. README плагина (раздел о тестах) и [AGENTS.md](../../../../AGENTS.md) п. 7–9 — одна-две фразы, если появилась группа «по одному» или команда `test:stable`.
