## 3. Правки и неизменные проверки

- Журнал: в тестах журнала `TEMP`, `TMP`, `TMPDIR` указывают на папку прогона до импорта плагина (приём из `crew-esc-question`); код плагина не менялся; все проверки на месте. Для `answer-harness` — опция `ownLog` только у `crew-answer-journal` и `crew-stuck-clear` (общее включение ломало `crew-answer-golden`).
- golden: берётся первое напоминание (текст без «Напоминание N из M»); сравнение с `landing-golden.json` прежнее, ключи не менялись.
- progress: «в» — вместо «медиана ≤ 1 мс» теперь «медиана показа ≤ 0,25 × чтение 20 журналов целиком», замер в том же цикле; на тихой машине это чуть мягче (≈1,9 мс против 1 мс), показ, читающий файлы, дал бы ≥ 1×; «а», «б», «в» — отношения прежние, добавлен повтор до 3 замеров (реальное замедление видно во всех); «г» — порог 100 мс прежний, повтор до 3 прогонов, `seen == 600` проверяется.
- step-yield: «a» — `maxGap < длительность/4` вместо `< 300`; красная проба `CREW_TEST_SYNC=1` по-прежнему красная; «b» — предел 1500 → 2500 мс.
- push, select, slot, plan-task: положительные «успеет» — ожидание условия (`until`, 60 с); в `turn()` ожидание конца доставок; паузы остались там, где проверяется отсутствие события; в select биение окна датировано на 30 с вперёд (свежесть окна этим тестом не проверяется).
- answer-journal REQ-15: «пасс и боковая строка < 50 мс» заменено отношением к чтению всех файлов журнала: пасс < 0,5×, боковая строка < 1×.
- Команды: `test:parallel`, `test:stable` (18 файлов, по 10 раз, по 8); README, `test/README.md`, `AGENTS.md` п. 7.
