## 4. Решения и расхождения

- **Единственный достижимый конец.** Спецификация требует раздел «Концы», проверка достижимости не даёт объявить конец без пути к нему; чат на Нове не кончается. Конец `Closed` достижим по слову `close_session`, сервер его не шлёт; на Нове это событие неизвестного имени. Путь назван в тесте `de the way only the table has`, сценарий `(table only)` вне сравнения. Слово `закрыть_сессию` добавлено в `src/machine_text/names_format.tsv` (одна строка).
- **Имя машины `DialogSession`** (не `ChatSession`): иначе сценарии одно- и многооборотного чата смешались бы по имени. Имя входит в журнал (`machine_started`), поэтому у многооборотной `ChatSession` метод `@name()` теперь тоже даёт `DialogSession` (одна строка `src/chat/chat.nv`; однооборотная не изменилась). Журналы уже существующих сессий хранят `ChatSession`; они всё равно не продолжаются (снимки старого формата).
- **Данные хода обнуляются** при возврате в `Idle` (иначе данные не равны состоянию `Idle` на Нове, у которого полей нет).
- **Правки вне основных границ, малые:** тип `Row` таблиц состояний (`src/machine_table`) → `TableRow` (в одной программе с драйвером PostgreSQL мешает вариант `Row` драйвера, п. 48); помощник `ev` в `src/machine/eval_test.nv` → `ev_plain` (п. 50); `begin_engine` хаба → `begin_session_engine` (п. 49).
- **Однооборотные сценарии `chat_engine_test.nv`** уже были данными (39 файлов `chat-*`); для многооборотной машины перенесены 28; 11 файлов «отказ с кодом X» заменены тестом `de every code` на всех кодах.
