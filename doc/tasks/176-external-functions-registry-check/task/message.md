## Чего хочет владелец

Слова владельца, 2026-10-25 (чат Методики и оркестратора): расхождение объявления с реестром хозяина — ошибка при загрузке, правило AL-123. Формулировка передана исполнителю оформления оркестратором (пересказ); дословная цитата владельца лежит в чате и вносится в журнал при приёмке постановки.

## Что нужно

Цель одной фразой: сверять каждую внешнюю функцию файла с реестром хозяина и называть расхождение.

1. Любое расхождение подписи в файле (имя, параметры, результат, класс) с реестром — ошибка с именем функции и расхождением; образец текста: «функция записать_статус: параметр 2 в файле число, в реестре строка».
2. Функция есть в файле, но нет в реестре — ошибка.
3. Лишние функции в реестре допустимы.
4. Признаки `читает`/`пишет` и роли берутся из реестра, не из файла.
5. Корпус: загрузка каждой таблицы методики и продукта с её `registry.md` даёт 0 расхождений либо список исправлений реестра.

## Критерии приёмки

AC-1. Красная проба на раздел спецификации AL-123 до кода: команда AC-2 на прежнем коде красная (раздел спецификации уже записан задачей 182, код ещё нет); красный вывод и номер раздела записываются в журнал первой записью работы, после работы та же команда зелёная.
AC-2. Одна команда-критерий: `sh scripts/accept-176.sh` (скрипт `scripts/accept-176.sh` пакета пишет исполнитель первым шагом, он красный до работы). Она запускает:

   - тесты на каждый вид расхождения зелёные: имя, число параметров, тип параметра, результат, класс, отсутствие в реестре, лишнее в реестре (ожидается «ок»);
   - скрипт корпуса: загрузка каждой таблицы методики и продукта (файлы берутся из выкладок рядом, только чтение) с её `registry.md` — расхождений 0; для таблиц продукта это достигается правкой реестров продукта (+1–2 ч), для таблиц методики — списком исправлений реестра в виде текста письма Методике (реестр методики здесь не правится; правило чужих репозиториев).

   Ожидаемый вывод последней строкой: `ПРИНЯТО 176: видов расхождений 7 из 7; таблиц N, расхождений 0 (исправлений реестров продукта K, письмо Методике: M строк)`.
AC-3. Приёмка — ОДИН перепрогон команды AC-2 чистым заходом (этапных ревью нет).

## Оценка

Число запусков и часов до результата: 4 запуска, 1,5–2,5 ч агента (+1–2 ч на правку расхождений реестров). Расхождение вдвое в любую сторону — повод остановиться и пересмотреть постановку (вопрос оркестратору с рекомендацией), а не дотягивать.
