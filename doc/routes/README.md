# Режимы работы по методике

Три режима пульта управления CrewHarness; хаб читает файлы этой папки при каждом запуске шага (настройка `routes_dir`, по умолчанию `doc/routes`
от рабочей папки хаба), поэтому правка текста действует без пересборки.

| Файл | Режим | Шаги | Что это по методике |
|---|---|---|---|
| [interactive.md](interactive.md) | «Интерактивный» | нет | малый (супербыстрый) маршрут: владелец пишет задачи, исполнитель делает правку, выкладывает на контур, даёт ссылку |
| [fast.md](fast.md) | «Быстрая задача» | 6 | быстрый маршрут: постановка, красная проба, реализация, тесты и стражи, одна независимая проверка, итог |
| [full.md](full.md) | «Полный путь» | 8 | полный маршрут: постановка с критериями, план, красная проба, реализация по плану, этапная проверка, независимая приёмка, документы, итог |

Источник — раздел «Соразмерность исполнения» и инварианты маршрута (`methodology.md`, раздел 18) и `task-sessions.md` методики
([unitcraft/ai-dev-methodology](https://github.com/unitcraft/ai-dev-methodology)).

## Формат файла

Простой markdown; его разбирает короткий разборщик хаба (`src/server/routes.nv`), правил три:

1. Строка `## инструкция` открывает раздел инструкции агенту: всё до первой строки `## шаг` (в сеансе её хаб подкладывает скрытой
   подсказкой перед сообщениями).
2. Строка `## шаг <id> · <вид> · <заголовок>` открывает шаг; тело шага — всё до следующей строки `## шаг` — это промпт-задание шага.
   Вид: `self` (шаг делает тот же агент) или `independent` (независимый проверяющий из другой семьи агентов).
   Необязательный четвёртый кусок `· обязательный` — шаг пропустить нельзя (инвариант 5 методики: проверяющий не автор).
3. Всё остальное (заголовок первого уровня, пояснения) разборщик пропускает.

В тексте промпта подставляются `{N}` (номер подзадачи — номер последнего сообщения в задаче) и `{task}` (папка файлов задачи).
Папка задачи: `doc/tasks/NNN-<slug>/task/` в репозитории папки сессии (если там есть `.git` и `doc/tasks/`), иначе
`<data_dir>/<сессия>/tasks/NNN-<slug>/task/`. Подзадача N — N-е сообщение пользователя в задаче: файлы `message.N.md` (сообщение и дата)
и `progress.N.md` (чеклист шагов режима, `- [ ]` / `- [x]`; хаб раз в две секунды считает отметки и показывает прогресс на странице).
