# Решения (ADR)

Формат — MADR: контекст, рассмотренные варианты (не меньше двух, с плюсами и минусами), решение, последствия (с
негативными), границы. Читается «Решение» и «Границы»; фраза из «Вариантов» решением не является.

Правка: дрейф — датированной вставкой «Уточнение, дата»; замена — новым решением со ссылкой, у старого статус
«заменено ADR-NNNN». Принятые решения не переписываются. Файл: `NNNN-<slug>.md`, статус в первой строке.
