# Словарь: термин методики -> идентификатор -> где в методике

Код движка и демонстрационной машины написан английскими идентификаторами: Нова в Oracle 0.1.0 не принимает
русские (слово владельца, 2026-10-18). Методика описывает движок русскими именами; этот файл сопоставляет их.
Источник — репозиторий `unitcraft/ai-dev-methodology`, ветка `main`, коммит `03b93a2162991f954b2ac887afdb389c788838f3`
(на момент написания, 2026-10-18). Файлы методики: `state-machine-engine-automaton.md` (движок, «Движок»),
`state-machine-spec.md` (нормы, «Спец. N» — правило N), `task-runner-session-states.md` и `task-runner-meeting-states.md`
(«Типы на Нове»). Столбец «Где» называет файл и раздел, в скобках — русское имя в методике.

## Типы

| Термин | Идентификатор | Где |
|---|---|---|
| Запрос (конверт обращения) | `Request[T]` | Спец. 15; `task-runner-meeting-states.md`, «Типы на Нове» (`Request[T]`); движок, «Типы» (`Запрос`) |
| Ответ с результатом | `Reply[R]` | там же (`Reply[R]`, `ОтветСРезультатом`) |
| Ответ с отказом | `Rejection` | там же (`Rejection`, `ОтветОтказ`) |
| Ответ: результат или отказ | `Response[R]` (`Answer`, `Refusal`) | там же (`Response[R]`, `Исход`). В задании 091 тип назван `Outcome`; в прелюдии Нова уже есть `Outcome[T]`, и свой тип с этим именем ломает C (spikes/env, `repro_engine`, п. 9), поэтому — `Response`, как в блоке «Типы на Нове» методики |
| Код сбоя | `FailCode` | Спец. 16; движок, «Типы» (`КодСбоя`) |
| Событие | `Event` | Спец. 13, 31; движок, «Типы» (`Входящее[Событие]`) |
| Вид события (класс, по которому ветвится движок) | `EventKind`, поле `Event.kind` | Спец. 6, 14, 16; в методике нет отдельного типа: движок ветвится по виду `Получено` (`ПолученОтвет`, `ПолученоСлово`, `ПросроченЗапрос`) |
| Имя события машины | `Event.name` | Спец. 31 («вид» события в идентификаторе `<вид>-<номер>`) |
| Выход шага (команда движку) | `StepOutput` (`Send`, `Log`, `Cancel`, `Save`, `Finish`) | движок, «Механика исполнителя» (отправка, журнал, снимок, конец). В 091 тип назван `Output`; в задании 095 переименован: `std.os.Output` (результат `Command.output()`) ломает C, как только программа подключает `std.os` (`spikes/env/repro_acp`, `user_output_vs_std_os`) |
| Результат шага | `StepResult` | движок, протокол `Автомат`, метод `перейти` (`Переход`) |
| Машина | `Machine` (протокол) | движок, «Протоколы и хранилище» (`Автомат`) |
| Журнал, строка журнала | `Journal` (эффект), `JournalEntry` | Спец. 31; движок, «Типы» (`ЗаписьЖурнала`), эффект `Журнал` |
| Снимок | `Snapshot` | Спец. 22; движок, «Протоколы и хранилище» (`Снимок`) |
| Хранилище | `Store` (эффект) | движок, эффект `Хранилище` |
| Связь со стороной | `Agent` (эффект: `send`, `receive`, `cancel`, `ack`) | движок, эффект `Связь` (здесь сторона одна — агент); `ack` — подтверждение входящего события после фиксации (задание 095), в методике нет |
| Время | `Time` (стандартный эффект Нова) | движок, «Протоколы и хранилище»; `Time.now()` |
| Данные движка | `EngineState` | движок, «Данные» (`СостояниеДвижка`) |
| Открытый запрос | `OpenRequest` | Спец. 14, 16 (`открытые_запросы`) |
| Счётчик попыток стороны | `PartyCounter` | Спец. 15 |
| Исполнитель | `Engine[M]` | движок, «Цикл исполнителя» (`Исполнитель`) |

## Коды сбоя (`FailCode`)

| Код методики | Идентификатор | Примечание |
|---|---|---|
| нет результата | `NoResult` | сбой вне списка исполнитель пишет этим кодом (Спец. 16) |
| отказ модели | `ModelRefused` | |
| соединение оборвалось | `ConnectionLost` | |
| форма не исправлена | `FormNotFixed` | |
| нет ответа в срок | `Timeout` | порождает исполнитель, не сторона |
| отменено родителем | `Cancelled` | в MVP не порождается (вложенных машин нет) |
| остановлено человеком | `StoppedByHuman` | |
| потолок заходов с открытыми находками | `CeilingReached` | в MVP не порождается |
| `MaxTokens`, `MaxTurnRequests` | `MaxTokens`, `MaxTurnRequests` | в методике на коммите `03b93a2` этих кодов нет; добавлены заданием 091 (слово владельца); в MVP не порождаются |

## Виды строк журнала (`JournalEntry.kind`)

`start` (первый шаг), `event` (принятое событие), `note` (строка машины, выход `Log`), `request` (запрос заказан),
`sent` (запрос отправлен), `closed` (запрос закрыт: ответ, отказ, срок, отмена), `discarded` (чужой или поздний ответ
отброшен), `cancel` (отмена заказана), `cancel_sent` (отмена отправлена), `snapshot` (выход `Save`), `finish` (конец
машины), `restart` (повторный вход).
