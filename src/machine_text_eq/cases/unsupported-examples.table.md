# Машина: Примеры, которых эта версия не поддерживает

machine: UnsupportedExamples
machine_version: 1
format: 2.5

> Примеры формата 2.5, в которых есть то, что 107 пометила «не реализовано»: сторона вида `machine` (вложенная машина), столбец `профиль`, строка
> `Предел запросов`, свойство `Правит`, подключение фрагмента «Пауза» с непустым списком вложенных машин и с `вход_заново: запросы_из_к_отправке`.
> Переводчик не молчит: каждое такое место — ошибка вида `unsupported` с номером строки, остальные строки переводятся. Ожидаемое число и места проверяет
> тест `machine_text_eq`; файл служит и ведомостью «не поддержано» по примерам формата.

## Типы

```
перечисление Критичность = Критическая | Значимая | Желательная
тип Находка { критичность Критичность, доказательство текст, повтор да/нет, вопрос да/нет }
тип Линза { идентификатор текст, потери_подряд число≥0, пробы число≥0, попытка число≥0 }
вариант КонтекстРоли {
  Линза { предложение текст, ответы_свидетеля ?[]текст }
}
тип ИтогЛинзы { находки []Находка, пробы число≥0 }
вариант ИтогПравки {
  Закончена { предложение текст }
  Вопрос { предложение текст, вопрос текст }
}
```

## Состояния

Начальное состояние: ПРАВКА

### ЛИНЗЫ — обращение (Lenses)
Сторона: линза; набор: порядок_линз
Срок тишины: 0
Вход:

| поле запроса | выражение | читает |
|---|---|---|
| вид | ВидВызывающего.Линза | сторона |
| сессия | сторона | сторона |
| контекст | вызвать(контекст_роли, КонтекстРоли.Линза { предложение: предложение, ответы_свидетеля: ответы_свидетеля[номер_захода] }) | сторона |
| трасса | трасса | сторона |
| номер_шага | номер_шага | сторона |
| номер_захода | номер_захода | исполнитель |
| к_отправке | к_отправке | исполнитель |
| линзы | линзы | исполнитель |
| ответившие | ответившие | исполнитель |

При приёме:

| событие | действия |
|---|---|
| ответ(итог) | пусть л = обязательно(линзы[сторона]) в (линзы[сторона] = { ...л, потери_подряд: 0, пробы: итог.пробы }); ответившие += 1; находки_линзы[(сторона, номер_захода)] = итог.находки |
| сбой | пусть л = обязательно(линзы[сторона]) в (линзы[сторона] = { ...л, потери_подряд: л.потери_подряд + 1, пробы: 0 }) |

| № | Событие | Условие | Действия | Куда |
|---|---|---|---|---|
| 1 | ответ | — | — | КОНЕЦ |
| 2 | сбой | — | — | КОНЕЦ |
